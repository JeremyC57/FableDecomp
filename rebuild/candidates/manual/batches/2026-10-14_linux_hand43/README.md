## Lessons
- A by-value class argument whose constructor runs BEFORE any scalar argument is loaded (`push ecx` frame, built at the top) is a named
  local, not an in-expression temporary (the temporary form builds it in argument order): 0x008927B0.
- A value computed by a call BEFORE the other arguments are pushed is a local (`long id = GetTextIDFromSymbol(symbol);` then the call):
  0x008918C0; the thing fetched BEFORE the id is pushed is a local too (0x00891F50 / 0x00891FA0), the chained form pushes the id first.
- A manager chain loaded straight into ecx (`mov ecx,[esi+4] ; mov ecx,[ecx+74h]`) before the pushes is an inline accessor on CWorld;
  with a float-returning callee the accessor form tail-jumps unless the result goes through a named float local (0x008909F0).
- `lea ecx,[eax+714h]` (the manager in eax first) for an embedded member used as `this` = an inline member accessor on the manager
  (`void* GetExclusiveOpinionSource() { return m_exclusiveSource.GetPItem(); }`); the reference-returning accessor gives `add ecx,714h`.
- Two separate null tests on a string's data block (length then data) are two inline accessors, each `m_pData == 0 ? default : field`
  (the `== 0` sense makes the null case fall through: `jne` to the load); a single merged if/else gives one test (0x00892070).
- A flag computed before the branch and ONE virtual call tail-duplicated into both arms (`or`/`and` then `push ; call`) is
  `flags |= 4; else flags &= ~4; Set(flags);` with the object through an inline accessor (`GetPhysics()`), so it lives in ecx: 0x00891120.
- The tail jump with argument-slot reuse (`pop esi ; mov [esp+4],eax ; jmp callee`) reproduces for a VALUE-returning call when the
  object is reached through an inline accessor (`GetQuestInfo()->AddBarHealth(...)`, 0x00891AD0); the plain pointer-member chain
  loads the member after the slot store.
- `FindMostRecentMessage(...) != 0` as a bare return expression loses the retail frame layout; the landed `messages` + `message`
  locals (as in RemoveBoastMessage) restore it (0x00893BA0).
- The lane's `GetInterface` template is also emitted out of line in some TUs: pass the plain function name as the leaf (gall.sh reads
  `// Leaf:`), or the extractor picks the larger out-of-line template instantiation.

# Glow targets, weather bounds and GPU shutdown

Three functions independently pass native VC7.1 RELOCATION_MATCH and exact-source canonical behavior tests plus host C++98/O2/no-elision fixtures. Main audited all17 relocation targets, surface destructor vtable and true no-op shutdown helper, all14 immutable source-grade snapshots and frozen source/fixture hashes. Actual shared headers remain integrated and native assertions retained.

B5ECE0 InitialiseTextures uses the actual glow renderer and pixel-format headers. Resource manager GPU member3190 differs from donor40E4 and uses a documented native view with the donor header retained. The old nonnegative page is freed, format21 initialized and a fresh page allocated; four texture allocations run unconditionally at256,64,64,16. Success requires every handle nonnegative. Tests include each allocation failure, old negative handles and resource-global replacement by callbacks. Three author grades.

B51F60 ClipBoxToCamera retains actual weather/camera headers, settings span at1D4 and camera position54. Native code uses the minimum span, not maximum; its ordered comparisons and squared-distance y,z,x arithmetic are preserved. If distance minus radius is within range, a48-byte scaled/translated box is passed to the camera. Main found the actual PDB camera ClipBox signature is const; declaration and full-source fixture were corrected at grade8 and remain byte exact. Tests cover all span axes, exact boundaries, negative ranges and NaNs as well as matrix contents and clip results.

F37170 BeginShutdown obtains the renderer, calls the genuine A0AF80 no-op method and detaches four texture stages. It deletes textures and surfaces then frees eligible non-restorable pages, finally setting the shutdown flag. Actual texture, surface, render-manager and pixel-format headers are included. The surface projection restores its real virtual destructor: native VT122F84C slot0=41C9C0 calls9F2E20 and conditional scalar delete. Texture destruction calls9F9F70 then scalar delete. Native arrays12/resources44/pages28/shutdown40 differ from donor layouts. Fixtures verify first and repeated shutdown, null resources, mixed page flags, ordered destruction and callbacks extending resource/page ends, which must be re-read during iteration. Three author grades.

FreeMemoryPage int and texture usage unsigned declarations are native32-bit ABI projections of PDB long/unsignedlong. No data truncation is introduced on the native compiler. These are isolated compiler/dependency fixtures and do not establish linked whole-game runtime behavior.

# w24B lessons (GOTCHAS-ready)
- (w24B, 2026-11-16) "Header debt" notes in parked lanes go stale fast: before porting a parked match, grep the CURRENT rebuild/include for the helper bodies the note says are missing. 0x00542780 (Q6: "no shared inline GetFrame/TouchResource") matched on the opt-in set of landed 0x00B64550 RenderSunFlare plus one new 4-line inline body; 0x00B625E0's blocker (SetDynamicCast re-read) is the repo's FABLE_RETAIL_CDEFPOINTER_SETDYNAMICCAST_REREAD now.
- (w24B) A lane `hdr/` is a full-file snapshot: never copy it forward. Start from the current repo header and re-add only the opt-in block (hand733's fable_user_profile.h would have reverted the PASS22 / PCLASS / AUTOSAVE opt-ins; the current file already had the typed containers under ..._PASS22_STATE, so the row needed one declaration).
- (w24B) Oracle extents built from the raw host length include manifest gaps: 0x004075C0 is 1194 bytes (rebuild/manifest/manifest-gaps.tsv host_len_trimmed), the w24 oracle row is 1797 = the function + two unlisted functions at 0x00407A70 / 0x00407BA0. When built == a clean prefix of retail (`ninsn` difference == `difflines`), check manifest-gaps.tsv before touching the source.
- (w24B) vector<C3DVector> on the shared STLport header already gives retail's callee pair: C3DVector is non-POD, so push_back calls the __false_type _M_insert_overflow 0x0066E370 and erase/clear goes through __copy_ptrs(__false_type) -> the random-access __copy; FABLE_RETAIL_STLP_COPY_NOINLINE makes that the out-of-line __fastcall 0x0074CA20 and FABLE_RETAIL_STLP_VECTOR_OVERFLOW_OUTOFLINE + FABLE_STLP_OUTOFLINE_UNINIT_COPY keep the overflow visible but called. No traits opt-in needed (Q6's "__true_type" model was wrong).
- (w24B) PAREN-tuple count is additive across inlined helpers: in 0x007DDA30 the clear()'s `push 0` moved -3 with SUBTRACT_XY_GROUP, -1 with X-only + the parenthesised GetSquaredMagnitude, +1 with no group; X-only group + FABLE_RETAIL_C3DVECTOR_MAGNITUDE_NAMED_SQUARED (no parentheses, a named local) is exact. Sweep the existing magnitude/subtract opt-ins as a matrix before adding a new one.
- (w24B) A `fdivr dword ptr [const]` operand in .rdata between other float literals is a float literal, not a global: 0x0126FA6C is 2.0f (the Q6 draft named it g_swoopDistance). Read the retail bytes at the address before inventing a name.
- (w24B) CTCPhysicsBase vtable: CTCBase has slots 0..27, so +0x78 = slot 30 SetPosition and +0x7C = slot 31 ResetPosition (Ego_r ?ResetPosition@CTCPhysicsBase@@UAEXABVC3DVector@@@Z); TCI 0x3A is TCI_MAPWHO (CTCMapwho, InMapwho bit 0 of +0x50, FableWin ?SetInMap@CTCMapwho@@QAEX_N@Z / ?IsInMap@).
- (w24B) A by-value struct result through a hidden pointer: with a declaration-only callee c2 must assume the result object's address escaped, so later reads of it are copied into temporaries before any intervening call (0x00A1CC30: 664v632, frame 0x34 v 0x20). Only a visible same-TU body of the callee removes the copies -- the signature does not matter (stand-in and PDB signatures give the same bytes). Such a row cannot land before its callee row.
- (w24B) ReadULONG / ReadType are FABLE_FORCEINLINE in engine/CDataInputStream.h now; chunk 733's `do { } while (0)` lever around the header reads of 0x0040BCA0 is no longer needed (same bytes without it).

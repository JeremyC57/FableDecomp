# Chunk 668 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- 2026-11-01 (chunk 668) **A 15-byte `mov eax,[esp+4] ; mov eax,[eax-8] ; mov ecx,[eax] ; mov [esp+4],eax ; jmp [ecx+N]` slot is a DirectShow DECLARE_IUNKNOWN forwarder, not a ??_G.** Slot 0/1/2 of an IUnknown-derived secondary vtable, __stdcall with `this` on the stack. The final overrider is the class whose `sub [esp+4],K ; jmp` thunks match: 0x00A3BD00 = CBaseVideoRenderer::QueryInterface (thunks -4/-0xD4/-0xD8 = the compiler's W3/WNE@/WNI@). The COMDAT lands in the first TU that emits the vtable (CTextureRenderer's, 0x00A3Bxxx), so the address range does not name the class. Emit it by defining the derived class's ctor.
- 2026-11-01 (chunk 668) A slot-0-less destructor reached from two ??_G of a base/derived pair (CRenderManager2D 0x009E16E0, CRenderManager 0x009C3100) is the BASE's implicit dtor: the derived implicit dtor that adds nothing is inlined into its ??_G as the call. No vtable store inside = compiler-generated (0x009C2FD0).
- 2026-11-01 (chunk 668) Real STLport 4.6 vector text decides retail's per-element-type inlining without help. In ~CRenderManager2D, vector<trivial> expands to `if (_M_start) free` and vector<CQuickDrawTriInfo> (two member dtors) stays an out-of-line `??1?$vector@..` call, interleaved in reverse member order (0x009C2FD0).
- 2026-11-01 (chunk 668) `fabs(x - y) < 0.01f` compiles to `fcomp qword` (a double compare); retail's `fcomp dword [pool]` needs `(float)fabs(...)` (0x00B52870, as the landed WorldFrameUpdate).
- 2026-11-01 (chunk 668) Byte-identical twins that differ only in a tail-jump target are named by that target, cross-checked with the caller blocks: FadeRainToTarget -> StartRaining, FadeSnowToTarget -> StartSnowing (0x00B52870 / 0x00B52900). Retail's snow copy really reads the rain strength (+0x5C8); keep the copy-paste.
- 2026-11-01 (chunk 668) A class derived from a CClass model with a trailing `unsigned char Type` starts at the padded size 0x14: a `_pad[0x91 - 0x11]` stand-in puts the dead bit at +0x94 (0x008D7A90 probe 1).
- 2026-11-01 (chunk 668) A loop bound held in ebp with `sar ebp,3 ; test ; jle` and `cmp ; jl` is `long count = v.size(); for (long i = 0; i < count; ++i)`. With ebx/esi/edi/ebp taken, i lives in the `push ecx` slot (0x008D7A90).

- 2026-11-01 (chunk 668) A generated header for a different class with the same name (engine/CBaseObject.h = Lionhead's CBaseObject vs DirectShow's combase.h CBaseObject) still trips vland's SHARED_HEADER_AVAILABLE substring check; say so in a `// Layout:` line (0x00A3BD00).

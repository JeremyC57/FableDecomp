# Pass12 lessons and limits

- A byte match is separate from exact original naming. The three held STLport rows have exact bodies and passing behavior tests, but the original extension configuration was not recovered. Do not infer it from equal code or a donor using a different library.
- Use ordinary inline unless original evidence proves a stronger annotation. Several inherited helper annotations were corrected without losing exact bytes; keep the corrected current selection, not an older ready packet.
- Genuine complete same-file helper bodies can affect caller slots and register knowledge. Their full original inputs, outputs, class access and template signatures still need proof. A partial stand-in is not a substitute.
- Original member access matters to emitted names even when target bytes are unchanged. CResource's five private fields, IVRefCount, CDefPointer's complete original interface, and the final script-base access corrections are recorded in the row/header review packets.
- Keep source/test/grade/header selections bound by hashes. Rebuild against the per-attempt closure rather than a later shared header tree, and use atomic replacement when editing a working copy so cached historical hardlinks stay immutable.
- A smaller byte-length difference is not necessarily a better candidate. Read the complete instruction residue and preserve the closest tested structure.
- Behavior scenario counts are Cartesian input cases, not independent implementations or source-shape attempts. Compiler grade counts also include repairs/restorations; do not inflate distinct-strategy counts with them.

Detailed successful and parked-row lessons remain in each PROBES.md/NAMING_EVIDENCE.md, hdr/CHANGE_NOTES.md, evidence/ summaries and the supplied reference/docs/lessons collection. The selected status table overrides any older status mentioned in those chronological reports.

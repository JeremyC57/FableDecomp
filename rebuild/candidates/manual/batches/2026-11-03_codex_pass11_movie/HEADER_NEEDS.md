## Overlay caveat (fable_string.h)
`fable_string.h` uses `#pragma once` with no include guard. MSVC searches for quoted includes in the directories of the
files already open. So when the overlay copy and the repo copy are both reachable, some TUs include both and fail with
C2011 redefinition. This hits the minimal overlay `hdr/` in 6 landed rows (004317D0, 00430900, 0047A9F0, 0055B040,
00631C60, 00667D30). All 6 pass without the overlay. This is an overlay-mechanism artefact, not a header defect: with a
full mirror (`hdr_full/` = `rebuild/include` plus `hdr/`, which is what a landing produces) all 123 landed includers recheck
clean, and the movie row still matches.

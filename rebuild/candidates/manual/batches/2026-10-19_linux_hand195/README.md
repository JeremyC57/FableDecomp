## Lessons
- A by-value CCharString argument is built in the argument area (`push ecx ; mov ecx,esp`) only when its copy ctor is declared (0053e0c0).
- Two out-of-line calls compared with `==`: VC7.1 here evaluated and spilled the RIGHT operand first, so retail's `cmp eax(second call), ecx(spill)` is `second() == first()` written in that order (0082add0).
- A returned/compared element address kept in a callee-saved register is a named pointer local (`const T* m = &n->value; ... return m;`), it also fixed the loop register allocation of ForEachMessage (0090e2e0, 008ad050).
- `||` chains of constant compares: written inline the first chain's then-block goes to the end of the loop; behind a small inline predicate it stays in place (00a26660).
- `delete task` goes through the out-of-line non-virtual `??_G` when the class has an inline dtor AND an inline class operator delete (the landed 0x00BF8C10 model); with either out of line VC7.1 inlines or calls `??1` + delete (00bf7f70).
- An unused out-of-line getter call (`brush->GetGameArea();`, `GetSplitBranch();`) is just a discarded call statement.

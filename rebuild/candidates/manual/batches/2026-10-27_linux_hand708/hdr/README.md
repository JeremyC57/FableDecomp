# hdr/ -- chunk 708 shared-header corrections

All six headers use the **opt-in** pattern. Each one keeps the existing repo text, byte-for-byte, under `#else // flattened Ego_r layout (the
landed default, unchanged)`. This was checked by a script: each `#else` branch equals the repo body line for line. The new retail class sits
under `#ifdef FABLE_RETAIL_<CLASS>`, so a landed includer that does not define the macro compiles the same text as before. Because no default
path changed, there is no `INCLUDERS_<Class>.txt` and no `--recheck-landed` run.

Each header carries a `// Retail opt-in (chunk 708)` evidence comment and the RETAIL_MARK line
(`GENERATED by ... then hand-corrected to retail`), so gen_class_headers.py keeps the edit.

Overlay use was proven in three ways:
- Without `FABLE_HDR_OVERLAY`, 0x00A66990 and 0x00A66F80 fail to compile (C2600), 0x00A47180 fails to compile (C2433) and 0x00BE2B20 is DIFFER 73v74.
- A deliberate member shift in hdr/engine/CKeyboard.h turned 0x00A66990 DIFFER 73v73. The shift was then removed.
- With the overlay, all four rows are RELOCATION_MATCH.

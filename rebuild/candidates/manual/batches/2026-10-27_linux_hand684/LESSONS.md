# Chunk 684 lessons

## GOTCHAS one-liners
- ImeUi GetImeId 0x00CB28F0: the matching text differs from the public June-2010 SDK in four places forced by the bytes: one `&&` condition over the layout / ImmGetIMEFileNameA / file-name checks (separate early returns make VC7.1 materialise a zero register and duplicate the zeroing tail), a DWORD `dwLang = (DWORD)g_hklCurrent & 0xffff` computed right after the hklPrev store (`mov ebp,eax ; and ebp,0FFFFh` before the first layout compare), the buffer checks folded into one condition, and ImeUiCallback_Free OUTSIDE the lpVerBuffer test (retail frees a null buffer: the Malloc-failure edge `je 0x00CB2AF3` lands on the Free) -- that last one is also what keeps uIndex in edi from the prologue.
- q.py does not apply a source's `// Flags:` line: pass `--flags /GS` (or /Zi) explicitly, or the grade is against the wrong build (GetImeId probe 1 graded 606v662 for that reason).
- A same-TU `static` function gets VC7.1's register convention (uIndex in ebx, no `ret 4`): a retail `__stdcall` static with a stack argument must be modelled with external linkage.
- VC7.1 never caches a file static across calls: retail's `GETLANG()` cached in ebp across ImmGetIMEFileNameA / CompareStringA is a user local, not the macro re-evaluated.
- NVectorMath SSE rows: the broadcast weights are `__declspec(align(16)) float x[4]` with element 0 assigned (`movaps xmm,[local] ; shufps 0`); a scalar aligned float gives a 0x58 frame with the locals on top of the frame, the 16-byte arrays the retail 0x48 frame whose fallback temporaries overlap them (0x00A5B870, 801 bytes, /Zi like the landed 0x00A5BEF0).
- `__restrict` is not a VC7.1 RTM keyword (C4235 "not supported in this product"): never a lever.
- CGraphicInfoFrame::GetTexture texture-family rows (0x00BA9360 / 0x00BA95D0 / 0x00BA9A70): the frame lookup is a per-row `__forceinline` MEMBER inline (a file-static helper with a reference local gives a different touch block); the flags assignment is a ternary in Get2DAlphaMaskTexture (`xor ebx,ebx ; jmp` arm form) but an if-shape in GetBump/GetDiffuse (store 0 first, conditional store 0x11); GetDiffuse's two `preloading = true; return 0` tails merge only with a `bool GetTexture(mipmap, flags, const CTexture*& out)` inline that returns false on the frame-less paths.
- CEngineResourceManager retail layout = the generated header offset - 0x230 (SatRGBATexture +0x2ADC, ZeroRGBATexture +0x2AD4, StipleFadeTexture +0x2AAC); the generated `engine/CEngineResourceManager.h` is not usable for retail offsets (header debt).
- VC7.1 two-pole IIR loops (libpk CDspGain::ApplyRamps 0x00C74510): the compiler enregisters the state[0]-derived running value on the x87 stack and keeps the other in memory in every spelling (rotation orders, yOld temporaries, float[2] / struct states, function scope, inline reference helper, embedded assignment, LICM); retail has the mirror (y0 in a frame slot updated in place, the old y0 carried on the stack into y1) -- lane gap, 29 probes.
- CTCDExperienceOrb::Create(CThing&) 0x0077A890: the out-param `GetTC<T>(T**)` model (landed GiveHeroRenownPoints) forces the component into memory; the HasTC-guarded pointer-returning `GetTC<T>(long)` (OnCollected model) leaves uninitialised locals reading a stale slot as retail; what remains is register allocation (creature ebp v edi) -- 21 probes, lane gap.

## Review at landing
- 0x00C74510: the reloc binding `?ApplyRamps@CDspGain@@QAEXPBM0PAM01HI@Z` comes from the landed callers' `int mode`; the callee reads a byte (`mov al,[esp+30h] ; test al,al`), so the sixth parameter is `bool`. The landed CDspGain::Apply 0x00C74CE0 / Crossfade 0x00C74D30 declare it `int` and matched; respelling to `_N` at landing changes their declaration too (their own bytes pass the int through, so re-grade them with `bool`).
- 0x00C74510 also adds a ninth CDspOps slot (+0x20): a biquad-with-input `(float* dst, const float* src, const float* feedback, const float* feedforward, float* state, unsigned int count)`; name descriptive.
- 0x00BDA150: the landed Allocate* callers (0x00BDA360 / 0x00BDA460 / 0x00BDA560) spell the callee `ProcessDisposalLists` (and one binding `FlushCycle`); respell to the PDB singular `?ProcessDisposalList@CEngineLandscapeMemoryManager@@AAEXXZ` (private).
- 0x0077A890: the landed CThingCreatureBase::OnDie 0x00664300 spells the callee `CreateExperienceOrbs(CThing*)`; the PDB spelling is `?Create@CTCDExperienceOrb@@SIXAAVCThing@@@Z` (static, CThing&).
- 0x00A5B870: reloc binding lacks the NVectorMath namespace.
- 0x00CB28F0 is `/GS` (char szTmp[1024]); 0x00A5B870 is `/Zi` (the return-address copy in the realigned frame, as the landed sibling).

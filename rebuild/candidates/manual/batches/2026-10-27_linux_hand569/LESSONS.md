# Chunk 569 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- Mixed inline / out-of-line `~CScriptThing` in one NScript thread body (0x00E39140): make the dtor `__forceinline` and put `#pragma inline_depth(0)` / `#pragma inline_depth()` around exactly the `return`s at which retail calls 0x004AA840 out of line; the other exits expand it inline.
- NScript "watch" loop that checks the terminate flag first (0x00E39140): `for (;;) { if (IsActiveThreadTerminating()) return; ...; Game->NewScriptFrame(); }` with the found / died exits written as `break` to the function end gives retail's rotated loop and the shared cleanup tail.
- CScriptThing inline wrappers compare as `Data == 0 || Data->IsNull()` / `Data != 0 && Data->IsAlive()` (gives `test al,al`; a bool-returning wrapper built another way gives `cmp al,bl`) (0x00E39140).
- CBasicString / CCharString `operator==(const char*)` and `CScriptThing::GetName` must be `__forceinline` to expand at the call site with the protected static `__fastcall CBasicString<char>::Compare` 0x00411570 (0x00E39140).
- CScriptDef retail offset = Ego_r.pdb offset minus the shrink of the Dinkumware vectors before the member (Ego_r vector 16 bytes, retail STLport 12): WB_LowHealth Ego_r 0xEE4 -> retail 0xE34 (0x00E12B30); AssassinExperience Ego_r 0x418 -> 0x3E4 (0x00E39140).
- Wait-until-health loop (0x00E12B30): a named `CScriptDef* def = pGlobalScriptDef;` re-read at the END of the loop body keeps the def pointer in a callee-saved register across the virtual GetHealth call (re-reading the global in the condition spills it through the `fild`).
- STLport 4.6 `__introsort_loop` written verbatim under `#pragma inline_recursion(on)` (0x00CBD700): VC7.1 expands the recursion five levels deep, only the outer level inlines `__median` and the pivot copy; matched at the first grade.
- libvorbis `_vds_shared_init` (0x00C8F200) is an LTCG-private static (v in EBX, `ret 8`): no /c compile reproduces it -- lane gap, park on sight.
- Matrix builders (0x00BEB6C0 CEngineInternalPrimitiveMeshBase::Calc2DObjectMatrix): writing the rotation through a 12-float `CMatrix3x4::Set(...)` (or member stores) keeps the negated axis values on the x87 stack (`fld ; fchs ; fstp [out]`); a `Set(const C3DVector&...)` fed `-right` temporaries materialises every temporary in the frame. Translation matrices built as locals at the top (`toCentre.SetTranslate(-centre); toPosition.SetTranslate(position);`) give retail's frame (only the position matrix is in memory, -centre stays in registers) and retail's cross-product load order. `x * 0.0f` is never folded (`fmul [0x0122DEDC]`), `x * 1.0f` is.

The AdvanceInCover / TakeCover / OpinionReactionRoot opt-ins wrap the unchanged default class in `#else`, FINISHSTENCIL and
RESERVE_ALLOCATE_AND_COPY wrap one unchanged member line / body in `#else`; every other opt-in only adds lines. `diff repo overlay`
shows no removed line for any of the 22 headers. No opt-in changes a layout: most are declarations; the inline bodies are GetFramesPerSecond, SetGameMap and the forced-inline
operator= (ASSIGN_FORCEINLINE, same text); the three retail-class branches (WIFEUPDATE, ADVANCEINCOVER, TAKECOVER) keep the default's
size (static asserts in the opt-in branch); FINISHSTENCIL retypes one member at the same offset; RESERVE_ALLOCATE_AND_COPY is a body.

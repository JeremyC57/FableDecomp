# NF213 lessons (one line each)
- Under MSVC a quoted include from a repo header searches that header's directory (and its includers') before /I, so an overlay copy of stlport/fable_containers.h is bypassed when a repo header (fable_string.h) includes it first: include the overlaid header directly, first, or the opt-in silently does nothing (0x00563130 push_back copy stayed 50 v 49 until the include order changed).
- The size-pragma scaffolding for a visible noinline callee is not neutral for the caller: VC7.1's caller codegen depends on how the same-TU callee was compiled; it matched for 0x005414A0 but moved registers in 0x006116E0 / 0x007E4B60 (the plain /O2 body matched). Grade the caller with the scaffolding on before trusting it.
- A /Os scaffolding copy can need its own inline budget: /d2inlS12 expands allocator::allocate -> malloc as the owner's FORCEINLINE local model did; the /O2 row body is untouched by /d2inlS.
- Header-based rows emit pick-any copies of every header inline they reach (LowerBound, bitset::test, HasTC, the implicit ~LHHttp2): run a HEAD-v-new defined-symbol diff against reloc_bindings / landed Leaf lines for each port, and prefer an existing declaration opt-in (FABLE_RETAIL_LHHTTP2_DTOR) to a new copy.
- A whole-row port of a dozen local models can match in one form when a header-based sibling row of the same class exists (0x0055FEC0 / 0x00562E70 recipes for 0x00563130).

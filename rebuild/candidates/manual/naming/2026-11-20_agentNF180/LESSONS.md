# NF180 lessons (one line each)
- reloc_bindings.tsv is not a complete census even of distinct spellings: 0x009EF360's stub bound 0x009AB5D0 as _FableHelp_baa30_009ab5d0@4 with no table line; probe (or grep the source of) every REFS row before calling an entry done.
- A "find wrapper" stub labelled CRegion::SetMiniMapRegionExitTextOffsetX (21 bytes, `ret 8`, hidden iterator result) is STLport map::find / set::find; the landed RunCutsceneMacro 0x00CBFB7D already binds the right spelling, so the port is a 3-line explicit instantiation on stlport/fable_map.h with FABLE_RETAIL_STLP_TREE_MFIND_DECL (two rows, first grade each).
- CVectorMap Sort vs Update is decided by the retail bytes: Sort = `mov edx,[esi+4] ; mov ecx,[esi] ; ... call sort ; mov byte [esi+0Dh],0` with no test, Update = the same after `mov al,[esi+0Dh] ; test al,al ; je`. A queue claim of Sort on a body with the Dirty test is wrong (q4959).
- A sort COMDAT that calls __final_insertion_sort out of line needed a new nested declaration-only opt-in (FABLE_RETAIL_STLP_SORT_FINAL_INSERTION_OUTOFLINE) inside FABLE_RETAIL_STLP_SORT_FASTCALL_BODY; the forceinline body otherwise expands it.
- A non-virtual ??_G?$CCountedPointer@V<T>@@@@QAEPAXI@Z stand-in closes with FABLE_RETAIL_CCOUNTEDPOINTER_DTOR_DECL_ONLY plus an anonymous-namespace `delete p;` scaffolding (the 0x00AD79C0 form): first grade, and the destructor stays a call so no new COMDAT body is emitted.
- A row-local header-less container class (CRetailList_CValue_<addr>, CCodeSectionManager) can keep its token while its member types move onto the shared headers: the callee bindings change, the row's own leaf does not, so no self-rename family is needed.
- A visible _M_fill_insert body (FABLE_RETAIL_STLP_VECTOR) gave the resize(1) char temporary its own frame byte (0x0083EEE0); with the declaration alone VC7.1 homed it in the dead argument slot (same size, DIFFER).
- A polymorphic class's ??_G (scalar deleting dtor via the vftable) can only be emitted by a TU that compiles a constructor; when the only inline one (the implicit copy ctor) is defined strongly by another landed row, the ??_G port is a one-definition hold (0x008CED20).

Vendor naming V2 (plan phase 1, step 2), 2026-11-04. Header-first.

METHOD
- Every candidate is compared with the symbol index ($S/plan/idx, symindex2 run covering HEAD after chunk 773). A row is
  accepted only when the graded function keeps the index's masked sha1 (all relocation fields zeroed) and the same
  (target, kind) relocation sequence, and every changed symbol is the decided spelling of its target (gate.py / hdrmig.py /
  rs2.py rule). Then all accepted rows were graded with vland --recheck-landed read-only, 3 batches of <=140 + 1 defmove
  batch (logs/vland_v2_*.log), each with its own LANDVERIFY_WORK; at most 2 at once.
- Header-first: hdrmig.py strips every local block / forward declaration of the header's classes, includes the shared
  header, renames aliases and accepts the row only if every symbol change is the header's own spelling (alias -> name,
  struct U -> class V). Configs: cfg_pkclock*.json (PKCCriticalSection + PKCProtectionInstance), cfg_pksem.json.
- Waves chain through cur/<addr>.cpp (reg.py), so a row touched by several components carries all of them.

# NF195 lessons (one line each)
- A transformer DIFFER under one MFIND mode is worth one regrade under the other: 0x006E9E40 / 0x006EDC50 matched with MFIND_NOINLINE after NF185's MFIND_DECL drafts differed.
- A test that links the row and calls a declared-only member template must make its own TU emit the body (call the const find there) and supply any out-of-line library helper the inserts reach (_Rb_global<bool>::_Rebalance).
- A noinline header body that matches the row can still fail the pick-any rule: compare the emitted COMDAT with the owner's bytes before keeping it; a declaration-only opt-in is the fallback (RESIZE_VALUE_DECL_ONLY).
- Generated engine headers are pack(1): a nested record with tail padding comes out short (CEmbeddedHighlight 0x11 v Ego_r 0x14); a stride diff of 3 bytes is the sign.
- A by-value inline getter (GetPDef()) adds the refcount pair; a tiny out-of-line accessor reads the member in place.
- reloc_bindings lists every symbol bound at an address, one witness each. It narrows a 1000-row census but does not settle it; see the probe lesson below.
- engine headers that use FABLE_STATIC_ASSERT need rebuild_abi.h first; fable_compiler.h alone does not define it.
- Never filter a pick-any run (`grep -v DIFF` hides a real owner). Rebuild the object from the final source and match every new symbol exactly against every landed Leaf and reloc_bindings target.
- reloc_bindings keeps one witness per symbol, so it cannot prove that no other row binds an address under another spelling. Probe the REFS rows before calling an entry done-already.

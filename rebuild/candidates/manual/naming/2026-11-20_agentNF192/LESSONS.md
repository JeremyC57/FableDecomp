# NF192 lessons (one line each)
- grep census output piped through head can drop the one hit that matters (libpk/CPooledResource.h was line 11): grep rebuild/include separately before treating a class as header-less.
- Keep the /Od preflight and the /O2 grades in separate Bash calls: a loop after a failed preflight burns one failing compile per row.
- Anonymous-namespace data statics (Ego_d PUB32 `?x@?A0x...@@`) are respelled by declaring the extern inside `namespace { }`; the hash is per TU path and the gate collapses it.
- A template-instance pick-any COMDAT with no owner symbol (owner rows on free-function stand-ins) can be checked directly against the retail bytes (tools/cmpretail.py: relocation fields zeroed) instead of compiling the owner row.
- NF188-era notes can be outdated by later header growth: engine/CIEngine.h already had slot 26 (AddChildPrimitive), so 0x00AFF0A0 ported in 2 forms.
- When a header method is declared but the TU needs the body expanded (C3DMeshFileMapChunk(EMaterialMapType)), an add-only inline opt-in with both PDB addresses is the cheap route.

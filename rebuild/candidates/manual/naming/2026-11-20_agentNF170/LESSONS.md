# NF170 lessons (one line each)
- reloc_bindings.tsv is NOT a complete spelling census: q4983's `CThingSearchTools_Calls` spelling (4 rows) is absent from it. Probe every REFS row (tools/probe.py) before calling an entry done-already.
- The Fable.exe absolute-dword scan gives false REFS hits inside rel32 operands (0x0059A238: `call 0x0099EBF0` encodes C0 45 40 00 = 0x004045C0). A probed row that binds nothing at the target is such a hit: check the bytes before recording a gap.
- GetSubDef<T> binder ports: drop the local def / CDefPointer / CDefClassBase models and their stand-in body, include the def's header + engine/CDefClassBase_GetSubDef.h with FABLE_RETAIL_CDEFCLASSBASE_GETSUBDEF_NOINLINE (+ CCLASS, CRESOURCELIST, CDEFINITIONMANAGER, CDEFSTRINGTABLE, CCHARSTRING): 14 of 14 rows graded RELOCATION_MATCH first form, including the CDefOut / CDefHolder ("def read once from the out slot") shapes.
- A def without an inline StatGetTypeName in its header (CCombatAbilityStrafeDef, CCombatAbilityUseProjectileWeaponDef) needs a member-specific opt-in: FableWin.pdb has ?StatGetTypeName@<T>@@SI?AVCCharString@@XZ and the owner body pushes the literal (two sources).
- When binders move onto the header body they emit the GetSubDef<T> COMDAT pick-any; an owner row that defines it as a strong explicit specialization then gives LNK2005. Move the owner to the nf135 address-helper scaffolding in the same hand-back and link-test owner + binders with LINK= cleared.
- Search-tool template owners (GetPBestThing / GetAllLeafThings) on the header bodies needed the nested shapes the retail instance shows: BESTTHING_BODY_NULLTEST + CTHING_SCANINCLUSION_ISALIVE (`mov cl,al ; not cl ; test cl,1`), LEAFBODY_CASTARG (argument homed just before push_back). Read the DIFFER side by side and pick the existing nested opt-in; one extra grade each.
- A descriptive local enum in a Transfer<T> instance is replaced by the header that defines the PDB enum (CQ_SunnyvaleMasterData.h, CFeatDef.h): only the instance's own callees (TransferBinaryIn, the TransferableComponent vtable) respell, and the exe scan shows only the self row references them.
- When moving `#define` lines to the top of a row, move only the new ones: a later `#define FABLE_RETAIL_CTCBASE` moved by a too-wide regex still matched but changed the include semantics (caught and restored, one extra grade).

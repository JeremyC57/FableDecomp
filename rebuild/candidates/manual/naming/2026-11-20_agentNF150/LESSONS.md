# NF150 lessons (one line each)
- Take the binder census from HEAD objects (vland of every REFS row + pairs.py PAIRS_OUT) before editing: WORKLIST claimed two wrong binders that were already right, and the one real wrong binder (0x00BB8090) was not in it.
- A self rename onto a private inline header member collides (LNK2005) with includers that emit the same COMDAT; a private member cannot be named from the nf86/nf88 derived-class helper, but an explicit instantiation with the member as template argument (access unchecked) emits it pick-any.
- When transforming a row by slicing its header-comment lines, check the slice ends before code: a surviving `#define X XLayout` silently renamed the class (the q.py "leaf matches no symbol" warning caught it).
- The CRenderStateManager setters reproduce the stand-in SetState byte for byte except the known bookmark test/or tie; the existing DESIRED / BOOKMARK / ADDSTATE_DIRTY fitted opt-ins did not move it in 0x00BB8090 (the HEAD fix was a named local of the capture mask).
- Queue lines copied from mixed-format NAME_FIXES can have shifted columns (q6237 / q6297): read the correct symbol from the PDB name sets, not from the column position.

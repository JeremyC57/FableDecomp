Plan phase 2, wave "leaf" (2026-11-04): LEAFGUESS cleanup. Comment-only respells of `// Leaf:` lines, proven by grade.

INPUT
- The 3,873 LEAFGUESS rows of the symbol index after bringing it to HEAD (symindex2.py --all, NJ=6; post/LEAFGUESS.tsv).
  A LEAFGUESS row's `// Leaf:` names no symbol in its object, so vland (verify_and_land.obj_text) grades the largest function.

METHOD (scripts/leafplan.py, scripts/wave.py)
- The graded function is found the way vland finds it: the object's .text blocks that start at offset 0; no leaf match ->
  the largest.  The new `// Leaf:` is that function's full mangled symbol, so vland's substring match now selects the
  same function by name (it is also still the largest, so the selection cannot move).  Anonymous-namespace symbols
  (`?A0x<hash>`, 5 rows) take the prefix up to `?A0x`: the hash follows the compile path, so a full leaf would miss again
  in vland's work directory.
- Proof that the graded function did not move: gate.py PASS on all 3,680 (index length + masked sha1 + relocation targets
  identical; the defined symbol identical up to the ?A0x path hash), the new leaf names a symbol of the object (3,680/3,680),
  and vland --recheck-landed read-only on the landed source (logs/vland_leafB*.log) and on the respelled source
  (logs/vland_leafA*.log): same parity on every row, no leaf warning after.  13 batches of <= 300, at most 3 at once.
- No symbol, byte or relocation changes, so no BINDINGS / CALLERS / RENAMES lines and no queue lines closed.

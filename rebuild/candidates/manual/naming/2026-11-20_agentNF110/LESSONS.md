# NF110 lessons (one line each)
- When one landed row defines a family template body in its own source and matches (0x009871C0's EGOD GetPFirstThingInRoughArea), grade that body in-row on a sibling first (1 grade): it matched 0x007FCEF0, and moved verbatim into the shared header as an opt-in it matched all 8 instances first form, where the older fitted FIRSTROUGH_BODY never did.
- Before counting a DIFFER as a failed body form, check the instance's prerequisites: T's StatGetTypeFlags define (mask 0 gives `xor cl,cl` and shifts register pressure: 0x009147E0's whole LayerInfo-pointer residue vanished with it) and whether retail expands the filter (no filter call in the callee list = an inline body is needed).
- A filter that retail expands may already have its inline body in the landed TU-mate caller (0x00914650 defines ScaresBirds::operator() for itself): reuse that text verbatim and the TU-mate's define set.
- The "pointer-taking filter binder" idea for GetPBest rows was a stand-in artefact: both PDBs spell every filter operator() by const reference; the shared CFilter_Bind2 / Bind3 headers compile them unchanged.
- A filter callee whose catalog label disagrees with the instance's PDB filter type is usually mislabelled, not the instance: check the callee body's member offsets against the T class layout (0x006A7F30 reads +0xE8 = CThingTrackNode::TrackName, so it is HasTrackName, not HasScriptData).
- Engine/TargetingPlayerSupport.h (the only CFilter_Bind5) needs FABLE_RETAIL_CTCTARGETINGPLAYER_UPDATE_LIST and its whole include chain: copy a landed UPDATE_LIST row's define / include set (0x00809A70) and swap the body defines, rather than adding the macro to a minimal set (C2079 in CTCMapwho.h).
- A cheap existing-split close: a caller whose local model declares the callee template non-const can take `const` in place (0x007FEAF0, one grade, no byte change).

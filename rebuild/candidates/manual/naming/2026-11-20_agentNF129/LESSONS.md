# NF129 lessons
- Probe every REFS row first (grade HEAD, record the symbol bound at the target). Most PRIORITY entries were 90%+ already bound;
  the work is the 1-5 stand-in binders, and the probe table makes shrink-only vs new-spelling a lookup.
- A shared header's default branch can be a flat donor layout without the member functions (CRenderManagerCore.h): when a call
  will not resolve, opt into FABLE_RETAIL_<CLASS> before reaching for a local model.
- fable_string.h member opt-ins (_SPRINTF, operator+=) sit inside the FABLE_RETAIL_CCHARSTRING branch; define both.
- A virtual added to a derived local model whose non-polymorphic base sits at +4 moves the base; put the virtual in the base model.
- CCountedPointer<T> members: an explicit instantiation of the shared template replaces the per-row stand-ins byte-for-byte.
- A `released` lock owner file may be taken over: the claim script should check the owner text, not only mkdir.
- When a self rename drops a stand-in class, check whether the landed test declares that class and links the row: if so the test
  must be rewritten against the shared header (vland LINK_FAIL otherwise).
- Keep compiles strictly serial: a grade started while a background vland ran is a rule slip even when it finishes cleanly.

# NF117 lessons (one line each)
- Porting a binder onto a header that already declares a callee under its PDB name renames that callee for the address: the callee's self row has to move in the same hand-back (claim it, respell in place), or the port creates the split it was meant to heal.
- A catalog "Rumble" name on a UI def reader was a label guess: the PDB name set has GetDataFromDef and the body copies a def field into CClickable::InputDelay (+0x18C); the def ids look like CUIDef's Action fields under a 0x1C shift, but retail's def layout is unproven. Check the PDB member set before trusting thematic names.
- Vtable spellings come free from the shared hierarchy: a ctor on engine/<Class>.h binds the same ??_7...6B<base>@1@@ set as its dtor row with no extra work (form 1, 103 bytes, RELOCATION_MATCH).
- Regenerate HEAD objects in a separate S (pS_head) before grading a new form, so the old relocation symbols for RENAMES section 2 are not overwritten.

# NF205 lessons (one line each)
- A script entity Main that only acquires a handle and waits on a parent flag ports in one form onto the shared headers: add the nested entity class as a declaration opt-in in the quest header (the JACKOFBLADES shape) and read the flag by its PDB member name (0x00D2D060: NativeParent +0x81 = JackLeaves).
- Before moving a binder onto a PDB callee spelling, compile the callee's self row: if it still defines a stand-in, the move creates a split; port the self row in the same hand-back (0x00994670 for 0x009FD160).
- A self rename whose only landed caller already binds the PDB spelling is a one-row job: check the reloc_bindings line for the address first (q11815, q11816, q11862 were all of this kind).
- A shared-header STLport include can newly define a pick-any template body (vector::_M_insert_overflow) that differs from the owner row: diff the defined symbols against the HEAD object and use the header's _DECL_ONLY opt-in.
- cmpbody takes one symbol name; when the owner row defines a stand-in name, compare by hand with two names (tools/cmp2.py) and record what the owner binds.
- A protected static can be referenced for the nf86 scaffolding from an out-of-line static member of an anonymous-namespace derived class; an in-class inline helper or a global function pointer is not needed.
- The ??_G a TU emits depends on whether operator delete is inline there: two landed TUs can emit different ??_G bodies for one class (0x0122A9A0 v 0x009A0AE0).

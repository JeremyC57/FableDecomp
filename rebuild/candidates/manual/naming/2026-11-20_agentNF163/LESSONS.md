# NF163 lessons (one line each)
- A HEAD control compile (with a Leaf line added) gives the old binding list and the defined-symbol baseline in one grade; the port then diffs to an identical symbol set.
- Check what the HEAD object actually emits before calling a leaf change a self rename: a non-virtual-looking `void Main();` in a local model of a CScriptBase subclass already mangles UAE.
- When a header forward-declares only some nested entity classes, add the missing definitions as one overlay opt-in rather than defining them in the row.
- A July row whose Leaf line is a bare name (`GivenTeddy`) can still be ported in one grade when the header already has the opt-in for its class.

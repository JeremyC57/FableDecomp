Vendor naming pass, wave V1 (2026-11-04): libpk / GameCODA / DirectShow strmbase
================================================================================
Repo untouched (no git). Everything is in this dir; overlay graded read-only with vland --recheck-landed
(FABLE_HDR_OVERLAY=overlay/rebuild/include, LANDVERIFY_WORK=vw_0 / vw_1; logs/recheck_0.log, logs/recheck_1.log).

METHOD
1. Spellings in use TODAY, not the first-binder table: every landed row in 0xC08AE0..0xCB8000 plus every landed row whose retail bytes
   call into the range or that reloc_bindings lists as a binder (5,286 rows) was compiled (scripts/symscan.py, scripts/defsyms.py;
   logs/scan_base.tsv = caller relocation pairs, logs/defs_base.tsv = the symbol each definer emits). reloc_bindings.tsv records only
   the first binder of a symbol, so its "counts" are all 1 and it misses respells done since (e.g. 00c1a230 already emits
   ?Wait@PKCSemaphore@@QAEXXZ although the table still holds ?Wait@CEvent_00c1a230). logs/SPELL.tsv = per-target spellings.
2. DECISIONS_V1.tsv (scripts/decide.py), per in-scope target emitted under >1 spelling (definer + callers), plus proven targets:
   proven (proven.tsv: strmbase vtable slot + BaseClasses declaration order; BaseClasses-declared Class::Method agreeing with the
   catalog, signature keys checked) > rule 1b (a spelling whose class is the body's __FILE__ class, one source) > rule 2 the landed
   definer's symbol > rule 3 the most-used caller spelling (ties: label agreement, __FILE__ class, length).
   Spellings rejected as winners: free fastcall/class-pointer stand-ins for members, generic classes (T, S, Obj...), engine PDB class
   names (Ego_r/FableWin name sets) or gameplay vocabulary on an audio-library function (propagated labels: CCreatureActionHeroJump,
   CTCHeroExperience, CParticleMorphs, CWorld...), and any winner already decided for / defined at / bound to another address
   (54 CONFLICT rows -> deferred). Held rows from hand769/hand770 (coordinator note) are the 6 HELD rows at the end of the file.
3. Respell (scripts/respell.py): align the demangled loser and winner, derive identifier renames (class names everywhere, method
   names in code / the Leaf line only), recompile, accept only if the graded block's bytes are identical, every changed relocation
   now names its target's decided winner, and the row's own symbol is unchanged or becomes its own decided winner. Each respelled
   source gets a `// Vendor naming wave V1 (one address, one name): 0x... <new> (was <old>)` line after its Leaf line.
4. strmbase definers (22, hand): rewritten on the shared engine/CBaseVideoRenderer.h (retail branch) with the BaseClasses source
   bodies (DX9-era SDK: GetPinCount returns 1). Overlay header: overlay/rebuild/include/engine/CBaseVideoRenderer.h adds the
   renbase.h overrides CBaseRenderer::GetPinCount/GetPin, CBaseVideoRenderer::OnRenderStart/OnRenderEnd/OnWaitStart/OnWaitEnd/
   OnStartStreaming/OnStopStreaming/ScheduleSample (overrides of existing slots: no layout or vtable change) and the non-virtual
   CBaseRenderer::ResetEndOfStreamTimer. Its one landed includer 00ca5850 regraded MATCH PASS with the overlay.
   Files renamed to <Class>_<Method>_<addr>.cpp (RENAMES.tsv; tests copied unchanged under the new names).

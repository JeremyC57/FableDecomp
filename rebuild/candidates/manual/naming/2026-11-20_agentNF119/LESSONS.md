# NF119 lessons (one line each)
- C2785 (explicit instantiation of a function template whose return type is a dependent `iterator_traits<I>::difference_type`) is not fixed by explicit template arguments either; the nf86 / nf88 address-taking scaffolding (`return &std::count_if<I, P>;` in an anonymous-namespace helper) emits the same COMDAT in one grade (0x0065F6A6).
- The same scaffolding emits an in-class (implicitly inline) shared-header member as the row's own function: a pointer-to-member return `long (C::*F())(args) { return &C::M; }` (0x0075F980 AppendControlPoint).
- callers.py lists one witness per spelling (reloc_bindings); to classify a REFS list, run one HEAD recheck over all of it and dump each object's bindings with reloc_identity.check() (work/probe.sh): 36 rows in two runs, no guessing.
- mkpay.py takes flags from build_candidates CompilerFlags only: a row with a new `// Flags:` line needs them added to the payload by hand (work/vl.sh does it), or vland grades it without them.
- A local stand-in callee name can hide the real catalog callee with a different-looking signature: CTCSound::PlaySound(sound, 0, flags, 0, -1) was CTCSoundPlayer::PlayAttachedCriteria(name, false, loop, false, -1); read the sibling row (0x0079CE80) before modelling.
- Byte-twin rows can share one propagated catalog name and one self leaf (0x0078EBF0 / 0x007940F0 both "CTCDivineWrath::PlaySoundW"): before a self rename, diff the twin's source and settle each address by its block position and the twin's own bindings (the CTCUnholyPower ctor binds 0x007940F0).
- For a scaffolded header body, prefer the declaration-only opt-in for its callees (VECTOR_OVERFLOW_DECL_ONLY): the OUTOFLINE form also matched but made the object define the callee's body as a pick-any COMDAT.

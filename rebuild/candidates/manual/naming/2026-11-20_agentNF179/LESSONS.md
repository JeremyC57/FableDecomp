# NF179 lessons (one line each)
- A pick-any COMDAT check is cheap: tools/comdat.py parses the COFF section table and compares masked bytes per symbol across objects; run it against every landed row that names the type before calling a new instantiation safe.
- binds.py (reloc_identity.check) prints nothing for multi-block TUs (RELOC_UNCHECKED); read those rows' objdump -t symbol table instead of concluding "no binding".
- CPersistTraits.h member specialisations need engine/CDataOutputStream.h (FABLE_RETAIL_CDATAOUTPUTSTREAM) included first, or TransferBinaryOut fails C2027.
- A local stand-in row on a UI list global usually carries a second stand-in for the list's own methods (clear 0x004855A3); census every callee it would move before promising a "mechanical" port.
- A propagated label can leave several rows defining the same class::method under a non-virtual spelling at the wrong addresses; when a census turns up a QAE twin of a UAE target, list every definer (grep the Leaf lines) for NAME_FIXES even if nothing clashes at link.
- A local-model row can often reach the PDB callee spelling by redeclaring just that member in the local model (access + return type) and changing `->` to `.`; check with symdiff that the defined symbols are unchanged.

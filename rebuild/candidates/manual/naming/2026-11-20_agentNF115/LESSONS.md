# NF115 lessons (one line each)
- A PRIORITY "self leaf differs" can be only a truncated `// Leaf:` prefix (0x006724B0): grade and list the object's symbols before re-authoring.
- Check a posed STLport mangled name against retail's `ret N` before applying it: q5218's posed __unique_copy dropped the tag parameter (ret 0Ch proves five).
- A caller whose retail TU saw a template body (pick-any COMDAT) cannot get that visibility from a stand-in body under the real name: the stand-in COMDAT could win the link for every caller. Port or block (0x0090C1A0).
- VC7.1 rejects an explicit instantiation whose return type is a dependent `iterator_traits<I>::difference_type` (C2785); give explicit template arguments or a header body opt-in (0x0065F6A6, 3 forms lost).
- Copying a landed row's whole preamble brings inert FABLE_RETAIL_* defines along; check every macro resolves before hand-back.
- A method that the flattened generated header lacks can get a declaration-only FLAT_* opt-in (NF83 shape) so stand-in casts move onto the shared class (0x00936BA0, 0x00937D20, 0x0065C781).

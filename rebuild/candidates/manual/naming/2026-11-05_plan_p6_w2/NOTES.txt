     the end-or-greater choice as a conditional expression, the store through the out pointer). The one-argument GetTC<T>(T**) /
     PeekTC<T>(T**) of the PDB forward to it (T::StatGetInterfaceType()). Measured: over the first 140 migrated rows the `if`
     re-assignment form passes 106, the conditional-expression form 115 (a superset: 0x004BFB40 loads the component straight into

2. Rows (tools/hdrmig6.py, the migration rewriter; every rule is in its header comment): the local `class CThing {...}` model and the
   closure models the header brings (CClass, CBaseObject, CBaseClass, CCharString, CWideString, CDefPointer, CDefPointeeBase,
   CVectorMap, CKeyPairCompareLess, CArray, CIVCountedPointeeBase, CResource, the local ETCInterfaceType enum, CInterfaceMap) replaced
   by `#include "engine/CThing.h"` with the FABLE_RETAIL_CTHING* opt-ins the row's members need; the stand-in lookups respelled to the
   header's members (GetInterface*(&v, N) / GetTC(N, &v) -> GetTC(TCI_X, &v) or PeekTC(TCI_X, &v); GetTC<T>(N) returning T* ->
   ((T*)&x->GetTC(TCI_X)); the zeroed-out-pointer wrapper `T* GetTC<T>(N)` -> `T* v = 0; x->GetTC(TCI_X, &v);`; HasTC / HasInterface(N)
   and raw UsingComponents word tests -> HasTC(TCI_X); interface numbers -> the Ego_r enumerators of engine/ETCInterfaceType.h, local
   enumerators mapped by value); member reads by retail offset -> the header's accessors (+0x10 CClass::GetType(), +0x18 GetUniqueID(),
   +0x60 GetPhysicsTC(), +0x64 GetTCGraphicAppearance(), +0x6C GetTypeFlags(), +0x8C GetDefGlobalIndex(), +0x8E GetCurrentMapNumber(),
   +0x90 GetPlayerNumber(), +0x91 bit 0 IsDead() and the STATEACCESS flag accessors); inside CThing's own methods the members take the
   header's names. The lookup's const-ness follows the index: a row binding only 0x004365B0 (LowerBound const) spells PeekTC, only
   0x0040F020 GetTC (one target, one spelling; the out variable of a PeekTC becomes `const T*`).
   Stand-in respells in the same rows: the physics component stand-in -> CTCPhysicsBase (42 rows), the driver stand-in -> CTCDriverBase
   (4), a global local CTCGraphicAppearance -> namespace NGraphicAppearance (97; the header's GetTCGraphicAppearance returns that type),
   `enum { ThingTypeMask = N }` -> static StatGetTypeFlags() (8, FABLE_RETAIL_CTHING_STATTYPEFLAGS), a local GetPlayer declared at
   0x004C7A10 -> PeekPlayer (2). A derived local stand-in `class D : public CThing { unsigned char _pad[N]; ... }` is re-based on the
   header (members below 0x98 are CThing's own, read through the accessors); a local class derived from a removed closure model keeps
   its retail offsets (the leading pad re-counted from the header's size: CBaseObject 0x8, CClass 0x14, CBaseClass 0x4,
   CDefPointeeBase 0x1c, CIVCountedPointeeBase 0x8, CResource 0x1c). A removed CCharString / CWideString model asks for
   FABLE_RETAIL_CCHARSTRING / FABLE_RETAIL_CWIDESTRING (fable_string.h keeps the retail member sets behind them); a row's own
   FABLE_RETAIL_* defines of the closure headers (STLport, strings, CVectorMap, CDefPointer, CClass) are hoisted above the include.
   `// Leaf:` lines: 725 rows had none; the gate and vland grade the largest function of the object, which with the header can be an
   out-of-line copy of a template instance VC7.1 emits beside the expansion (e.g. 0x00435000: the 112-byte ??$PeekTC@... COMDAT next to
   the 98-byte GiveHeroGold); the index's symbol for the row (the function the landed object defines) is written as the Leaf line.
   One Leaf line is corrected (IBE -> QBE mangling only; 0x00435070).

# agentFAM03 header overlay

Full copies of the CURRENT repo headers with `#ifdef FABLE_RETAIL_<HEADER>_VSLOTS` additions only (default path unchanged).
Each block declares, inside the class, the retail virtuals the existing declaration lacks (declaration only, no layout change).
Where the active class models the vptr as a data member (`void* __vftable`, generated flat headers) that member is put under
`#ifndef ..._VSLOTS` (the declared virtuals give the same vptr at +0; the offsetof assert on it is guarded the same way).
Grade with `FABLE_HDR_OVERLAY=$S/w22/agentFAM03/hdr`. Slot order in the block is the retail slot order of the declared methods.

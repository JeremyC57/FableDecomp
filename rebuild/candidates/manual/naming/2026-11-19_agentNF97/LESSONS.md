# NF97 lessons (one line each)
- A row-local `FABLE_FORCEINLINE` reader helper (`ReadLong() { long v; GetData(4, &v); return v; }`) is not always removable: rewriting it as a direct `GetData(4, &local)` matched 3 of 9 rows (the bool reads) and DIFFERed in 6. The FableWin.pdb typed readers (GetSLONG / GetUBYTE / GetUWORD / GetFloat) as plain header inlines matched all 6 in one grade: try the PDB's inline accessor before a direct call.
- A shared-header opt-in can sit inside another opt-in block (CTCPerceiveThing.h `_CANSEEORSMELL` is inside `_AWARENESS`): a C2039 "not a member" after defining the opt-in means checking the `#if` nesting (awk depth listing), not adding a second declaration.
- A test that must stop modelling a shared-header class can usually link the row instead: include the same headers with the row's opt-ins, define only the out-of-line callees the row binds (here the CIntelligentPointer copy and ~CBaseIntelligentPointer, or GetData), and reach private members through raw storage at the retail offsets.
- A row whose callee lives in an anonymous namespace cannot be linked by its test (the ?A0x hash is per TU); keep a self-contained model there, on the shared headers.
- Check the catalog PassPattern of every held test before grading: NF95's 0x0065F0FA test printed `0065f0fa_TEST PASS` where the catalog says ONCREATE_BUYHOUSE_OK.
- A local base model that needed a forced inline (0x007554C0) can become a plain shared-header inline once the containers are members of the derived class as in the PDB layout: the port matched on the first grade.

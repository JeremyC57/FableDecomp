# NF130 lessons (one line each)
- A one-definition fix for a header inline whose owner row defined it strongly over local models: move the owner onto the header and have it return the member's address (`&Class::Member`) from an anonymous-namespace function. That grades first time; run the control link first so the "after" link proves something.
- A HEAD row's comment naming a virtual slot can be wrong (slot 79 "GetMaxJoggingSpeed" was GetMaxWalkingSpeed). When a header port differs only in a vtable displacement, take the header's slot order and the derived classes' slot lists as the evidence.
- A sibling agent's landing can reach the repo working tree mid-session. Before the final recheck, cmp every overlay copy and orig/ against the repo, and drop the copies that are now byte-equal.

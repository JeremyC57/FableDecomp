# NF103 lessons (one line each)
- A data respell inside a row's EXISTING local class model (statics added to the local `class CThingSearchTools`) is a scriptable in-place form: 48 rows, one transformer, two payloads, all RELOCATION_MATCH PASS first time.
- For rows that use a stand-in class but include the shared header's generated branch, a declarations-only opt-in on that branch (statics) respells them without a port: 26 rows in one payload.
- A header body respell needs a cpp -P gate of every includer AND their tests: 0x00435530's test defined the header's retired stand-ins (TCC_FAIL), found only by the recheck of the 17 changed users.
- Never edit an overlay header while a vland payload that uses it is running; rerun the affected rows in the final recheck.
- The explicit-instantiation port of a CThingSearchTools_Calls row onto its landed twin's define set (0x00518900 on 0x005185F0's) matched in one form; the self leaf then equals what the caller already binds (callers.py), narrowing a split.
- absrefs.py maps a reference to the preceding catalog row even past its length: compare the offset with the row length before calling it a binder (7 of 8 "other" hits were gaps).
- grep a marker that is unique to this round when classifying rows (`q11463` also appears in NF100's notes).

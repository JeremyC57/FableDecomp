# NF80 header overlay (round 7, land1117fu: q10763 / q10920 / q10923 / q10931 / q10939 / q10943)

Every file is a copy of the current repo header with `#ifdef` opt-ins added; the base copies are in `../orig/` (same relative
paths) and were cmp-identical to `rebuild/include/` at hand-back. All macro names are new and member-specific; no existing line was
changed or removed. The additions are new `#if` blocks; some sit inside an existing opt-in block (fable_string.h `_FORCEINLINE_LESS`
inside `FABLE_RETAIL_CCHARSTRING_LESS_INLINE`, CTCBase.h `_REGISTRY_LOOKUP` inside `FABLE_RETAIL_CTCBASE_REGISTRY`, the
CWideString `_TOCHARSTRING_BODY` arms inside `FABLE_RETAIL_CWIDESTRING`), so they only take effect when both are defined. With none of the new macros defined each header is token-identical to the repo text: `../tokid.log` preprocesses
35 landed includers (4 per header; fable_string.h with CCHARSTRING + LESS_INLINE users 0x004ABC70 / 0x004BB200, the
FABLE_RETAIL_CWIDESTRING user 0x009A8170 and 0x004B3CE0) with and without the overlay (`cpp -P -I-`, so each quoted include
resolves as it will after the merge) and every pair is IDENTICAL. `../tokid.sh` reruns it.

# NF80 lessons (one line each)
- A header body opt-in for a COMDAT callee (BODY = inline noinline, DEFINE in the self row) can replace a row-local copy in one grade per row; write the body to match the self row first, then grade the BODY-only users.
- reloc_bindings.tsv keeps one caller per spelling: grep the sources for the stand-in's declaration to find every binder (0x00686F10 was hidden that way). Better: nftools/callers.py <target> plus a compile of each calling row (work/cscan.sh) gives the exact binding of every caller; the source grep found 9 _Lbound rows where the compile found 11.
- An overlay of a ROOT header is shadowed by any repo root header that includes it from the same directory (C2011 redefinitions): add an unchanged pass-through copy of that includer to the overlay, and prove token identity with `cpp -P -I-` so includes resolve as after the merge.
- STLport tree helpers (insert_unique, _M_find, _M_lower_bound, _M_insert, map::operator[]) port in one grade as explicit instantiations on fable_map.h; copy the opt-in set of a landed sibling on the same tree shape (0x009EFB80, 0x009EF750, 0x00579114, 0x004B3CE0).
- A const component lookup in retail (the const CVectorMap::LowerBound 0x004365B0) means the source used CThing::PeekTC, not GetTC: check the callee's own leaf against the new binding, not only the grade.
- In a /Os algorithm TU the header's plain inline comparator and CCharString::operator< are called out of line; a per-TU FORCEINLINE opt-in restores retail's expansion.
- A Sizeof body that is one expression lets VC7.1 evaluate the call first; retail's local-sum order (array part, then the pointer test) came from a two-statement body.
- Probe the old row once with the full relocation list saved (g.sh truncates at 40 lines) before grading the new version, so section 2 pairs both from real objects.
- A one-definition header body for a template member: write it as a template member definition and explicitly instantiate it in the self row. An explicit specialisation that is `inline` in includers and ordinary in the self row (BODY/_DEFINE) grades fine but under /Gy gives a nodup COMDAT in the self row and pick-any ones elsewhere: LNK2005 when linked (check with comdat.py and a link with `LINK=` cleared; env.sh sets LINK=bufferoverflowu.lib, which hides the real error behind LNK1181).

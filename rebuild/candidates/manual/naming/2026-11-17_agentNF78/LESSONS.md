# NF78 lessons (one line each)
- An entity-script TU with a local GameCalls / CThingManager_Calls interface ports in one grade: delete the forward block, the typedefs and the interface; define FABLE_RETAIL_NSCRIPT before engine/CGameScriptInterface.h; declare `extern CGameScriptInterfaceBase* pDSTGame`; type Game as CGameScriptInterfaceBase*; and copy the enum enumerators (EScriptAIPriority) from a landed script row.
- The shared GFSerialiseMapBinaryIn body (engine/CPersistTraits.h) fits more instances than its comment lists. Add TREE_MERASE_NOINLINE where retail calls _M_erase from the inline clear. A reader that must stay a call but be visible to c2 (frame sharing) needs a noinline header body. Declare explicit traits specialisations so that BINARYIN_BODY is not instantiated for them.
- A map copy constructor COMDAT whose tree copy constructor VC7.1 will not inline under any /d2inlS budget needs FABLE_FORCEINLINE on the tree copy constructor (preference 3). The budget flag alone did nothing (S22 and S60).
- Read reloc_bindings.tsv lines for a binder as possibly stale: 0x00570332 already bound ReleaseData. Grading the unmodified row with xref2 settles it in one grade.
- Grade a legacy July row unmodified before editing it. 0x0081EE60 is DIFFER in this lane on its own, so no respell there can be verified.
- When a binder's protected-access fix is done through a shared legacy header opt-in, rewrite any test that links a stub of the same member with the same define (0x0063A970: LINK_FAIL until then).
- The two-view-CScriptThing residue (an inline argument copy but an out-of-line member copy) survives a full port onto the shared headers. A declared copy constructor, an implicit copy and inline_depth(1) each fail differently. It is a mechanism question, not a naming one.

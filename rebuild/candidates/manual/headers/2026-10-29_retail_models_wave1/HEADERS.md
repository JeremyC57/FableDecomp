# Wave 1 class-model migration: shared headers (2026-10-29)

All paths are under `rebuild/include/engine/` in the worktree `$S/mig1/repo`. Every header below compiles under VC7.1
(the lane's `cl` with the verifier flags) and under `g++ -m32 -w -std=c++98 -fsyntax-only` (probe sources:
`$S/mig1/work/t/g_all.cpp`, `g_cgsi2.cpp`, `g_esb.cpp`). The vtable probes compile a derived class and compare the
emitted vtable's relocation symbols, slot by slot, with the retail slot names (`scripts/vtprobe.py`). Results:

| probe | slots | result |
|---|---|---|
| CGameScriptInterfaceBase via `probe_cgsi.cpp` (local derived) | 918 | 917 match; slot 308 is the documented enum stand-in |
| CGameScriptInterface (header retail branch) via `probe_cgsi2.cpp` | 918 | 917 match; slot 308 the same stand-in |
| CScriptThing via `probe_st.cpp` | 79 | 78/78 named slots match (slot 0 is the deleting dtor, skipped) |
| CDefClassBase chain via `probe_dcb.cpp` (CSubDefClassBase-derived) | 25 | 25/25 (slot 14 = const GetPSubDefInfo) |

The opt-in macros: `FABLE_RETAIL_NSCRIPT` (new NScript headers; each one `#error`s without it) and the existing
`FABLE_RETAIL_DEF_CLASS_BASE` (def chain). `CBaseClass.h` has no macro: it was already the retail model.

## New headers (FABLE_RETAIL_NSCRIPT)

### fable_nscript_forward.h
Forward declarations shared by the NScript headers. The class keys are the ones the PDB mangled names carry (V/U).
Enums are MS forward declarations under VC7.1. Under g++ they get empty placeholder definitions (`#if !defined(_MSC_VER)`),
because C++98 has no opaque enums. `FableNScriptUInt64` is `unsigned __int64` under VC7.1 and `unsigned long long` otherwise.

### CGameScriptInterfaceBase.h (generated by `scripts/gen_cgsi.py`)
- **Chain:** RTTI `.?AVCGameScriptInterfaceBase@@ : CBaseClassNonCopyable : CBaseClass` (ghidra_out/rtti_bases.tsv).
- **Vtable:** 0x0126009C. Slot 0 is the deleting dtor 0x006E7180; the other 916 slots are `_purecall` 0x00BFEA08.
- **Slot names:** each slot is named from the overriding CGameScriptInterface slot (vtable 0x01260F0C,
  ghidra_out/cgsi_slots_aligned.tsv). The mangled names are FableWin.pdb's; 916 are also in Ego_r.pdb, and slot 2
  TraceMessage is FableWin-only. Declarations are the VC7.1 undname spellings. Overloads are declared in reverse slot
  order because VC7.1 groups overloads and emits the last declared first. The probe confirms this.
- **Access:** slot 378 EndLetterBox is protected (FableWin `MAEXXZ`).
- **Unproven / stand-in:** slot 308 AddLogBookEntry takes the nested enum `CHeroLogBook::CHeroLogBookEntry::ECategory`. A
  nested enum can't be forward-declared, so the header declares the parameter as `long`. The ABI and slot are the same,
  but the mangled name differs.

### CGameScriptInterface.h: new `#ifdef FABLE_RETAIL_NSCRIPT` branch (generated part: `scripts/gen_cgsi_derived.py`)
- **Class:** `class CGameScriptInterface : public CGameScriptInterfaceBase`.
- **Slots:** the 916 overrides, plus slot 917 `SetTrapAsActive(const CScriptThing&, bool) const` at 0x00895130 (FableWin).
- **Ctor:** 0x006E7740, the bound Ego_r spelling. Slot 0 is the vector deleting dtor 0x006E7D50.
- **Members** (+0x04..+0x4C, size 0x50): from the generated flattened model, which stays in the `#else` branch for its 832
  includers.
- **Unproven:**
  - the address of the ~CGameScriptInterface body;
  - HeroSThing (CScriptThing) and ScriptTimers (STLport map) are still opaque;
  - the PDB's non-virtual members are not declared yet.
- The generator keeps the branch (RETAIL_MARK matches `FABLE_RETAIL_`).

### CScriptThing.h: new FABLE_RETAIL_NSCRIPT branch (the generated flattened model stays the `#else`)
- **Chain:** RTTI `: CBaseClass`.
- **Vtable:** 0x01238C8C, 79 slots. Each slot is named from its address's retail label, cross-checked against FableWin.pdb
  (77 are also in Ego_r). Slot 78 IsEqualTo is protected and FableWin-only.
- **Non-virtual members:** ctor 0x006E7B40, copy 0x004ABE90, dtor 0x004AA840, op= 0x008AB980, op== 0x008AAE20,
  op!= 0x008AAE40, static NullString 0x0143E8EC.
- **Members:** PImp is `CCountedPointer<CScriptThingImp>` at +4; size 0xC.
- **Contract:** the includer defines `CCountedPointer<T>`. The row's own model decides the inline expansion.
- **Inline bodies:** retail expands the dtor, copy and slot wrappers inline at some sites. A row that needs one defines it
  out of class after the include (`inline` / `__forceinline`). This was verified to give identical bytes on 00ef54a0,
  00ef5670 and 00f0eda0.
- **Open:** a row that needs the copy inline at one site and out of line at another can't be expressed with the shared
  header. See REVERTED.tsv, 00f05f30.

### CScriptBase.h
- **Chain:** no RTTI. The ctor 0x00CB8110 calls CBaseClassNonCopyable() 0x0099A2F0, so the base is CBaseClassNonCopyable.
- **Vtable:** 0x012C1648, 5 slots:
  - 0: deleting dtor 0x00CBD4F0 (~CScriptBase 0x00CBD510);
  - 1: RegisterMain 0x00CBD4B0;
  - 2: Main 0x00CBD4C0;
  - 3: Init 0x00CBD4D0;
  - 4: OnPersist 0x00CBD4E0, which ends in `ret 4` (the one-argument slot).
- **Slot evidence:**
  - Main (slot 2): the RegisterMain rows spawn a vcall thunk `jmp [eax+8]`.
  - Init (slot 3): the quest vtables (0x00F26B90 is slot 3).
  - RegisterMain (slot 1): the one PDB virtual left over. This is proven by elimination, not by a call site.
- **Access:** from the PDB: RegisterMain, Main and Init are protected (`MAEXXZ`); OnPersist is public.
- **Members:** Threads +4, EntityScripts +8, EntityScriptBindings +0x18, LastWorldUpdateFrame +0x28, PActiveThread +0x2C
  (read by IsActiveThreadTerminating 0x00CB7940), RuntimeScriptedEntityPersist +0x30. Size 0x40 (Ego_r 0x54 uses Dinkumware).
- **Unproven:** the containers are opaque byte arrays, with their real types given in comments.

### CLevelScriptBase.h
- **Class:** `template <class T> CLevelScriptBase : CScriptBase`. Game is at +0x40 (the landed quest rows read +0x40) and
  MasterScriptData at +0x44.
- **Unproven:** the addresses of the ctor and dtor (declared only).

### CEntityScriptBase.h
- **Chain:** no RTTI.
- **Vtable:** 0x012C3224, 7 slots:
  - 0: deleting dtor 0x00CDEBF0 (~CEntityScriptBase 0x00F35B40);
  - 1: Main (pure);
  - 2: Init 0x00CDEBB0;
  - 3: GetParentScript (pure);
  - 4: OnPersist 0x00CDEBC0;
  - 5: OnPredicateFail 0x00CDEBD0;
  - 6: OnInterrupted 0x00CDEBE0.
- **Slot evidence:** the pure slots are named from the overrides. Every entity class has `?Main@..@@EAEXXZ` and
  `?GetParentScript@..@@UBEPAVCScriptBase@@XZ`. For example, the CAT_BanditAlly vtable 0x012F7D88 has slot 3 at
  0x00F03840.
- **Members:** Game +4, Me +8 (size 0x14).
- **Unproven:**
  - the base access of Main (every override is private; the header declares it public);
  - the 5/6 order of OnPredicateFail and OnInterrupted, which rests on the landed entity rows plus CSpawnedFuncBase's
    same pair order.

### CTimer.h
- **Layout:** `{long TimerIndex}`, non-polymorphic.
- **Ctor/dtor:** ctor 0x00CD4450 (interface slot 87 RegisterTimer) and dtor 0x00CD4470 (slot 88 DeregisterTimer), both
  through the global 0x0143E8F8.
- **Operators:** the Ego_r set, declared. Retail expands `operator=(long)` inline as slot 89 SetTimer, and rows define that
  body out of class.
- **Unproven:** the addresses of the comparison and accessor operators.

### CPredicateBase.h, CIsThingAlive.h, CPredicate_And.h
- **CPredicateBase:**
  - vtable 0x012C2FF4: `[operator() pure, Clone pure, deleting dtor 0x00CDDB40]`, declared in that order with the dtor last;
  - ctor, copy and dtor are inline: retail stores the vtable inline at every site and has no out-of-line copy;
  - static `InitialiseGameInterface` comes from FableWin.
- **CIsThingAlive:**
  - vtable 0x012C32F0: `[0x00CDF120 (jmp to CScriptThing slot 75 IsAlive), 0x00CDF130 Clone, 0x00CDF160]`;
  - ~CIsThingAlive is 0x00E241B0;
  - the ctor is FableWin-only, so retail expands it inline.
- **CPredicate_And<CIsThingAlive,CIsThingAlive>:**
  - vtable 0x012E1B70: `[0x00E23F00, 0x00E247A0, 0x00E245A0]`;
  - ctor 0x00E24760;
  - `NScript::operator&&` is `__fastcall` (YI) in both PDBs and is defined inline.

### CEntityScriptBindingBase.h, CEntityScriptBinding.h
- **Vtable:** each `CEntityScriptBinding<T>` vtable (for example 0x012E1E10) has exactly 2 slots and no destructor:
  - 0: GetEntityScriptName, body `lea eax,[ecx+4]; ret` (0x00E25C60);
  - 1: CreateActiveEntityScript (0x00E25D90). The PDB has it as protected; the catalog label
    `..._CreateActiveEntityFromInfo` is a propagated label (NAME_FIXES.tsv).
- **PDB coverage:** FableWin has 121 instantiations, each with exactly that ctor, these 2 virtuals and no `??1`.
- **Members:** EntityScriptName +4, PParentScript +8, Func +0xC, ClassAllocFunc +0x10, ClassAllocValid +0x14, Flags +0x18
  (0x1C). This is the Ego_r layout, and the binding factories call new with 0x1C.
- **Unproven:**
  - the base is `__declspec(novtable)` (macro `FABLE_NSCRIPT_NOVTABLE`). This is inferred from the binding ctors storing
    only the derived vtable;
  - neither PDB has the base slots' own access or pure-ness (the header declares them pure and protected for slot 1);
  - `Func` is never written by the ctor.

## Def chain (FABLE_RETAIL_DEF_CLASS_BASE)

### CDefClassBase.h (retail branch corrected)
- **Size: 0x25, packed, not 0x28.** The class is declared under `#pragma pack(push, 1)`, matching Ego_r.pdb 0x25.
  - The landed CDegradableDef::operator= 0x00454434 has `bool Degradable` at +0x25 and the next 4-byte member at +0x28;
    it matches retail only with the 0x25 base. The earlier 0x28 evidence (CFireHeartPatternDef's first member at +0x28)
    can't tell the two apart, because that member is 4-aligned.
  - Rows whose opaque derived bytes started at +0x28 got an explicit `_pad_0x25[3]` or an aligned opaque type:
    00d34d40, 00f2d010, 00f345f0.
  - The DEF-HE rows keep their `sizeof(CDefClassBase)==37` audits. The earlier `==40` rewrite was undone.
- **Slots 14/15 are proven:** slot 14 is the const `GetPSubDefInfo` (0x0042DA60) and slot 15 is the non-const one
  (0x0042DA50).
  - The const `GetSubDef<T>` rows call `[vptr+0x38]` from a const member.
  - The CParentDefClassBase overrides are bound UBE/UAE.
  - The probe reproduces all 25 slot names.
- **Inline dtors:** ~CDefClassBase, ~CDefPointeeBase and ~CIVCountedPointeeBase are inline. The retail deleting dtor
  0x0042DAB0 stores the CDefPointeeBase vtable and calls ~CResource 0x009FC550.
- **Added (FableWin spellings):** `operator=` 0x00431F10, the `GetSubDef<T>` member template, the nested CSubDefInfo
  (DefIndex, OriginalParentDefIndex), and AreDefaultValsApplied/SetDefaultValsApplied (inline).
- **Unproven / not declared:** the private default ctor `??0CDefClassBase@@AAE@XZ` (FableWin). Note that the bindings spell
  0x00430370 as QAE; see NAME_FIXES.tsv.

## CBaseClass.h (rewritten in batch 1)
- **Ctor:** out of line, 0x0099A2D0. Ego_r and FableWin both place `??0`/`??1` side by side, and 1,225 landed rows call it.
- **Dtor:** virtual `~CBaseClass` 0x0099A2E0.
- **Copy:** the copy ctor is implicit. Rows write `: CBaseClass(other)` in their inline copies, because retail expands a
  bare vtable store.

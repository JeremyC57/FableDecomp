# Lessons (chunk 239)
- A by-value getter returning a C3DVector with a user copy ctor, called once per component (`GetCenter().X`, `.Y`, `.Z`), gives three 12-byte temporaries where only the used component is stored (frame +0/+0xC/+0x18) (0x00AC27A0).
- A recursive tree writer/builder whose second recursion is the last statement becomes VC7.1's rotated loop (`mov esi,[esi+24h]` and jump back); write both recursive calls plainly (0x00AC27A0, 0x00AC2A80).
- An override of a second base's virtual compiles with `this` at that base: model the class with the real multiple inheritance (C3DAnimation2 : C3DAnimationStats, CMovableResource) and every offset reads 0x2C lower (0x00A4E960).
- Unnamed temporaries passed by const reference to successive calls share one frame slot; retail's distinct slots mean named function-scope locals declared just before each call -- VC still schedules their fild/fstp between the argument pushes (0x00A39FE0).
- A CCountedPointer returned by value and ignored loses its dtor's clearing stores as dead stores; retail keeps them when the result is a named block local declared after the prototype it registers (0x00AA4710).
- Two recursive animation combiners matched only with (a) an inline manager forwarder `GetAnimationInfo(i) { return MeshBank->GetAnimationInfo(i); }` (MeshBank loads into ecx before the index push), (b) its result in a named local before the next call's pushes, (c) `unsigned long childDepth = depth + 1;` (homes in the dead state-argument slot; `++depth` reuses the depth slot) (0x00AA0C50, 0x00A9F2F0).
- `a + (b - a) * t` keeps `a` on the FPU stack (`fsub st(1) ; fadd st(1)`) only through an inline by-value helper `Interpolate(a, b, t)`; written inline VC reloads `a` from memory (0x00A9F2F0).
- 0x007EE540 is CTCVillageMember::GetPVillage() const (returns a pointer: `test eax,eax`), not IS_THING_ALIVE (0x0092D060).
- Early returns that all share one `xor al,al` epilogue come from nesting the conditions (`if (a && b && c) { ... } return false;`); flat `if (!a) return false;` chains duplicate the epilogue (0x0092D060).
- Same-TU stand-in callee bodies must be `__declspec(noinline)` when the callee is a template member: the template instantiates at the point of use, after `#pragma auto_inline(on)` (0x00A26AD0).
- VC7.1 canonicalises the operand order of commutative fmul pairs independently of source order (array indexing or named fields alike); a matrix inverse kept seven pairs reversed against retail (0x00C1D1C0, parked).
- Without /Op VC7.1 turns repeated `x / steps` into reciprocal multiplies; /Op keeps the fdivs but adds a rounding store after an int->float conversion that retail lacks (0x00C5A9D0, parked).
- CNavigationInput's Proximity/Speed are floats: a float member zeroed in an init list stores an immediate 0 while int members use the zero register (CBrainOutput inlined, 0x0097D580).
- Loop-invariant bool arguments written in the call (`(flags & 2) > 0`) are hoisted out of the loop with `setg` straight into frame bytes; named bools before the loop compute in registers and store (0x0097D580).
- The "callee-saved register pushed inside one branch" shape is reachable in the lane: a bool kept across a def release (`push ebx ; ... mov bl,al ; ... pop ebx`) came out of an inner `{ CDefPointer def(...); b = def->X() == "..."; }` block (0x00911C20).
- Frame-slot sharing between a lookup key, a hit-event out pointer and an earlier block's locals needs both block nesting (event half in its own block, the out pointer in a nested block) and same-TU stand-ins for the callees that take their addresses (const LowerBound 0x004365B0, GetEvent 0x008AF0A0) (0x00911C20).
- A function-scope out-parameter that GetInterface only writes on a hit has its never-written home loaded into a callee-saved register at function entry when it is used across loop passes (0x00911D90).
- When the TU inlines the non-const vector-map lower_bound (the `cdq ; sub ; sar 1` halving loop on a constant key) and the hit/end pick reuses its register, write the pick as one ternary (0x00911D90).
- A static frame call through an object (`GetPFrameWorld()->GetCurrentFrame()`) still evaluates the object call; operands that retail loads before the static call (into esi / a frame slot for fild) are named locals declared after the world fetch (0x00911C20).
- 0x00957210 is CCreatureAction_BriarRoseIntoInvulnerable's ctor (vtable 0x01294B8C), not ForcePush (ForcePush is 0x009572A0, vtable 0x01294CD4).
- A creature def add-ref'd by hand around GetSubDef and the sub-def then held in the SAME register (BriarRoseWillUse 0x00956FE0) is one raw pointer variable reused (`def = out.Object`) with a hand-written release at the end.
- A switch that pushes a different literal in each case before one shared CCharString ctor call (`push -1` hoisted) is an inline helper returning CCharString by value with `return CCharString("...")` per case; a helper returning const char* gives `mov eax,lit ; push eax` (0x0092A0C0).
- An inline GetCreature() accessor (`return Brain()->PCreature;`) stops VC7.1 hoisting the identical brain load of two if/else arms, and makes the creature load schedule before the zero pushes of an action ctor (0x00956FE0, 0x00957A20).
- An int->float fild temporary reuses a dead lookup-key slot only when VC7.1 knows the key's address does not escape: give the TU a same-TU LowerBound stand-in (0x0093A8C0).
- A dead `setne bl` after an action call comes from `bool failed = ... != 2; if (failed) { Terminate(); return; } ... Terminate();` -- the two identical tails merge and leave the setcc; the extra bool use also makes VC keep constant 1 in ebx (0x0091B190).
- An inline GetCreature() { return Brain()->PCreature; } accessor fixed the brain/creature register pair (ecx,ecx vs eax,ecx) for a GetPosition this; IS_THING_ALIVE overloads (raw pointer and intelligent pointer) must be __forceinline or VC7.1 calls one out of line (0x009790F0).
- OnActivate wrapper: HasAnim(CCharString("X"), CAnimFilterAnyGroup()) built the string after pushing the filter address and dropped the base-vtable restore; retail's order (name ctor, filter vptr store via edi, base vptr restore before ~CCharString) comes from an inline group helper taking (const CCharString&, const CAnimFilterBase&) (0x970610).
- Args pushed before a this-expression call (GetPWorld()->X->Y.Call(a,b)) vs retail's values-in-ebx/edi pushed after the call: name the world pointer (CWorld* world = GetPWorld();) and the creature before it (0x970610).
- x87 CSE death: an inline C3DVector::operator*(float s) keeps s live through the Z product (fld z; fmul st(1); fstp st(0)); retail's `fmul [z]` consuming the scale comes from spelling each component with the same (radius * 0.75f) subexpression (0x970930).
- HasTC as masked dword `bits[0] & 0x80` compiles to `mov cl,[eax+0x20]; test cl,cl; jns` (sign-byte test); the bitset::test form gives shr/test cl,1 (0x970930).
- Random inline written with locals (next/rotated) lets VC7.1 sink the `% range` div past a following call (GFGetCurrentFrame); retail's div-before-call comes from the *seed form (`*seed = *seed*0x24A1+0x24DF; *seed = GFROR13(*seed); return *seed % range;`) (0x96c9a0).
- A const char* literal passed to a `const CCharString&` parameter (implicit conversion) builds the temporary before any pushes and re-leas its address; an explicit CCharString("...") temp pushes the later args first and reuses the ctor's eax (0x96c9a0).
- Deriving a Methods struct with `virtual` slots from the generated CAIStateGroupBase.h (which spells the vptr as a `void* __vftable` member) adds a second vptr and shifts every member by 4; model the base locally when the function makes virtual calls (0x94c900).
- `component->Call(GetCreature())` evaluates the creature argument before an inline GetTC object expression; retail's component-then-creature order needs the component in a named local (0x94c900).

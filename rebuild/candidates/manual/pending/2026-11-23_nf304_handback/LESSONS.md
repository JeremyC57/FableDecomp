# NF304 lessons (one line each)
- `nf.py proof` pairs renames by name after stripping DEF/UND, so a renamed DEF still prints ALL_EQ: diff `nf.py syms` of HEAD v new for every row (re-scopes especially); entries 1-3 / 8 renamed pick-any COMDATs (an implicit copy ctor, implicit ctor/dtor, local inline getters) and fail ruling NF300 Q2 although objsec is ALL_EQ.
- Re-scoping a type that is a by-value parameter of a SELF's own definition makes it a self + every-binder unit: at HEAD the binders were RESOLVED against the self's stand-in, so moving the binders alone leaves them unresolved (entries 27 / 28: six rows moved together; entry 14 held for the same reason).
- Table witnesses go stale between landings (entries 5, 10, 32 and the GetPlayer PAV line): the HEAD object, not the table, is the work list; a stale line is a table-only fix when the full exe census of the target is compiled.
- A class-key change on a local model (struct CPlayer -> class) respells every other symbol that names the type: entry 9 also moved the TU's GetPlayer binding (PDB form `CPlayer& GetPlayer(long)`, 15 of 27 callers bind it); held because that callee is T3-queued.
- The census-compile step (every caller of each respelled target, controls included) costs ~1 s per row in 4 background lanes; it is cheaper than reasoning from source, and it found the untabled wrong binders 0x0063E950, 0x00642970, 0x00B2C4E0.
- Many clang precheck failures on unchanged tests and sources are VC7.1 `wchar_t` / L"" vs `unsigned short` ctor mismatches: NOWCHAR (accepted) clears them; keep cl /Zs for MSVC-only syntax.
- nf.py xr / bind.py take the FIRST object symbol containing a bare `// Leaf:` (0x00750540's `Open` matched ?SetOpened@COpenCloseHelper@@): a `-` binding is a tool miss until objdump + the retail bytes confirm it.
- A self rename can break the row's own test when the test links the row object against its own model of the class (0x00A10DC0 LINK_FAIL): update the test's declaration with the self.
- Check every respelled CALLEE (not only the entry addresses) against T3_PORT_QUEUE / other agents' lists: a class-key fix moved 0x00449CB0's GetPlayer binding onto a T3-queued target (entry 9 held).

# Chunk 221 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- CCombatSequence OnCreate family: read the sequence's owner/target through inline getters (`GetCreature()`/`GetTarget()`, pointer or reference). Direct `m_1c/m_20` reads give a different eax/ecx/edx rotation for the AddAction `lea` temporaries (00906050, 00907d00, 00909ba0, 009079c0, 00909520). A string argument to the action's constructor inside the new-expression is an IMPLICIT CCharString conversion; VC tracks it with ebx flag bits, and `mov ebx,1` doubles as a later `true` push (00909520).
- STLport tag structs (`random_access_iterator_tag`, `__false_type`) need a user-declared empty constructor. `__false_type()` on a POD empty struct value-initialises: a `mov byte ptr [esp+N],0` and its own frame slot. With the constructor, VC homes the tag in the dead argument slot like retail (0047be50 and the other vector operator= rows).
- A same-TU stand-in for CVectorMap::LowerBound 0x0040F020 (its retail body under `#pragma auto_inline(off)`) tells VC7.1 the inlined lookup key's address does not escape. The key then shares its frame word with a later string or by-value copy (008bae10/008baf20: frame 0x14 -> 0x10).
- Same-TU stand-ins for the def/counted-pointer fillers do the same for the filled pointer: GetDef 0x7A35D0 (008bc790/008bc8c0/008bcbe0: def held in a register, strings homed in the dead argument slot), GetSubDef<T> 0x5CC10E/0x669580/0x8C78F0 (00848730, def in ebx/ebp) and the CCountedPointer(T*) ctor 0x8C3260 (008c0c00: frame 0x10 -> 0xc, release through `dec [esi]`).
- A stack CIntelligentPointer that only exists to clear a member (`none.SetPItem(0); m.SetPItem(none.GetPItem())`) must sit in its own `{}` block. Otherwise the inlined lookup keys get a separate frame word (008d5480: 0xc -> 8).
- Named object local puts GetPItem before the argument pushes: `CThing* creature = PCreature.GetPItem(); creature->AddTC(...)` / `creature->SetSuspendAnimation(true, 0)` matches retail's object-first order. Written inline, the arguments are pushed first and GetPItem runs last (0069f2b0, 008c0c00). For `x->m_pDef->GetSubDef(&out)` the named `CDefClassBase*` local gives retail's `mov eax,[eax+70h] ; lea ; push ; mov ecx,eax` (008c7280).
- A physics component reached as `GetPItem()->GetPhysics()->V()` (inline accessor) loads straight into ecx for the virtual call; the direct member read goes through eax (008ca4a0, 0069f2b0, 008bd3f0).
- A C3DVector local of which only X/Y are written (`C3DVector delta; delta.X = ...; delta.Y = ...;`) reproduces a 12-byte frame hole that retail has; a C2DVector or two floats shrink the frame by 4 (008bd3f0).
- RTM cl CSEs a constant used three times (for example `% 2` / `& 1` plus two `test byte ptr [eax+91h],1` dead-bit tests, or two tests plus a `true` push) into a free callee-saved register (`mov ebx,1 ; test [..],bl`). Retail does not (008559e0, 00849f70 parked). Conversely retail CSEs 0 into ebx in 008cf7d0.
- An STLport vector `operator=` whose element copy is non-trivial keeps `_M_allocate_and_copy` / `__copy_ptrs` in or out of line per TU. Read the callee list (malloc call inline vs a thiscall `(n, first, last)`), and declare the LTCG-convention callees `__fastcall` with the stack arguments in retail push order.
- The catalog row 008bb320 holds its own 16-byte switch jump table; q.py grades it, but landing needs `verify_land_jumptable.py`.

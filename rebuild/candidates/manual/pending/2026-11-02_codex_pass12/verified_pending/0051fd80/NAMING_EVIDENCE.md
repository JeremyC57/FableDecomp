## Two exact-name holds

Native00527d80 and00527d20 are distinct unsigned64-key lookups for UIDToThingMap and CEntityRuntimePersistence's persisted-dead map. Their bodies are byte twins, but their original map value types differ and the current symbols are distinct. Native receivers, header/root links, node key at+10/+14 and returned node/sentinel prove the real STLport _Rb_tree::_M_find algorithm and each specialization. Official STLport4.6 _tree.h chooses a private const member-template under its default VC7.1 configuration; this is the current spelling. The alternative _STLP_NO_EXTENSIONS build selects a private non-template with identical code. No exact target configuration proof or emitted original _M_find PDB name has yet been found. Both original raw TPI searches return only _Rb_tree_node_base, not the native instantiated trees. Therefore these names are explicitly held for main adjudication, exactly as the set<CCharString> helper in00520d00. The older placeholder map/Find aliases are not copied to silence a verifier.

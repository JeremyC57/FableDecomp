# Chunk 211 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A def read ONCE from its GetSubDef out slot and kept in one register for the field reads and the release is a small holder built from `out.Object` (0x0066B1D0, as 0x00750240); reading the thing def into a local BEFORE declaring the out slot sinks the out slot's zero store below the `push` (0x0066B1D0; same trick as chunk 136's chain locals).
- Through such a holder, a nested member struct (`def->Vector.size()`) makes the lane strength-reduce `&def->Vector` into its own register and spill the def; put the accessors on the def class itself (0x006E2C00, 0x007275C0).
- `if (--RefCount == 0) Destroy();` on a CDefPointer local whose null test VC elided (the pointer was dereferenced) comes out of the lane in the long `mov edx,[eax+4] ; mov ecx,eax ; add eax,4 ; dec edx ; test edx,edx ; mov [eax],edx` form whenever the pointer lands in eax or a zero register is live; through a member pointer re-read into ecx (`if (P) { P->Release(); P = 0; } P = 0;`) it is the short `dec [ecx+4] ; jne` (0x005E9F30 matched, 0x00811830 / 0x00773E10 parked).
- `Call(T(new X(...)))` with T = CCountedPointer and the raw-pointer ctor `if (Data) Info = new Block(Data); else Info = 0;` builds the counted pointer straight in the argument area with the three exits (0x00762AB0).
- An action temporary built by one of two constructors and passed by address: write an if/else with a temporary per arm (sibling scopes share the frame slot and VC cross-jumps the identical SetCurrentAction/destructor tails); `&(c ? T(a) : T(b))` builds two temporaries plus a copy (0x0072C9C0).
- Two copies of the same `const C3DVector&` (a range filter and a comparator) load the components once only when C3DVector has a memberwise user copy ctor; the implicit copy reloads per copy (0x007F67C0).
- A call whose object (`GetWorld()->ThingSearchTools`) retail fetches after the argument temporaries are built but before the pushes: a `__forceinline` helper taking the arguments by reference whose body is `T* tools = GetWorld()->Member; return tools->Call(args);` (0x007FEAF0; the chunk 130 helper form plus the member local).
- A pass-through argument pushed before a virtual call belongs to the following direct call (`push edi ; call [edx+30h] ; mov ecx,eax ; call IsPosInMap`): `GetWorld()->GetWorldMap()->IsPosInMap(pos)` (0x0066AEF0).
- A two-case switch compiles its tests in value order but lays the case bodies out in source order: retail's 0x10 body before the 0xb body means `case 0x10:` is written first (0x0072B870).
- Per-arm `if (thing->HasTC(k)) result = thing->GetTC(k);` on a zero-initialised result reproduces the zero register in ebx and the tail-duplicated returns (0x00798F50); a single shared lookup after an if/else picks the thing does not.
- STLport `_Rb_tree()` inlined: `_M_header(alloc, 0)`, `_M_header._M_data = malloc(sizeof(node))`, `_M_node_count(0)`, then `_M_empty_initialize` (colour byte, parent 0, left/right = header) re-reading the header after every store (0x00BD92E0); the STLport list ctor zeroes the node word, mallocs the sentinel, links it to itself and stores it last (0x007CA830).
- A derived constructor that inlines a base's `(type, flags)` constructor needs `__forceinline` on it, else VC emits it out of line in the TU (0x00BD9830 / 0x00BD9940).
- A store of -1 that retail schedules above the derived vtable store still comes from a plain initialiser in declaration order (0x004E2250: `FrameSetAsTargetNextThing(-1)` precedes the vtable store in both builds).
- Engine headers that are flat POD structs with a `__vftable` data member: write the method as a `__fastcall` free function over the header struct (0x00731BE0 precedent) and reach CTCBase calls through `((CTCBase*)self)->Call()` so the callee keeps its real member symbol (0x00731BF0).
- `(CWorld::GetWorldFrame() + thing->UniqueID) % 15 == 0` with the unsigned __int64 id read into a local first gives `cdq ; add ; adc` and `_aullrem` (0x00799AA0).
- Lane gap seen five times in this chunk: retail shrink-wraps a callee-saved push into a branch (`test al,al ; je ; push ebx` / `push ebp` / `push esi`) to hold a value only that branch needs; the lane either keeps the value in a frame byte, reloads it, or pushes at entry (0x007721A0, 0x007742C0, 0x007743B0, 0x00747B80, 0x006E2C00). It does sink a push when the register only holds an address inside an `if` body (0x00773B20 matched).
- Lane gap: two `HasTC` bit tests of the same bitset word joined by `||` (or split into two ifs) fold into one `test ch,3`; retail tests them separately and keeps the 0x100 mask in a register (0x0072C9C0).

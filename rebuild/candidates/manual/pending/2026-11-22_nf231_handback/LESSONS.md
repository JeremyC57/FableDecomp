# NF231 lessons (one line each)
- A class's landed vtable COMDATs can be truncated models (1 slot): census vtable slots in the retail exe (absrefs.py) AND in the compiled objects (vtsyms.py) before calling a virtual "unbound".
- pin_asserts.py rewrites plain FABLE_STATIC_ASSERT lines of the overlay copy in place: copy the overlay into the equiv_check tree only after pinning.
- engine/CDisplayManager.h needs FABLE_RETAIL_CPIXELFORMAT (Direct3D9Types: HWND, D3DCAPS9) and engine/IDirect3DDevice9.h before it.
- A private static can be defined in a test at namespace scope; with `#define private public` placed after the other headers and only around the one class header, the rest of the tree keeps its access.
- An explicit specialization of a declaration-only STLport member (`template <> std::vector<T>::iterator std::vector<T>::erase(iterator, iterator)`) is a clean test stub for an out-of-line COMDAT callee.

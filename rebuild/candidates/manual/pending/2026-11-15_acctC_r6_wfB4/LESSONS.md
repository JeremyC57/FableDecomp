# wfB4 lessons (one line each)
- (0x00B8B780, 0x00B89C30) The SetRenderState bookmark test/or operand order is decided by two c2 comparator calls per inlined AND, both readable with a 3-minute gdb trace of the merge-sort comparator 0x1076A394 (k/cmp.py + agentC20 sched2/host.py): measure the ids before sweeping spellings.
- First pass (inline time): record ids come from a free list (step 3 per setter) and then from the high-water mark; an id >= 2048 wraps (rotl16(id,5)) and swaps the operand order from that block on. Dead asserts do not touch it; one more inline parameter / local record before the block does.
- Second pass: two temp ids (mod 1024), one growing ~36 and one ~20 per setter block; the retail-order window starts where the fast one wraps and ends where it catches the slow one. Dead asserts add ~8 to both (start moves, end does not); a named local or a trivial accessor expansion moves the slow one by 23..36 at once.
- FableWin COMDAT ADDRESS ORDER is evidence for helper USE: the inline functions placed right after a function's TU are the ones that TU used first; a helper whose only COMDAT sits at a later address (GetAppropriateMipmap, GFLimit<JJJ> for the billboard TU) is NOT used by that TU.
- FableWin float code: +2 instructions per binary float expression passed as an argument (rounding temporary) and 3 instructions per float constant push or member-float push: operator*(float) 31i, operator+/- 34i, GetTranslation / GetRowX 22i are the default one-expression bodies; a row with many constant float arguments is ~2i per argument larger without any ASSERT.
- A "NoTranslation" product whose retail bytes keep the translation dot products is a full SetMultiply / PostMultiply on a by-value matrix copy whose translation was zeroed with constants: VC7.1 folds `+ 0.0f` and drops the dead zero stores (0x00B8B9CB).
- Check the FableWin neighbours of a row before trusting its sizes: RenderWeaponTrail's FableWin body uses CArray<CArray<C3DVector>> and a std::list, i.e. a later source revision.
- (0x00BCC800) UNREFERENCED OUT-OF-LINE COPIES of a row's inline helpers are oracles for the helper TEXT: grade each copy (pointer-to-member probe, retail bytes by VA) before touching the row. Six copies with the same-direction register swap = one wrong text in the innermost helper (FindNode), not six allocation ties.
- (0x00BCC800) A register swap that follows an inlined helper into every caller is a priority gap of 2-3: run c2prio on the smallest copy, read the per-block K table, and look for the block where one more live candidate (K+1) gives the swing. Here: a named `index` used twice (`if (table[index]) return F(table[index], key);`) instead of a `child` local.
- (0x00BCC800) A value read twice through the same expression keeps its index local alive across the test (a real candidate that takes the scratch register first); a single-use named local is forwarded and changes nothing. `x = t[i]; if (x) f(x)` and `if (t[i]) f(t[i])` are the same instructions with different register choices.
- A probe variant chain built with string replace silently fell back to the default text for every later variant: keep one file per variant and verify one variant changes the output before trusting "no change".
- (0x00B89C30) Bookmark-order rows: letters = fixed second-pass base XOR "swap from the first block whose first-pass id is >= 2048"; the final setter run first drains a free run of ids, then takes new ids from the high-water mark. Each named local or temporary object adds exactly 1 to every later id wherever it is declared, so sweep n = 0..12 unused locals ONCE (2 s a grade, tools/p2.sh letters): if the retail letters are not in that list, no spelling that only adds symbols can close the row.
- (0x00B89C30) The id map has regimes: at n = 3 an earlier free run ends one block sooner and every later run starts 32 / 64 lower, so the response to a count ruler is not monotonic; a one-block miss is not "one local away".
- (0x00B8B780) Size the row itself against FableWin before believing an assert count: subtract 2 instructions per constant float argument (0.0f / 1.0f cost +1 byte, other constants +5), then divide by the assert size (+63i / +223b or +82i / +318b). Here: one assert, with an accessor call in its condition, not two.
- (0x00B8B780) A FableWin COMDAT first emitted with a TU for an accessor that no retail byte uses (GetVertexCount, GetPRenderToSurface) is the condition of a debug ASSERT, not a missing statement.
- The shared header already has landed FITTED SetRenderState variants (SETRENDERSTATE_DESIRED, _BOOKMARK, ADDSTATE_DIRTY: one named symbol per expansion each): try the five combinations before any ruler on a bookmark-order row; they move the window by whole blocks.
- A variant that defines an opt-in the header cannot compile alone makes cl spin until the timeout and blocks the work directory of that address for later grades: preflight with g++ -E, and never grade the same address from two shells.
- (0x00B89C30, third agent) c2's record ids are per FUNCTION: a full-size function defined above the row changes no bookmark letter; do not look for TU context in this residue class.
- Unused-local rulers must be INITIALISED (`long unused1 = 0;`): an uninitialised unused local is dropped by c1 and measures nothing (earlier "no effect up to 8" results were this artifact where the locals had no initialiser).
- Bookmark first pass, exact rule: a setter block's `state` id = free-run cursor + uniform symbols n + inline PARAMETER temps alive at that expansion. Function-level symbols, inlinee locals, multi-return inlines and temporary objects are all uniform (position-independent); only a forwarding inline layer AROUND the call adds a positional id, and it is freed when the layer ends (wrapping earlier setters does nothing). Argument spellings (pass-through inline, casts, locals, statics) never create it.
- Before declaring "one-record wrappers have no effect", test them on every uniform base n = 0..2: on the n = 1 base a one-parameter layer is invisible, on n = 2 it is the match.
- FableWin COMDAT const-ness is evidence for member types: a helper emitted only in its const form (GetAsCArray QBE, front QBE, GetZeroSizeArray ABE for CVertexShaderConstant) means the object expression is const in the original (CurrentVSConstantLayout is a pointer to const), and its /Od size checks the const overload's text.
- struct_layouts_egor.tsv drops pointee const (`_Myfirst` of a vector<T const*> is listed `T * *`): take const-ness from template arguments and FableWin overload sets, not from the member type column.
- (0x00B8B780, third agent) Second-pass bookmark ids: dead asserts and initialised unused locals move them only in 32-id chunk jumps (asserts: both sequences at counts 1, 4, 6, 9; the 8th local: `beta` only), so their grid can only shift the S-run by whole blocks; a residue that needs a 3..18 id relative shift needs a TEXT change (an inline accessor layer: about -7; a 3-parameter template like GFLimit: +11) measured by its own trace. Map the (asserts x locals) grid once (`w4/sw1.py`), then stop counting.
- A FableWin "first emitted with this TU" list misses helpers an EARLIER TU already instantiated: check every template instance by its exact argument list (GFLimit<long,int,long> 0x01A93F80 exists although GFLimit<long,long,long> is emitted later) and every plain accessor in the class's PDB name set (PeekNonHomogenousViewTransform) before calling an expression hand-written.
- Fine id effects and chunk jumps do not add: removing an accessor also removes one uniform symbol and can drop the text below a chunk threshold (re-add one ruler local when testing), and two fine levers measured separately did not sum. Trace every candidate; `k/m.sh` needs ABSOLUTE source paths.
- (0x00B8B780, fourth agent) A bookmark-order row whose S-run END is off by one block after every ruler sweep: look for a NAMED COPY LOCAL initialised from a member (`const float radius = sphere.Radius;`) between the setters; such a local is not a uniform ruler (it moves the second-pass `alpha` sequence by a block's worth) and removing it closed the end at every assert count. Run single code-identical toggles on the base that has the start right before sweeping devices.
- (0x00B8B780) Dead-assert "count" is really IL weight: (mesh, mesh, mesh) and (mesh, billboard, distance > 0.0f) differ by a whole block of the S-run start. Sweep conditions as well as counts, then pick the smallest statement count that matches.
- (0x00B89C30, fifth agent) A bookmark-order block that needs "one more live temp" is closed by a value copy alive during its OWN setter's SetRenderState expansion (enclosing inline parameter, or a local in the setter body); casts, `+0`, refs, const params, object-pointer accessors and argument inlines are not copies. Check the debug-build size of the setter before using a header local (FableWin K-setters 14i: a local makes 16i).
- 0x00B89C30 (sixth agent): c2 inline-parameter temps die at the end of their own call, not at the end of the full expression: a comma expression `A(..), B(..)` keys exactly like two statements; nesting the body in `if (p) { }` keys exactly like an early return; for / while / guarded do-while loop forms key alike.
- 0x00B89C30: a float/double unused local with a constant initialiser counts as ONE ruler, like `long x = 0` (the constant adds no record).
- Non-volatile float statics passed by value compile to `mov reg,[G] ; push reg` under VC7.1; unary +, `+ 0.0f`, `(float)(double)x` all fold to the same moves: only `volatile` (or real arithmetic) gives retail's `fld [G] ; fstp [esp]` copies.
- (0x00B89C30, seventh agent) A bookmark-order block that needs ONE more first-pass record where a row-level local overshoots elsewhere: a dead
  FABLE_RETAIL_ASSERT whose condition calls an inline with a named local / by-value class result (CTexture::GetWidth -> C2DExtentsI) adds records at
  expansion time WITHOUT shifting earlier sections, at any position in the function (row locals are FE symbols and shift everything). Probe the window
  with a throwaway `inline bool P(long a){ long t = a; return t != 0; }` in 1..16 dead asserts (2 s each), then pick a real inline with the same weight.

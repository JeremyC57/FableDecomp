# Chunk 384 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- STLport inner helpers inlined into an out-of-line algorithm (`__push_heap`, `__make_heap`, `__pop_heap`, `__unguarded_linear_insert`, `__uninitialized_copy`, `__uninitialized_fill_n`) need `__forceinline`; a plain `inline` helper stays a call (0x00673F90: 60v86 until forced).
- STLport has no `__type_traits` for enums or `pair<>`: uninitialized_* over them take the `__false_type` loop with the placement-new null test (0x006727F0, 0x00673F90, 0x0069C8F0).
- A generic byte loop in `std::fill` means the element is `bool` -- STLport's char/uchar/schar overloads are memset (0x00685430).
- `vector<T>::_M_insert_overflow` whose fill_len == 1 arm CALLS `_Construct` (speed TU): give `_Construct` a same-TU `__declspec(noinline) __fastcall` template body next to the noinline `__uninitialized_copy` / `__uninitialized_fill_n` bodies (0x0069D300, extends the 0x0051C110 recipe).
- A class argument passed by value in a /Gr TU goes on the stack and the callee cleans it (`ret 8` for an 8-byte CCountedPointer); the parameter's destructor is duplicated at every return (0x00697A50).
- Anonymous-namespace free functions: `// Leaf: ?Name@?A0x` (prefix) plus a non-static `Call<Name>` wrapper to force emission (0x00697A50, 0x00698A30).
- Free template `operator!=(const CIntelligentPointer<T>&, const CBaseObject*)` (`YI`) is `xor ecx,ecx ; cmp eax,esi ; setne cl ; mov al,cl` (0x00689270).
- The <math.h> `float ceil(float)` overload emitted out of line: `fld dword [esp+4] ; sub esp,8 ; fstp qword [esp] ; call ceil ; add esp,8 ; ret` -- write `float __cdecl ceil(float v) { return (float)ceil((double)v); }` with the CRT `extern "C" double ceil(double)` (0x00689370).
- Static `__fastcall` member returning a class by value: hidden result in ecx, first argument in edx; `return T();` with an inline default ctor gives the two zero stores, `return T(p)` constructs in the result slot (0x00692E50).
- Retail constructing a nested temporary BEFORE forming the other argument means the inner object was a named local (VC evaluates arguments right to left, so `push_back(T(T(a..), traits[i]))` forms `&traits[i]` first) (0x00682140).
- Register split this=ebx / pointer=edi came from assigning the pointer inside the condition (`if (!flag && (p = Member) != 0)`); a local initialised before the `if` gave this=edi / p=ebx (0x00682140).
- A find whose temporary argument is destroyed BEFORE the `== end()` compare is a named iterator in its own statement; one full-expression compares first (0x006991F0).
- CCharString::GetCRC inline is `CCRC::Calc(0, GetPString(), GetLength())` (length evaluated first, shared "" 0x0129AAF4); with LowerBound's body in the TU under `auto_inline(off)` the key is homed in the dead name argument slot (0x0069D090, speed-TU twin of 0x0065FBA4).
- A q.py source that `#include`s a file not present in the work dir (e.g. a probe-local .inc) hangs cl under Wine (no object, no error): keep every graded source self-contained (0x0069C8F0).
- VC7.1 ICE (C1001) on a member-template call deduced through `CDefPointer<const T>*` next to an explicit-specialisation declaration: call with the explicit argument `GetSubDef<CEntitySoundDef>(&p)` and drop the specialisation declaration (0x00698A30).

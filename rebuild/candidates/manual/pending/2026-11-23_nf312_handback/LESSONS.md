# NF312 lessons (one line each)
- A binder can carry a same-TU made-up BODY of its callee under the callee's own name (0x007786F0 "Stand-in body" of 0x00778610): respelling that binder onto the PDB name creates a second, different strong definition beside the self row. grep the binder for a `{` definition of the callee before a signature respell; such a binder is T3.
- Table witnesses go stale in both directions: three wrong lines (0x00A0B560, 0x00D17340, 0x00E1D690) were already fixed in their sources and the GFROR13 YIKK witness 0x0091B010 binds the PDB form; the real remaining YIKK binder (0x008ED590) gets it from a shared candidates/ header. Compile the witness before classifying an entry from its table line.
- Declarations are not bindings: 58 rows declare `unsigned long GFROR13(...)` and never call it (not in the exe census); only callers bind. Intersect declarer greps with the exe census.
- Retyping a stand-in container's element (0x005580B0 CActionList) can rename a pick-any COMDAT the stand-in emits (front()): read `nf.py syms` HEAD v new for DEF changes even when objsec is ALL_EQ.
- A force-inline filter in a binder can still be emitted as a pick-any COMDAT; moving the binder to the PDB reference form renames those copies onto PDB names that a strong self (0x006689E0) and another binder's copies (0x00669110) already define: compare the copies with cmpcomdat (bytes + relocations) and link with the strong self as a control.
- The ENTRIES spellings column hides `(a,self)` / `(a,b)` witnesses from a `\(([0-9a-f]{8})\)` regex: take every 8-hex inside the parentheses, and add the table's witnesses of the other agents' targets.
- A virtual slot's const-ness and name bind no symbol, but a PDB-const self body forces the const (`const CTCPhysicsBase*` from the const GetPhysicsTC): the slot's PDB name (GetPhysicsMeshInfo, slot 93) was in engine/CTCPhysicsBase.h and two landed headers.

# Chunk 894 lessons (GOTCHAS-ready one-liners)
- Twin rows (0x00436D60, 0x00863E70, 0x008ADCC0, 0x00978250 vs 0x0096BCB0; 0x00739030 vs 0x00739140; 0x00F28990 vs 0x00F34D70; 0x00F3FB60 vs 0x00A4B1D0): list the differing relocations first, then swap only the template argument / callee those relocations name; graded RELOCATION_MATCH first try. Catalog names on such twins are often a neighbour's (HeavyWeapon, GetPBestThingInRoughArea, vfunc_25): trust the callee's string literal or reloc binding instead.
- ??_G of a derived class whose base dtor inlines (0x00B84190): retail's 75-byte body needs the derived destructor defined OUT OF CLASS (empty) plus a constructor defined in the same TU; an implicit dtor gives 30 bytes, an empty in-class dtor 36, and without a ctor the ??_G is not emitted.
- x87 compare order `fld [0.0f] ; fld st(1) ; fucompp` (0x00C720C0): make the tested value a named FLOAT local (not a double expression), and keep the quotient in float with `(float)log(k) / length`, so the compared and divided value is one stack candidate.
- Commutative fadd order (0x00A17620): a `(double)` cast on one operand flips which operand c2 loads first, but the cast leaves a no-code 0x269 tuple that delays the next fadd by about 3 cycles (hand892 sched.sh dump); not a fix when retail's DAG has no cast.
- Same-TU static kernel bodies (0x00C6EEF0): a libpk wrapper that inlines a kernel needs the kernel's body repeated in the TU (shared macro from libpk/MixKernelsSIMD.h), with the non-inlined sibling kernel left extern.
- GFStringToInt jump threading (0x009E1960): `#pragma optimize("s", on)` and /O1 do not stop the guard threading; they change the whole body (strlen call, push/pop constants). Do not retry.
- A shared-header rebase does not move the esi/eax choice in 0x00D259A0; the landed sibling 0x00DE1F10 uses eax in retail too, so the enum-vs-long store is not the lever.

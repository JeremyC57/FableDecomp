# NF228 lessons (one line each)
- A visible out-of-line callee body matters for escape analysis: with _M_lower_bound declared only, VC7.1 cannot move the next key store above the value store (0x0041E1CD f1 DIFFER); with the body visible but not inlined it can.
- Template COMDATs take the optimize mode at the end of the TU: a row whose function needs `y off` restores `y on` after it so the pick-any copies match their /Oy owners (0x0041E1CD, as 0x0041E3F6 at HEAD).
- STL tree tests on the shared headers link with FABLE_RETAIL_STLP_MAP + _TREE_INSERT_UNIQUE_HINT_BODY + _MAP_ORIGINAL_INSERT_BODY and a no-op _Rb_global<bool>::_Rebalance stub.
- A private static of a header class can be set in a test through a declared member the test stubs (CNewFrontendGameComponent::Init under the INIT opt-in), called qualified on raw storage of the header's size.

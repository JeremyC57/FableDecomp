# Chunk 848 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- (chunk 848) An implicit STB `operator=` (CBaseObject::operator= 0x0099A3B0 plus the PImp copy) is expanded in place only when the cast-map assignments sit inside one single-site `do { } while (0);`. Without it, VC7.1 calls the COMDAT (0x00EA2720 three assignments, 0x00D321C0 `mymap["Hero"] = seh_Hero;`).
- (chunk 848) A sister-wait loop written as a plain `while (!Start...) { NSF; if (T) return; }`, with a row-local inline ~CScriptThing, keeps the temporary dtor expanded and the loop unrotated (0x00D321C0). A declared-only `CCountedPointer<STB>::operator=` spec (0x008AB1E0) keeps that call out of line.
- (chunk 848) A 64-bit UID read in binary is `unsigned __int64 value = ReadUHUGE(); unsigned __int64 uid = value;` with `SetNameForThing(value, ...)` and `NPCNameMap[uid]`. `value` stays in esi:edi, and the address-taken `uid` shares the default-temporary slot. A single named UID (signed or unsigned) leaves a slot residue (0x005253F0 binary path; the same split in the text path makes it worse).
- (chunk 848) `CurrentlyLoading = true; SerialisingGameState = CurrentlyLoading;` gives retail's single store source. Two `= true` stores do not (0x005253F0).

- (chunk 848) CleanOutLine's `[ecx+eax]` index (as opposed to `[eax+ecx]`) needs GetAsCharArray spelled as a preset pointer plus `if`, not `?:` (FABLE_RETAIL_CCHARSTRING_GETASCHARARRAY_SELECT; 0x009BC120, landed 0x009BB0D0).
- (chunk 848) In the STLport set limit filter, the key is a scoped `const long` stored after the null test, and `find(key) != end()` is evaluated find before end(). The tree find is the member template (owner decision D1) and is called out of line at 0x00B2EB20 (0x00B2D9F0).

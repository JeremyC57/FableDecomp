# agentC26 LESSONS (one line each)
- (c2 inliner) The caller-size penalty is a STEP: pen = (sz/2)*(a+g)/9000 only once a+g > 9000 (c2.dll 0x1078D1E2..0x10742BBA); below that it is 0, so it can never add a small amount (+13) to a price; in a 4 KB row (a+g <= 5508) it never applies.
- (c2 inliner) Static site frequency is a second, independent lever: a top-level dead statement with a non-returning arm (`if (0) { NoReturn(); }`) emits nothing, changes no register, and halves the frequency of ALL later code (x0.75 with an inner `if (!c)`); `__assume(c)`, the fable_assert.h dead arm and anything inside an inline helper do not. Check a "wrong price" against a frequency divisor first (tools/krange.py solves the divisor range per decision from one trace).
- (map rows) Retail's Reset<CComponent> split in 0x00603000 and 0x005FF190 = the DEFAULT text at price 95 with the code after the hero block 5.5..6.5x less frequent; no RESET_ELSE_* text and no /d2inlT flag is needed to explain it (original construct not found).
- (0x0061E6D0) An uninitialised TC out-local (`CTCInventoryMap* p; thing.GetTC(id, &p);`) is homed in memory and shifts a whole row's inline budget and frame; retail's `xor reg,reg` just before the inlined lookup says the source wrote `= 0`. That one initialiser replaced six `#pragma inline_depth(0)` devices / a fitted dead assert and fixed the frame size (0x424 -> 0x41C).
- (frame) Find a frame-size surplus with a /FAs listing + efm.py votes (tools/fa.sh): look for an own-slot symbol of ours that retail never stores (retail slot shared with an unrelated symbol) -- that symbol should be a register in retail.
- (FableWin sizes) FableWin's assert has no do-while(0) (a do-while costs 2i/4b at /Od); a mini TU with `template class CCountedPointer<NUISystem::CComponent>;` + fwsize checks every member in 0.7 s (tools/fw.sh, fwv.sh). Instruction counts pin the NUMBER of assert units per member, not their expressions.
- (asserts) "Every FableWin assert leaves dead IL in retail" is false: the FableWin-sized full set overshoots every big row under every non-empty release form; dead-arm assert sets that work are subsets fitted per row (and Get/ctor arms break matched siblings 0x0060C900 / 0x0060EEB0 / 0x0061B610).
- (ordering) Dropping REBIND from landed 0x0061B610 leaves equal size and two `[eax+ebx]` v `[ebx+eax]` operand swaps; a dead Get assert restores them: extra IL shifts c2's symbol ids, so "budget" devices can also be id-order devices.

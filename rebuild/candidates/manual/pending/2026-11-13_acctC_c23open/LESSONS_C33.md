# agentC33 LESSONS (one line each)
- (size residue first) A 133-byte / 12-byte-frame shortfall in an 8 KB builder was ONE missing sub-expression used twice: `!GetPDef().IsNull() &&` before `!GetPDef()->IsVignette` (two CDefPointer temporaries with conditional-destruction flag bits per test). Find missing temporaries by the byte slot / flag bits in the retail frame (tools/slotsr.py: distinct ebp slots retail v ours with access counts) before any allocator work.
- (c2prio) Priority contribution of a candidate in a block = cost x K, K = number of candidates referenced in that block (a write costs 3, a read 1, `push imm8` / byte constants 0); live-through = -K. A forced what-if value that "gives retail" can be decoded into a K (0x005F59C7: textBank 35 = 7 x 5, const -1 piece 40 = 12 x 5 + 6 - 26, i.e. retail's tail block has only the five essential candidates).
- (c2 split pieces) wf.sh forced priorities do not stick on split pieces (re-sort recomputes); tools/lin.py prints a named candidate's piece lineage with the colouring that triggered each split (which constant / entry variable took the register first).
- (extent) A scan that ends in a nonsense instruction (`pushal`) can still have the right LENGTH: the function owns its switch table after `ret` + padding (0x006096E0: ret 4 at 0x0060C8DA, table 0x0060C8E0..0x0060C8FF, next function 0x0060C900).
- (map statements) `GetParentThing().GetCurrentMapNumber()` (C31's lesson) also orders the load in CTCInventory::OpenInventory (0x00585B9E): use it wherever retail loads ParentThing before the receiver's vtable.

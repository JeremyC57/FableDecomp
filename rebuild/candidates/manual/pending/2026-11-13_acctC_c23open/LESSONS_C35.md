# agentC35 LESSONS (one line each)
- (find missing bytes first) Compare CALL TARGET SEQUENCES by address (tools/calls.py: retail targets v our listing symbols through reloc_bindings) and mnemonic histograms (tools/mh.py) before any allocator work: one missing indirect call = a `continue` with its own destructor copy; a moved run of calls = swapped if / else arms (c2 keeps source order of the arms).
- (lens) When one colouring decision cascades, force that ONE root priority with a what-if (tools/lens.sh, wf force1 by name) and compare LINEARLY (tools/lin2.py; difflib mis-aligns repeated blocks): everything that still differs under the lens is either a real source difference (vtable loaded after the argument call = a named argument local; a pointer loaded before the call that takes its holder = a named local before the call) or the next allocation decision.
- (c2 split rule) A root is split when a candidate takes the SECOND callee-saved register (edi) while interfering with it (neighbours left with one register are split), not when the first one (esi) is taken; read the first `-> edi` before the first `split pass over ids` in the c2prio trace to get the real competitor (here `style_count` 109 v top_level 89), then the needed priority delta.
- (c2 dead null store) The `Object = 0` of an expanded CDefPointer / counted-pointer destructor is dropped only for the object destroyed LAST in its scope (and never for an object initialised through a hidden return pointer): a retail destructor without the null store proves a scope boundary right after it.
- (K) Named locals inside an expanded inline helper and address-taken named locals do not change K (copy-forwarded / not candidates); only register-candidate locals of the row do. fwsize differences in helper TEXT (Release through the pointee, GetTC through Find) therefore rarely move priorities, and can break bytes that the tuned text already gives.
- (shell) A grade on a source with a missing #include spins cl until the timeout: preflight with g++ -E after ANY include / opt-in edit, and keep g.sh's timeout short (240 s); kill only your own cl.exe by PID (match your row address in its command line).
- (Anniversary PDB) `llvm-pdbutil dump -symbols` on the repacked 4k PDB gives the memory-homed LOCAL NAMES of a function (S_REGREL32 after its S_GPROC32): weak third source for local names and for which objects are address-taken.

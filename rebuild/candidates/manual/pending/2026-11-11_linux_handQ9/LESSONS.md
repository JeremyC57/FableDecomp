# Chunk Q9 lessons (GOTCHAS-ready one-liners)

- 0x0092B900 CAIStateGroup_OnHeroPush::Update: a member vector written, normalised and then read for atan2 wants ONE reference local (`C3DVector& direction = PushDir;`): VC7.1 then reads X and Y through the same esi base (0x0092BA2C/2E); the plain member spelling folds Y to `[edi+18h]`.
- 0x0092B900: retail's push-vs-facing dot is (Y*Y + Z*Z) + X*X (0x0092BA0B..1D) = the shared FABLE_RETAIL_C3DVECTOR_DOT_GROUPED; the one-line X+Y+Z Dot evaluates X first.
- 0x0092B900: an inlined Normalise that loads X, Y, Z but sums Z*Z, X*X, Y*Y (0x0092B96C..7A) needs the components read into locals first (new opt-in FABLE_RETAIL_C3DVECTOR_NORMALISE_LOCALS); every one-expression sum (GFSqr or plain, any order) loads in its own sum order.
- 0x0092B900: a temporary CCreatureAction_PlayAnimation destroyed through ~CCreatureActionBase 0x00693EF0 directly means no user destructor (new opt-in FABLE_RETAIL_CCREATUREACTION_PLAYANIMATION_IMPLICIT_DTOR); the declared virtual dtor binds ??1CCreatureAction_PlayAnimation@@UAE@XZ, which retail does not call.
- 0x0092ACE0 GoToLibrary: `if (a != OK) return false; else { ... if (b != OK) return false; ... }` keeps the FIRST `return false` copy inline (0x0092AD6A) where two sequential early returns keep the last; `return failed ? false : true;` drops the `xor eax,eax` before `sete al`.
- 0x0092ACE0: `direction /= direction.GetMagnitude2D()` with the one-line `GFFastSqrt(X*X+Y*Y)` gives retail's Y*Y-first sum, the stored reciprocal and the memory-operand Y/Z multiplies (new opt-in FABLE_RETAIL_C3DVECTOR_MAGNITUDE2D); naming `const C3DVector& position = GetPos();` keeps the GetPos call ahead of the pushed LookAtPos arguments.
- 0x00E1CAE0 MonitorMazePhases: per-exit-site inlining of an unused handle's destructor is a pure inline-budget residue: /d2inlT138 plus a scoped `#pragma inline_depth(0)` around the arm's two `IsActiveThreadTerminating()` returns (call 0x007E74D0 at 0x00E1CCC1 stays out of line).
- 0x009F3010 CSurface::ReadOnlyLock: spell a read-only twin exactly as its landed twin (Lock 0x009F33E0, same TU): GetDimensions defined in the TU and auto-inlined, one CSurfaceLockedRect per arm, and the failure arm's C2DExtentsI(0, 0) built through Initialise (`xor eax,eax ; mov edx,eax`, 0x009F3081; opt-in FABLE_RETAIL_C2DEXTENTSI_INITIALISE).
- 0x006AB430 GetMovementBandTypeFromJoytickMagnitude: an else-if chain ending in `else return 3;` makes VC7.1 keep the FIRST copy of each merged return inline (0x006AB495 / 0x006AB4C9); separate `if (...) return` statements keep the last copy.
- 0x006AB430: component flags read through the out-parameter `PeekTC(id, &ptr) && ptr->IsX()` form reuse the component in eax and load the flag into cl (0x006AB464 / 0x006AB504), as the landed GetCurrentMaxMovementSpeed 0x006AB5D0.
- 0x006AB430: FABLE_RETAIL_CTHINGPLAYERCREATURE_VSLOTS2 alone puts GetMaxRunningSpeed at slot 12 (+0x30); retail calls slot 81 (+0x144), which needs FABLE_RETAIL_CTHING_ORIGINAL_VTABLE.
- Migration first: three of the four matches (0x009F3010, 0x006AB430, 0x0092B900) were local-model drafts whose residue went away on the shared headers plus one or two body changes; look for a landed sibling's spelling before probing registers.
- Inline budget: expanded iff sc < T (74) with sc = c1*(1/f + 2)/3 for f >= 1 and c1*(1/f + 6)/7 for f < 1; a `for` with an increment clause keeps the 5x loop frequency after the loop, an if + do-while or a `for(;;)` without the clause does not (0x00E1CAE0 trace).

# Chunk 161 lessons (for GOTCHAS)
- A thing's def read as `ParentThing->PDef->GetSubDef(&out)` through a CDefPointer MEMBER's inline operator-> (into a local declared BEFORE the out pointer) fixes the eax/edx rotation and the late zero store that a raw `(CDefClassBase*)PDef_Object` cast gives (0x705C30).
- An out pointer / component that retail homes in a dead argument slot (and then keeps in a callee-saved register) comes from a `__forceinline` helper that declares the out pointer, calls the lookup and returns the value (0x733950 combo component, 0x670560 particle emitter); together with a CCharString named local in its own `{}` block all of them share the dead slot.
- Empty iterator tags inside STLport inline helpers share the dead slot only when the helpers run in SEPARATE statements; `v.erase(remove(...), v.end())` in one full expression gives erase's tags their own frame word (0x7366C0; write `last = end(); newEnd = remove(...); erase(newEnd, last);`).
- A float zero member stores as an immediate `mov [m],0` per word; long zero members in the same record get a hoisted `xor eax,eax` register (0x732950 CAnimFrameUpdate).
- `CThing* r = 0; ... if (hit) { r = slot->Get(); ...} return r;` keeps the zero in ebx with two epilogues; an early `return 0` / `return crate` after the failed test reuses the tested eax (0x7B6790).
- A CDefPointer local whose destructor has NO null test (`if (--Object->ref == 0) Object->Destroy();`) and which is a copy (not address-taken) gives retail's `dec [ecx+4] ; jne` (0x7B6A80); once the local's address went to GetDef/GetSubDef the same dtor re-reads it after the dec, and an inline Release() or a pointer-local copy gives the counted `lea eax,[r+4] ; dec ; mov [eax],..` form (still open: 0x69A8B0, 0x7366C0, 0x729410).
- Open lane-gap candidate: retail loads a looked-up component used as `this` straight into ecx on both join paths (hit `mov ecx,[eax+4]`, stale `mov ecx,[esp+N]`); every local form tried joins in eax + `mov ecx,eax` (0x732950, 0x733EE0).
- `front()` of an STLport list as a reference adds `add eax,8`; the front node as a pointer local addresses `[node+8+off]` directly (0x7293A0).

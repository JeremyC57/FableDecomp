# NF226 lessons (one line each)
- `#pragma optimize("y", off)` above a row's function also reaches every template COMDAT VC7.1 instantiates at the end of the TU; restore it right after the function (or keep it below the includes) or the owner copies differ.
- Before porting one of a class's special members, objdump the sibling rows: a HEAD stand-in ??_G / vtable COMDAT in another row can reference the symbol the port removes, which makes the rows one unit.
- A header port can turn a non-virtual stand-in call into a direct call to the header's virtual; census that callee too (here SetMetaLayer QAEXJ -> UAEXJ).
- ownwalk.py (retail targets read at each relocation of each owned COMDAT) gives the owners of a whole STL call tree in one pass; a bogus target means that copy's bytes already differ.
- VC7.1 emits unreferenced inline COMDATs that only `.debug$F` names (e.g. ~list -> jmp ~_List_base in a size TU); check objdump -r before treating such a NEQ copy as reachable.
- A fatal cl error (e.g. a header's #error) spins under Wine with no timeout in run_tool: wrap test compiles in a subprocess timeout.
- A test can call / satisfy mangled symbols of a row-local model with `/alternatename` to plain __fastcall stubs, instead of re-modelling the class.

- A repo header that includes its sibling by a bare quoted name (rebuild/include/stlport/fable_string.h -> "fable_containers.h", rebuild/include/fable_string.h -> "stlport/fable_string.h") resolves next to itself first (MSVC searches the includer's directory before INCLUDE), so an overlay copy of the sibling is silently ignored once the repo header is reached first; include the overlaid header first in the TU (it then owns the include guard), and do not overlay fable_string.h itself (two #pragma once files -> C2011 redefinitions).
- VC7.1 hoists the CFilter_Bind2 reference stores (&filterA, &filterB) out of a per-map search loop in retail (0x00603000 [esp+98h]/[esp+9Ch], 0x005FD1D0 [esp+40h]/[esp+44h]); in a big loop body whose temporaries reuse the Bind2 slot it re-stores them every iteration -- GFFilter_Bind2 vs a direct CFilter_Bind2 temporary and named filter locals make no difference.
- `x.f() != y.g()` with both objects from out-of-line getters: VC7.1 evaluates the left object expression first, then the whole right operand, then the rest of the left call -- read which PeekWorld() result feeds which call to recover the operand order (0x00603000: GetRegionNumberFromName is the left operand).
- `if (find(k) != end())` on a const map loads end() before the call; a named iterator (`it = find(k); if (it != end())`) reads [header] after it, as retail does.
- `strcmp(GetStringAsCharArray(i), "LITERAL") == 0` (CDefString::operator==(const char*) inlined) becomes `mov ecx,len+1 ; xor eax,eax ; repe cmpsb` against the literal (0x006045F4); the out-of-line copy 0x005B3440 keeps the two-bytes-per-iteration loop.
- Wine cl also spins on a fatal C1189 #error (not only C1083): engine/CDefString.h needs FABLE_RETAIL_CDEFSTRINGTABLE; engine/CEnginePrimitiveHandle.h needs FABLE_RETAIL_CENGINEPERSISTENTPRIMITIVEBASE.
- CCountedPointer<T>::Reset expansion is decided per call site by VC7.1 (retail 0x005FF190 expands 2 of 9 sites, 0x00603000 expands 10 of 13 and calls the first three); the declaration-only probe gives the all-calls size, so retail size minus that = expansions x ~0x5E.

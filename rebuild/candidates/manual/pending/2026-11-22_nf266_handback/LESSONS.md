# NF266 lessons (one line each)
- A local model that declares every virtual public can bind a whole PDB-protected run wrong, not one slot: read the header's access labels and the PDB name sets for the neighbouring slots before scoping a one-slot access fix.
- A header-based emitter of the same base table (0x006DF800 here) is a cheap "no address gains a spelling" witness for every slot an access respell moves, when no whole-tree census exists for those slots.
- An access-only respell in a row with its own FABLE_STATIC_ASSERTs stays line-neutral with the access labels written on existing lines (`protected: virtual ...;`, `public: <next member>`): the defined set and every COMDAT stay identical.
- A HEAD control can fail the clang precheck on a construct VC7.1 accepts (fable_map.h `erase(first++)` without _POSTINC, C4620): drop it from the link set rather than grade past a failed precheck.
- Include an overlaid header LAST in the row when no shared header includes it: first, its own includes (CCombatActionBase.h) run before CThing / CDefPointer are complete and the size asserts fire.
- The CCombatActionBase.h MELEE branch needs engine/CDefPointer.h (PMeleeAbilityDef) ahead of it.
- A multi-class port onto the shared headers can leave the leaf COMDAT byte-identical (same size and hash): compare the objsyms hash first, then only the relocation symbols that moved matter.
- A clang SLOT=N census is cheap for "which tables bind slot N" questions, but label it clang-only until a VC7.1 object confirms the table is emitted.

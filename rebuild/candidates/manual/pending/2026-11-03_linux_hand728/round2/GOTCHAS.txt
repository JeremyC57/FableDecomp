- VC7.1 LICM across an out-of-line callee: with the callee's template body in the same TU (e.g. CPersistContext::Transfer<T>), VC7.1 sees the callee only reads its `const T&` default and stores a loop-invariant temporary once before the loop; a declaration-only callee re-stores it every iteration (0x006D2BD0; try the same on CQuestManager::TransferBoasts 0x004B05C0).
- Same-TU template body also keeps an address-taken out-param in a register: GetSubDef<T> / CDefinitionManager::GetDef<T>(name) bodies in the TU let VC7.1 cache the CDefPointer across later calls (`dec [ebx+4]` release); declaration-only reloads it (`mov esi,[eax+4] ; dec esi ; mov [eax],esi`) (0x006D0830, 0x006D1E30).
- Implicit const char* -> CCharString temporaries are built BEFORE the other arguments and the object expression; an explicit CCharString("...") temporary is built after them (0x006D0830 movie / quest / text symbol).
- An inline accessor (CWorld::GetMessageEventManager(), GetGameScriptInterface()) as the object expression makes VC7.1 evaluate the object before the arguments; a raw member pointer (`GetWorld().PMessageEventManager_Data->`) evaluates the arguments first (0x006D0830).
- `!thing->IsDead()` compiles to `test byte [x+91h],1 ; jne`; `thing->IsAlive()` (`!Dead` on the bitfield) to `mov dl,[x+91h] ; not dl ; test dl,1` (0x006D0830).
- Retail lays `if (X) { A; return; } rest` blocks after the rest when the source is `if (!X) { rest } else { A }`: VC7.1 keeps source order, so a block found at the function end means an inverted if/else (0x006D0830 divorce / WaitingForSex blocks).
- objdump desyncs on $L labels inside a leaf: collect DISP32 relocations from the leaf header to the next non-$L symbol instead of pairing them with decoded call lines (callchk).
- An inline member body that calls CIntelligentPointer<T>::Get needs T complete at the class definition; define such accessors after the class, guarded on the other header's include guard (CThingAICreature::GetHomeBuilding / CThingBuilding.h).
- hdrcheck2.py writes stubs next to itself (coordinator/stubinc): copy it to scratch to keep agents from writing into the repo (EXTRA_RULES forbid git clean).

# Chunk 217 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- RTM cl 13.10.3077 homes /GS game-event payload locals in the dead `event` argument slot (the chunk-178 lane gap is gone), but an inline GetTC lookup key competes for the same slot: put the payload reads in a `{}` block that closes before the lookup (0x0062C3E0, 0x0062C4B0) or opens after it (0x0062C0E0); a function-scope payload local takes its own frame word (+4 frame).
- VC7.1 lays overloaded virtual functions out in reverse declaration order: declare `GetMapNumberAt(const C2DCoordI&)` before `GetMapNumberAt(const C3DVector&)` to get slots 17/16 (0x004FB160).
- A by-value parameter whose address is passed to an out-of-line template (SGI `__find` 0x0050E540, STLport `_M_insert_overflow` 0x00440990) stays register-held only when the callee body is defined above the caller under `#pragma auto_inline(off)`; with the find body visible and its empty iterator tag taken by const reference (user ctor), the tag lands at the live parameter slot like retail (0x004FEDE0; resolves the wave-25 chunk-149 "tag at an existing slot" shape for that case).
- Same-TU getters compiled earlier (CTCWound::CWound::GetWoundStrength/GetScarStrength) defined above the caller keep member reads cached in edi across the calls (0x00757570).
- Two floats truncated into a `C2DCoordI(long, long)` temporary passed by const reference to an inline accessor give retail's X-then-Y `_ftol2` order with the results in registers; passing them as two plain arguments converts Y first (0x0063D8A0).
- A `C2DCoordI centre(...)` local whose X is register-promoted still reserves both frame words (retail frame 0x14 vs 0x0C with two plain longs; 0x0063E3C0).
- `C3DVector operator*(float f) const { return C3DVector(X*f, Y*f, Z*f); }` spills each product to the frame in X, Y, Z order; a named `result` filled member by member keeps them on the x87 stack (0x00872A20). A vector built from another member's fields (`C3DVector(a.Y, -a.X, 0)`) reads both fields through the member pointer register only as an inline const member of that vector.
- A ternary initialiser choosing between two by-value CWideString calls adds destruction flags; an inline helper with two `return` statements builds straight into the hidden slot (0x004A0780).
- A counted-pointer local declared in its own block shares the frame words of an earlier full-expression temporary (ToWideString result; 0x004FBF60), and the landed Reset body above the caller removes the count-block re-reads around the by-value copy.
- STLport `operator[]` as `*(begin() + n)` also fixes eax/ecx order for 13-byte packed elements (CWorldMap::PlayerPositionInfo, 0x00502500).

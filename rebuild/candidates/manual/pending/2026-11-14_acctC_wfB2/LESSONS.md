- c2 static frequency is purely structural and cheap to measure: a 10-line probe TU with one inline `mark()` per position and the inline tracer prints f per site (wfB2 tools/fq.sh, probe/fq/). Measure the construct before arguing about it.
- `for` with an increment clause leaks: everything after the loop keeps 5 x the pre-loop frequency (so sequential loops multiply); `while` / `for` without increment / do-while do not leak (body 9 or 10, after 1). `break` adds mass, `return` inside a `for` does not reduce the leak.
- Each `&&` operand of an `if` halves the arm (0.25 for two), `||` gives 0.75; a condition with temporaries (bool temp) is one 0.5 test. `if (a && b) return;` leaves 0.75.
- A loop-entry guard c2 folds into the loop's own entry test (`if (!v.empty()) for (...)`, or the iterator declared first and `if (it != end) for (; ...)`) emits no byte, halves the loop body and cuts a `for` leak from 5 to 3. The form that tests before the iterator store is NOT byte-neutral for list loops (je before the store).
- An inline helper cannot change its caller's later frequencies (returns, loops, noreturn checks inside it are invisible after the call).
- Inliner argument savings: `this` = address of a local +3 (lost through a named reference / pointer), +2 per stack argument, +3 for a constant argument; caller-size penalty sz x (a+g)/18000 only above a+g 9000.
- tools/sx.py (frame- and register-masked structural diff of a q.py output) separates statement-shape errors from allocation in one call: row 0x00603000's default source has NO structural hunk except the one Reset expansion.
- The Xbox 360 PDB lists block locals in order per block; a named local there that is a temporary in TLC bytes (HasInformation filter) shows the two texts differ -- check each against bytes before copying.
- (statement shape, cross-jump) A statement retail shows ONCE after an if / else-if chain or a switch (`parent->AddChild(marker)`) may be written in EACH arm: VC7.1 cross-jumps the identical tails, the bytes are the same, but c2's allocator sees the reference in every arm block (large K) and the variable's priority changes function-wide (0x005FF190: `parent` took ebx from the head, 148 -> 46 real hunks; also fixed a `jne ; jmp` branch pair and four switch-case schedules). Try it before any allocator work when a parameter lives in the wrong place.
- (named locals come in pairs) A pointer loaded once and kept in a callee-saved register across a call (`mov esi,[esp+44h]` .. two virtual calls through esi) is a NAMED local used for both calls; if naming it makes the row worse, look for the companion named local in the same loop (0x005FF190: `nameSprite` alone 175 real hunks, plus a named `C2DVector position` in the next arm 6).
- (c2prio as a reader) tools/pp.py + pagg.py on the c2prio JSON show which blocks feed a split piece; a "flip through a whole loop" is usually two candidates one or two priority units apart (0x00603000: `this` piece 33 v list head 32 after GetParentThing() added one candidate to one depth-0 block).
- (reload order) The order of two piece reloads at a block end is not the colouring order of the pieces (same order, different emission in two variants); it follows the piece ids (free-list slots), i.e. the whole split history -- do not chase it with priorities.
- (index loop guard) The byte-neutral loop-entry test for an index loop over a vector of big elements is `i = 0; if (i < v.size()) for (; i < v.size(); ++i)`; `!v.empty()` / `v.size() > 0` emit a second compare when size() is a magic-number divide.
- (assert shape) `if (!(c)) __assume(0);` emits no byte and halves the static frequency of later code like the fitted loop tests do; retail has `__assume(0)` macro bodies elsewhere (CPersistContext). Measured only, not handed back.
- (uninitialised out-local) Retail reading a stale frame word on the not-found path of an inline GetTC (`je` over the store) means the out-local is declared WITHOUT `= 0`.

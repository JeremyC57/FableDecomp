- (c2 scheduler, 0x00B6EDF0) Scheduling regions are 81 tuples cut from the START of the basic block; inline setters called on different array elements (v[i].Set...) get one base each, so every store gets a latency-0 edge to every later store of another element -- store reordering can only happen inside one element. - (bookmark rows) Split the residue first: tools/bk.py prints the load-order pattern (S/C, second pass) AND the `or` destination (state v mask register). A pure `or`-destination swap with equal S/C is a register pick, not a first-pass key wrap.
- (0x00B5CA70) A length gap of 8 bytes per site in a SetPixelShaderConstant run is `or [mem],r` (fused, 6 b) v `mov r2,[mem] / or r2,r / mov [mem],r2` (14 b): the fusion is decided before scheduling, so it is an IL / source fact, not a scheduling tie.

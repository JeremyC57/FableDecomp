# NF269 lessons
- A stand-in binder row's local member names can be the wrong way round (0x00BFDE20 "vertex" block went to DeleteIndexBuffer): take member names from the PDB layout header, checked against which queue each member is pushed to.
- Re-proving a call target also re-identifies the CALLER: the RTTI slot table and the Ego_r order around a binder's neighbours named four of the six stand-in self rows (CWaterPatchMesh, CLandscapeLayerMesh) for free; record them as NAME_FIXES instead of widening the unit.
- A July row on a two-includer candidates header moves cheapest by an opt-in in that header that swaps its stand-ins for the shared headers; the rows only define the macro, and equiv_check over the closure plus objsec ALL_EQ proves it without touching anything else.
- Declared-but-uncalled stand-in members in other rows' local models (OnPostRelocation rows) emit nothing: confirm with the exe scan before counting them as binders.

# chunk 790 lessons (GOTCHAS one-liners)
- 2026-11-06 (chunk 790) VC7.1 canonicalises a flat float sum of products: all 12 term / parenthesis permutations of `a.X*b.X+a.Y*b.Y+a.Z*b.Z` emit identical code, and so does the source operand order inside each product. Only a running sum (`d = p1; d += p2; d += p3;`) changes the emitted term order. Which operand the x87 loads first is still the compiler's choice (KickedChicken 0x00E64210 parked on it).
- 2026-11-06 (chunk 790) A literal product (`0.5f * 0.15915494f`) folds into one __real constant (0.0796) that q.py masks. Keep retail's two fmul with a `static const float` and separate statements, and always run fltchk on a "match".
- 2026-11-06 (chunk 790) Copying a C3DVector local with the user copy ctor lets VC7.1 drop unused field stores. `C3DVector v; v = expr;` (implicit operator=) keeps all three, as retail does.
- 2026-11-06 (chunk 790) A script wait `while (true) { ...; if (x) break; }` is rotated (head duplicated at the bottom). `bool done = false; while (!done) { ... if (a) done = true; else if (b) done = true; }` gives retail's unrotated loop.
- 2026-11-06 (chunk 790) A declared-only explicit specialization of a dtor (`template <> std::vector<CScriptThing, std::allocator<CScriptThing> >::~vector();`, `template <> CCountedPointer<CScriptGameResourceObjectMovieBase>::~CCountedPointer();`) forces the out-of-line call (0x008AC970 / 0x006E7AB0) where retail calls it and plain inline would expand it.
- 2026-11-06 (chunk 790) strchk / fltchk pair relocations by offset, so they only mean something on a MATCH / RELOCATION_MATCH. On a DIFFER row of a different length, compare string order by instruction sequence instead.

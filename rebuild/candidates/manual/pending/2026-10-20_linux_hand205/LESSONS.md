# Chunk 205 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A CTCBase-derived model with an `__int64` member must derive from a real base holding the vptr (engine/CTCBase.h works): a flat `virtual v00(); CThing* ParentThing; ...; unsigned __int64 X;` pads the vptr to 8 and shifts every member by 4 (0x0077B0D0).
- Flat CTCBase models need the explicit `unsigned char _pad0a[2];` after IsInGlobalUpdateTCs (+0x09); forgetting it moves the first derived bool to +0x0A and silently reshapes the whole body (cost three rows a grade each: 0x007F8C20, 0x007469C0, 0x0075C530).
- A by-value CDefPointer temporary read through `.Object` (add-ref + release sharing one null test) picks retail's ecx only when AddRef/Release are inline MEMBERS of the pointee; open-coded `++/--` in the pointer class picks edx (0x0070B4D0).
- Retail's long counted release `mov esi,[eax+4] ; mov ecx,eax ; add eax,4 ; dec esi ; mov edx,esi ; test edx,edx ; mov [eax],esi ; jne` comes from `if (p) p->Release();` with `void Release() { DecRef(); if (GetRefCount() == 0) DeleteThis(); }` on the pointee (0x007E30A0); the short `dec [reg+4] ; jne` form only reproduced when the def pointer sits in a callee-saved register and the release is hand-written `if (def) { if (--def->RefCount == 0) def->Destroy(); }` (0x007F90B0, 0x007F4D50 family).
- `return a + b` over a call expression evaluates the object first only when the callee chain is split into named locals: `const Def* def = Member; CMeshBank* bank = GetWorld()->Bank; bank->Get(def->Index);` keeps def in ebp across GetWorld and reads the field after the call (0x007E30A0); the chained form pushes the argument before GetWorld.
- A manager method called through `GetWorld()->Manager->F(this)` where retail loads the manager into ecx BEFORE pushing the argument is an inline CWorld forwarder (`void F(key) { Manager->F(key); }`), not a local (a local goes through eax and `mov ecx,eax`) (0x0079D020).
- An in-class inline member called from two functions of one TU is inlined in one and emitted out of line for the other (CTCBulletTime StopSound: inlined in ImmediateCancel 0x0079D020, called out of line at 0x0079CEE0 from Pause 0x0079CF30); author the inlining caller with the body as a `__forceinline` member.
- A 3D local with only x and y filled (`C3DVector v; v.X = ...; v.Y = ...;`) explains a frame word that the visible locals do not (0x0075C530, same family as 0x0094FFF0).
- A 2D delta of a by-value C3DVector call result keeps the result pointer in eax (`fld [eax] ; fsub [esi]`) when built by an inline `C2DVector DeltaXY(const C3DVector&, const C3DVector&)` filling a named C2DVector with a memberwise user copy ctor (0x0075C530).
- An `unsigned char` bit read as `mov cl,[m] ; shr cl,5 ; test cl,1` inside an inline IsDead() is an `unsigned short` 1-bit field (an `unsigned char` field gives `test byte ptr [m],20h`) (0x0079CF30/0x0079D020).
- A camera-point flag member assigned twice where the second store depends on the first (`NodeToEndOn = endNode; if (endNode == -1) NodeToEndOn = size() - 1;`) keeps the dead first store in retail but not in the lane once the helper is inlined with a constant (0x0075E270).
- One pointer local reused for two out parameters (`GetOwnerBuilding(&thing)` then `thing = 0` as the hit-thing out of IsLineOfSightFiltered) is what makes the two share one frame word (0x0075DAA0).
- The STLport `vector::size()` loop forms: `i < size()` with an unsigned index gives `jb`, `i != size()` gives `jne`; `(float)(size() - 1)` converts through the unsigned `fild ; test ; jge ; fadd 2^32` path (0x0075CF00, 0x00813B80).
- Two complete `SetText(..., 4, ...)` / `SetText(..., 2, ...)` arms are tail-merged by VC7.1 into `push 1 ; push 0 ; push 0 ; push 4 ; jmp` (0x0072E710) -- write both arms in full.

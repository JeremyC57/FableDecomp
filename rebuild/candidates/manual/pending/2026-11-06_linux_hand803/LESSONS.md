# Chunk 803 lessons (GOTCHAS one-liners)
- Long NScript entity Mains: the main loop is `for (; !false; Game->NewScriptFrame()) { if (IsActiveThreadTerminating()) return _Fail_Val.Return(); ... }` plus a trailing IAT; `while (!IsActiveThreadTerminating())` inverts VC7.1's inline/called choice for the seh_me dtor at the exits (WB 175 lines -> 25 -> match).
- A local CTimer whose index retail keeps in ebp: same-TU `__declspec(noinline) inline` CTimer ctor and dtor bodies under `#pragma auto_inline(off)` (an uncaptured local); the ctor body alone is not enough (0x00E158F0).
- Retail calling the CScriptThing copy 0x004ABE90 means FABLE_RETAIL_CSCRIPTTHING_IMPLICIT_COPY must stay undefined, and a row-local `inline ~CScriptThing() {}` expands every temporary's dtor (BarrelThug 1106 -> 870 lines); retail expanding ~CScriptThing at one exit only is not reproduced by either spelling (SwordCrowd 0x00ED5F50).
- Pause object constructed inline at every site (PauseAllNonScriptedEntities(1) direct) needs FABLE_RETAIL_CWIDESCREENMAGICPAUSEENTITIES_FORCEINLINE_CTOR even in short Mains (BarrelThug, AffairMan).
- `ClearThingHasInformation(Me); EncounterOver = true;` after a yes/no if-else shows as the yes-branch `jmp` into the no-branch tail (retail cross-jumps); inside the else it is 24 lines off (AffairMan 0x00DB09E0).
- CScriptThing::GetPos on a named local expands inline in retail (null check + NullCoord 0x0143E8E0) while a returned temporary stays a vcall: a row-local `__forceinline` GetPos body gives both; plain `inline` calls the COMDAT for the local.
- engine/CV_SwordInTheStoneScript.h declared WatchForDeathDuringSwordPull() with no parameter; the PDB and the landed row take a CScriptThing (fixed in the opt-in branch).
- fable_string.h is `#pragma once`: an hdr/ overlay copy collides with the repo copy (C2011) unless every root-level includer in the chain (here fable_definition_table.h via CDefPointer) is also in the overlay, and the row includes "fable_string.h" first.
- The p.sh g++ precheck greps -E output for "#error" and misses a real #error (gcc prints it on stderr as "error:"): dropping FABLE_RETAIL_DEF_CLASS_BASE hung cl.exe on CDefPointer.h's #error; grep stderr for "#error" too.
- md.py shows masked relocations as `[0x1375748]` vs `[0]` diffs: count only non-reloc lines when judging a near-match.

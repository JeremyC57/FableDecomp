# Chunk 94 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- Two `mov byte ptr [esi+N],0` immediates where the lane emits `xor al,al` + two register stores = `#pragma optimize("s", on)` (the size build prefers the 7-byte immediates when no register is free for reuse) -- the whole CTCInventoryExperience module (0x0056E5EC..0x0057598A) is /Os.
- A `test eax,eax ; jle D / cmp eax,2 ; jle A / cmp eax,5 ; jg D ; B ... ; A ...` ladder is a `switch` with case GROUPS ({1,2} -> A, {3,4,5} -> B): VC's binary-search lowering puts the higher group's body first; the if/else form lays the {1,2} arm out first (0x00572636).
- Twin bodies where one passes `this` (`mov ecx,esi`) to a helper and the other does not, calling the SAME address: the second callee is a static `__stdcall` whose empty body was ICF-folded with the thiscall one (0x0056EC8C / 0x0056ECCB, callee 0x005BC58C `ret 0Ch`).
- A global loaded before a CDefPointer copy's null test/add-ref is read into a local BEFORE the copy is constructed (`long scale = g; CDefPointer def(PDef); x = def->f * scale;`); the plain expression folds it into `imul eax,[g]` after the add-ref (0x00574647).
- `mov bl,al` across a string destructor and a def release, then `test bl,bl ; sete al`: the def copy and the string in an INNER scope, the string a NAMED local (a bare temporary reuses the callee's returned eax instead of `lea eax,[esp+0Ch]`), `return !started;` after the scope, and an `unsigned char` result (bool adds `xor eax,eax`) (0x0061A260).
- CDefPointer local copies in the inventory modules release with NO null test (`dec [p+4] ; jne ; call [vt+4]`), while the CTCTargetingAI one null-tests both ends: model the destructor per module, not one shared CDefPointer (0x0056F26F vs 0x007F59C0).
- A vector member destroyed inline in a destructor that stores its own vtable = `_Destroy_range(first, last, SScalarTag())` (`__fastcall`, last loaded first into edx) + `if (first) free(first)`; the tag lands in the high byte of the `push ecx` frame slot (`lea eax,[esp+7]`) and the base destructor is then a call, not a tail jump (0x00A37360, 0x00AF5900, 0x00B81E60).
- A destructor whose ONLY vtable store is the root's (0x012354D0 CIVCountedPointeeBase) with no base call after it = `__declspec(novtable)` derived class over a root with an inline empty destructor (0x00BCDE40).
- A comparison of a vector's first element and last element written through `list->_M_start` twice re-reads the start after the intervening member store; retail keeps it in esi = a named `first` pointer local (0x0056EF2D -- the remaining regalloc diff is a lane gap).
- `mov eax,ecx` + movzx into eax + `push eax ; call ; ret` (no tail call because the callee takes a stack argument) = /Os; the speed build zero-extends into edx (0x005D8E70).

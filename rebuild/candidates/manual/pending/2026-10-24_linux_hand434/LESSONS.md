# Chunk 434 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A method that calls a small helper and then uses `this` from ecx without ever saving it (no `push esi ; mov esi,ecx`) means the helper's body is compiled earlier in the same TU: VC7.1 tracks the callee's register use and knows ecx survives. Reproduce it with a same-TU stand-in body under `#pragma auto_inline(off)` + `__declspec(noinline)` above the caller (all 15 CheckState callers 0x00C20750..0x00C20EF0; GetLevel 0x00C20BE0 also needs GetActivePlayer's body).
- VC7.1 folds a switch whose cases are all empty to nothing -- `__noop`, `__assume`, dead stores, empty `if`s, empty loops, empty inline or later-defined out-of-line calls all vanish before switch lowering. A retail jump table whose every entry is the same `ret` (0x00C20720, byte table of seven zeroes) is an LTCG artifact: park it after one grade.
- if/else with the same inline `Add` in both arms makes VC7.1 merge the arms behind a selected object pointer (`add esi,8` / `add esi,14h`, then `mov ecx,esi ; push 1`); a `?:` on the list pointer or reference does not (0x00C1E780).
- Hidden-result POD returns: `C3DVector a, b, c; a = x.SwapYZ(); ...` builds every result in one shared temporary and copies it; `C3DVector a = x.SwapYZ();` builds straight into the local. Retail 0x00C1C280 is the assign form (171 vs 111 bytes).
- `bool handled = obj->Virtual(args...); return handled ? 0 : -1;` loads the object and its vtable into callee-saved registers before the argument calls; the one-expression `return obj->Virtual(...) ? 0 : -1;` reloads them after (0x00C1D8C0).
- `value == call()` compiles to `cmp <value reg>,eax`; `call() == value` to `cmp eax,<value reg>` (0x00C1ECF0).
- Zeroing members of a frame struct: `0.0f` float members are stored as immediates (`mov dword ptr [..],0`), integer zeros get CSE'd into a zero register (0x00C20A20); two adjacent member stores at the top of a body came out in reverse source order there (`m_pChannel = channel; m_pPhysicalPlayer = player;` gives retail's +0xA0-first stores).
- In-place x87 rotations: the product of the component that is overwritten first (`s*Y` / `s*X`) must be a named local formed BEFORE the first store, and the sum written `s*Z + c*Y` (that operand order) -- the plain `y = v.Y; v.Y = c*y + s*v.Z` form differs at byte 13. cos/sin/atan are /O2 intrinsics (`fcos`, `fsin`, `fld1 ; fpatan`); use float literals (`1.5707964f`) so the constants become `__real@` pool entries, not named statics (0x00C1C900, 0x00C1C990, 0x00C1CAB0).
- Dense switches returning addresses: the explicit `case 1: case 2: return 0;` arm written last merges with the fall-out `return 0` and lands after the case bodies (0x00C20750); check the table entries by hand.
- libpk sound events: states 2 "Waiting for data", 3 "Waiting for physical player", 4 "Waiting for memory", 5 "Playing using virtual player", 6 "Playing using physical player" (describer 0x00C21040, jump table 0x00C212D8); the event lists of CSoundEventManager are member objects at +0x134 / +0x164 / +0x194 with slot 8 = Remove and slot 9 = Add.
- A probe file with several variant functions compared against one retail row in a single compile (probe/pv.py) is much cheaper than one grade per variant and does not spend the grade budget.

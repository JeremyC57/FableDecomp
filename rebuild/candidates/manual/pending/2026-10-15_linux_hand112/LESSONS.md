# Chunk 112 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A clamp that re-reads the member it just stored (`fcomp [ecx+0B0h]` after `mov [ecx+0B0h],edx`) is an inline helper taking the maximum by const reference (`ClampMax(Health, MaxHealth)`); the plain `if (Health > MaxHealth) Health = MaxHealth;` forwards the stored parameter (`fcomp [esp+8]`) (0x006A5260).
- A by-value CDefPointer copy through an inline `GetDef()` reproduces `inc [ecx+4]` under a null test followed by a release with NO null test (`mov eax,[ecx+4] ... dec eax ; mov [ecx+4],eax ; jne ; call [eax+4]`) when the destructor is `if (--m_pDef->m_refCount == 0) m_pDef->Destroy();`; the read result rides in bl across the release (0x006A5AB0).
- A member pointer null-tested in ecx (`mov ecx,[esi+60h] ; test ecx,ecx`) and re-read for a later call is an inline accessor used at every site; a single named local gives `mov esi,[ecx+60h]` and no re-read; the bare member gives `mov eax,[..] ; test ; mov ecx,eax` (0x006A4F60 vs 0x006A4F10 vs 0x006A4D90).
- `if (Base::F(x)) { ...; return true; } return false;` keeps retail's trailing `xor al,al`; `if (!Base::F(x)) return false;` returns the call's al without it (0x0083D940).
- Zero stores to a temporary emitted as IMMEDIATES after the argument pushes (`mov dword ptr [esp+8],0` x3) are float members zeroed by an inline constructor; integer/pointer members take an `xor eax,eax` register before the pushes (0x006FD170).
- A `#pragma optimize("s", on)` TU does not inline a plain inline `operator()` of a binder (`CFilter_Bind2`): `__forceinline` it; the same member template then reproduces both the bound (0x005800D6) and the out-of-line single-filter instantiation (0x005C0D9D) with retail's register colouring.
- A `??_G` whose user destructor body makes a call (`RemoveFromGlobalTCs()`, `DoStopRunning()`) plus several member destructors needs `__forceinline virtual ~T()` -- the plain inline destructor is called out of line (30v59/30v75) (0x0063A230, 0x0072A450); a small one (one call, one member) inlines without it (0x0077D140).
- Non-virtual deleting destructors catalogued under a class name are often std::pair records: the nested record's implicit destructor puts the inner address in edi (`lea edi,[esi+4] ; lea ecx,[edi+4]`) -- model `struct { CCharString first; CInner second; }` + a `delete` helper (0x004B77A0, 0x006FB730).
- A `__thiscall` helper of the SAME TU called from the graded function must be defined above it under `#pragma auto_inline(off)` (0x00C62400 calls 0x00C623F0).
- CThingSoundEmitter (retail) has a sound object at +0x98 that Ego_r.pdb lacks, and its members are `pack(1)` (PAttachedThing +0x9d); the CThing class operator delete 0x004C73B0 is `static void __fastcall operator delete(void*)` (object in ecx).

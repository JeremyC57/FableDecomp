# NF260 lessons
- A data global's binders are the objects that NAME it, not only the retail referencers: two rows bound the descriptive spelling only from
  an in-class operator new / delete body (UND in the object, no leaf relocation at the address), and eight rows mentioned it only in
  comments. Compile every HEAD source and read leaf relocations plus UND lists before drawing the unit.
- A rename of a global whose type is already right is proven cheaply and completely by objdump: all-section relocation lists equal with
  the old name substituted, .text equal, defined symbols equal. That also settles vtables and pick-any copies for the whole object.
- An add-only header declaration is symbol-identical to a row-local `namespace X { extern ... }`; a row that models the class itself can
  only take the row-local form without becoming a port.
- Time a step before stating that it will not fit: the 54-row vland recheck took about 40 s, not the 15 minutes I assumed.

# Chunk 166 lessons (for GOTCHAS)
- (wave 25, chunk 166) A GetSubDef out pointer whose zero store sits between the owner-def load and its null test is hand-ordered: `CDefClassBase* d = ParentThing->PDef.Object; out.Object = 0; if (d) ++d->m_refCount; d->GetSubDef(&out); if (d && --d->m_refCount == 0) d->Destroy();` (an inline copied CDefPointer puts the zero before the load). Matched 0x5C3057 / 0x59C8F2.
- (wave 25, chunk 166) A persist hook with one Transfer call on a selected pointer (`lea eax,[esp]` / `add eax,18h`) is two complete Transfer arms (save / load) that VC7.1 tail-merges; a pointer-select or ternary form keeps `this`/context in the wrong registers.
- (wave 25, chunk 166) MSVC pads a vptr to 8 bytes when the same class declares a double member: put the vptr in a polymorphic base class so the members start at +4 (0x5C2FE1).
- (wave 25, chunk 166) In a size TU the inline CCharString `operator==(const char*)` (strcmp intrinsic arm) and a C2DBoxF two-vector ctor must be `__forceinline`; the box copies through `lea ecx,[reg+N]` only when C2DVector has a (forceinline) user copy ctor.
- (wave 25, chunk 166) A default element whose non-string members zero with immediate stores has float members; long members share an `xor` register. A caller that loads the vector pointer AFTER the default element is built calls `resize(n, T())` directly; an inlined one-argument `resize(n)` loads the vector first.
- (wave 25, chunk 166) `fldz ; fstp [ebp-4]` plus `fld [ebp-4]` on the miss path is `float r = 0.0f; if (...) r = f(); return r;` (a direct `return f();` folds the miss to a constant load).
- (wave 25, chunk 166) Two by-value `GetPDef()` temporaries in one argument list give retail's edi-first/esi-second add-refs and reverse releases (0x5CCF86 / 0x5C2F27).
- (wave 25, chunk 166) Labels: 0xAF1600 is ~CParticleDataBank; 0x619220/0x6193B0 are a vector resize(n) and CPersistContext_TransferableVector::Resize; 0x5BF414/0x5BF4ED are CTCInventoryBase::UpdateItemStatsForThing / OnItemReturnedToInventory; 0x5CCFFC is CreateTitlePC; 0x437CD0 is CPlayerGui::GetPHeroInfoScreensManager.

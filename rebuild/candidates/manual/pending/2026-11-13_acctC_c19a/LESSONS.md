# agentC19 lessons (one line each)
- (0x00BA5260) A count-sensitive x87 operand-order residue that one dead ruler fixes ANYWHERE in the function is an IL-size residue: fix it with the FableWin-backed text of an expanded helper (fwsize /Od count), here GetAppropriateMipmap 75i -> 81i (named radius, distance in two steps, (float)GetWidth(), GFLimit<long,long,long>).
- fwsize deltas with EQUAL instruction counts and a few bytes difference (CRGBColour ctors +4b, GetScale +2b) are compiler/layout differences of the later FableWin build, not text; chase instruction-count deltas only.
- Before trusting a predecessor's or coordinator's global respelling, check who STORES the global: 0x01436E80 receives `new CEnginePrimitiveRenderer` (landed CEngine::Initialise), 0x01436E78 is the render-time GPPrimitiveRendererSharedData; q.py masks relocations, so a wrong global only shows in vland.
- A TU that needs a callee's body for escape analysis must carry the body text that matches at the callee's own address: prefer the shared-header helpers (CGraphicInfo.h touch opt-ins) over in-row copies; an in-row inline that is not FABLE_FORCEINLINE stays called and costs ~230 bytes.
- An out-of-line function that never writes its bool& parameter (GetReflectionTexture 0x00BA9830: no byte store) is a callee-visibility candidate, but adding it did not move row 2's priorities.
- (0x00BA2350) A forced c2 priority what-if that reproduces the prologue can still be further from retail overall (9412 v 9516 bytes): check the WHOLE row after forcing before calling one decision the root cause.

# Chunk H40e lessons (GOTCHAS-ready one-liners)

- (chunk H40e, 2026-11-11) A script Main whose movie ctor / dtor sites are ALL too hot by one factor (expanded where retail calls, each within 2x of its threshold) wants the loop condition as an `&&`: `for (; !IsActiveThreadTerminating() && true; Game->NewScriptFrame())` runs the body at 2.5x instead of 5x and the folded operand leaves no code (`for (;; NSF) { if (T || false) break; }` is the same thing). 0x00E50FD0: 10022 -> 9882 v 9885, retail's split at every movie and ~STB site (attack ctor 0x00E51149 expanded, third exit pad 0x00E535C1 and phase-0 ctor 0x00E514B8 called). Measure with tools/iv.sh first (28 s, no grade).
- (chunk H40e) Once an inline-budget residue is gone, read the middle of the function again: 0x00E50FD0 had an if / else written in the wrong arm order (`jne` to the else arm at 0x00E51665: write the fall-through arm first) and `EntitySetFacingAngleTowardsThing(Game->GetHero(), Me, false)` with the arguments swapped (retail pushes &Me BEFORE the GetHero call, 0x00E51379), both hidden under 200 lines of split noise.
- (chunk H40e) `xor ebx,ebx ; mov [esp+N],ebx` at the entry of a function whose first statement is a new-expression with temporary arguments is the conditional-temporary flag word's home store (/FA: a $T sharing its slot with later string temporaries): exactly one per function, whatever the number of new-expressions, and an inlined callee's conditional temporaries take bits of the same word. A second zero store into the same slot from another register (0x00E50FDF / 0x00E50FE8) is another variable; not reproduced yet.
- (chunk H40e) c2 does remove a local struct whose only use is its inline zeroing constructor, and a `long done = 0` that is only read in a loop condition: neither leaves an entry store (work/micro/m7.cpp, bb10).
- (chunk H40e) VC7.1 C1001 (ehexcept.c line 1348): a `for` condition `!T() && (true || U(Str("c") + Str("d")))` -- a temporary behind a folded `||` inside a loop condition -- crashes the compiler; do not probe that shape.
- (chunk H40e) c2 cross-jumps two return pads' tails only above a size: with the vtable stored as an 11-byte immediate our exit pads 1 and 2 of 0x00E50FD0 merged, retail's 7-byte register stores (0x00E53580 / 0x00E535B0) stay apart.

# Chunk 286 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- Inline graphic-frame request: when retail tests `Data` (je -> new CFrameData path) and then `Data->Frame` (je -> a separate BeginLoading + return path), write it nested -- `if (Data) { if (Data->Frame) {...; return a;} Data->BeginLoading(); return b; } Data = new CFrameData(this); Data->BeginLoading(); return b;` (0x00B9BCC0). When retail cross-jumps one shared BeginLoading for both, keep the combined `if (Data && Data->Frame) ... else { if (!Data) Data = new ...; BeginLoading; }` (0x00BC7660).

# NF293 lessons (one line each)
- A pointer -> reference respell of a callee is all-or-nothing when the self row defines the stand-in pointer spelling and other binders resolve against it at HEAD: moving one binder alone newly unresolves a reference HEAD resolved (0x00855AF0 v the entry-10 self 0x00857F30). Check the self's DEF before moving binders; a self that already defines the PDB spelling frees every binder.
- decl.py (census rows x non-comment declaration lines, header-only rows counted) is a cheap pre-compile triage: it shows in one pass which binders carry a local pointer model and which bind through a shared header, so only those rows need compiling.
- `*arg` for a reference parameter is byte-neutral whenever the HEAD pointer argument already converted to the parameter's pointer type (derived-to-base included): 51 / 51 rows ALL_EQ. The cases that are not in place are a base-typed argument (CThing* for CThingCreatureBase&: a new cast) and a stand-in type.
- A full include-tree copy as FABLE_HDR_OVERLAY (VC7.1) and NF_TREE (clang) avoids the root-header double-include trap for fable_user_profile.h; equiv_check over two copies plus a planted real token (a comment-only plant flags only by whitespace) proves an add-only opt-in in ~25 min.
- nf.blk() was bounded by the first `}` after `Address =` (safe here: Address is always the block's first field and no field value held a `}`); it now parses the row's own `[pscustomobject]@{ ... }` block, as NF294's fix does.
- A `const` respell of a self can force a stand-in virtual it calls to become const; finding the real slot (count engine/CBankFile.h's virtuals) gave the real name too (0x009CC530: slot 19 is GetEnumerationType, not the made-up GetBankHandle).

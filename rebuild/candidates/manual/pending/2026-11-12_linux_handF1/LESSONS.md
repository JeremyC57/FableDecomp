- A pure copy stage that survives in retail x87 code (a component homed and reloaded with no arithmetic between) is an identity the compiler folds late, not a copy: VC7.1 propagates every C3DVector copy spelling, but `v / 1.0f` (operator/ reciprocal) keeps the stage (0x00878BE0).
- VC7.1 keeps at most two scalar-replaced float fields on the x87 stack at a statement boundary (X, Y enregistered, Z homed): read "which components are in memory" as a count of value stages, then find the source that has that many (0x00878BE0, 0x00BC2480).
- Debug body sizes in FableWin.exe.signatures.tsv (bytes, instructions) pin an accessor's shape: +6 bytes / +2 instructions per term is `mov reg,[ebp-8] ; add eax,[reg+d8]`, a local reference summed field by field, not a chain of accessor calls (0x009E3B60 GetXPosShift).
- Table loads re-read once per accessor instead of shared: the accessors read the table through different spellings (reference local v indexed global); do not look for an aliasing store (0x009E3B60).
- A callee defined earlier in the same source file, and STLport vector operator= / _M_insert_overflow header bodies, must be visible for the caller to keep the array start and a local vector's finish in registers across the calls (0x00AD9770).
- A scale kept as a C3DVector local costs 12 frame bytes even when only Z is homed; three float locals put the homed one in a dead argument slot (0x00BC2480).
- `fld ; fchs ; fstp [matrix]` per element with the translation read last is element-wise assignment; a Set(-a, -b, c, pos) call materialises the negated temporaries first (0x00BC2480).
- `cmp word [thing+8Ch],0` followed by `movzx` of the same word is the thing pointer named in a local after the def pointers are declared: CSE keeps the pointer but not the load through the new name (0x00801920, 0x00801A50).
- An iterator dereference hoisted before the calls of its statement (`mov reg,[it] ; add reg,10h` early) means the tree's const find is declaration-only; with its body visible (FABLE_RETAIL_STLP_TREE_CONSTFIND) the iterator stays in the frame and is read at its argument position (0x00801920).
- A named `control` reference forms the element address first (`mov edi,begin ; add edi,off`); `vector[i]` spelled at each use, with the pure callee's body visible, gives retail's `lea edi,[edx+ecx]` after the first compare (0x00407CD0).
- Two nested inline bool helpers return through an extra temporary (flag in cl, merged compare tails); one flat helper gives `xor al,al` / `mov al,1` and retail's block order (0x00407CD0).
- Pipe fg.py output to a file before `head`: a closed pipe makes it print a BrokenPipe traceback.

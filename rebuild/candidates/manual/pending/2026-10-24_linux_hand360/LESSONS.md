# Chunk 360 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- `_Push_heap` rows are SGI/STLport `__push_heap`: `parent = (hole - 1) / 2; while (hole > top && comp(first[parent], value)) { first[hole] = first[parent]; hole = parent; parent = (hole - 1) / 2; } first[hole] = value;` as an explicit `__fastcall` -- 39 of 40 rows in chunk 360 match with this one body; the Dinkumware `for (...; _Top < _Hole && ...)` spelling flips the test to `cmp ebp,edi ; jge` (0x004CFEB0).
- A /Gr heap helper's `ret N` = 4 (top/bottom) + sizeof(T) + sizeof(Compare): it reads off the comparator size (0x34-byte CThingCompare_BestForTargeting2 at 0x0080A480, 16-byte direction functor at 0x0097ADF0), and a comparator called out of line names the element type through its manifest label (0x00512410 CIsHouseLargerThan -> CThingBuilding*, 0x005140A0).
- Propagated `_Push_heap<float*,...,less<float>>` labels on 4-byte heaps cover pointer heaps with real comparators; `fld [elem+0Ch]` through a loaded pointer = `a->member`, `mov ecx,[parent] ; mov edx,value ; call [esp+N]` = a `bool (__fastcall*)(T*, T*)` taking the pointers by value (0x00932370), `mov ecx,&parent ; lea edx,&value ; call [esp+N]` = one taking `const T&` (0x00AD0920).
- The world-seed coin flip `CDoNotUseBinaryPredicate` in `_Push_heap`/`__unguarded_linear_insert` is `if (Random() & 1) return false; return true;` (`test al,1 ; mov [edi],eax ; jne`); `(Random() & 1) == 0` materialises `not al ; test al,1 ; je` and the const-ref coin of the landed 0x00807520 spills to a `push ecx` frame dword (0x00806990, 0x00806910).
- A 4-byte-element push_heap with two `ret`s (the drop duplicated into the `hole <= top` exit) needs no source change -- VC7.1 tail-duplicates `first[hole] = value` itself (0x005140A0, 0x00776750, 0x00A206F0).
- An unaligned /Os heap helper with an ebp frame, `first` spilled to `[ebp-4]` and `leave` reproduces with `#pragma optimize("s", on)` and the pair's operator= declared out of line (0x004DD875; the comparator and CCharString::operator< `__forceinline`).
- `pair<float, CCharString>` assignment moves the float through eax inside the loop but through `fld/fstp` for the final drop from the by-value slot -- same implicit operator=, no special source (0x004CFE10).
- Wrapping both calls of `f(a.x) > f(b.x)` in an inline helper `Value(p)` makes VC7.1 evaluate the RIGHT operand's call first (0x00807620 probe): keep the calls written inline when retail evaluates left to right.

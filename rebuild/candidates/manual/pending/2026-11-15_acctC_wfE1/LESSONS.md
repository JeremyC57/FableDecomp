# wfE1 LESSONS
- (0x00DB97A0) A script Main's end-of-function dtors (function-scope seh_me etc.) that retail CALLS while ours expands them (f 2.5 after a `for (; true; NSF)` loop): a `#pragma inline_depth(0)` region that ends at the function's own `}` is function-wide (frame and everything change); wrap the body from the first such declaration in a `{ }` block and close the region after the BLOCK's `}` (`#pragma inline_depth()` before the function's `}`).
- (0x00DB97A0) Frame packer order = slot weight / size descending, ties in presort order (tools/pkw.sh + tools/pkn.py, C15 pk probe): a 16-byte seh_me at w104 ties a 4-byte cond-temp flags word at w26 and loses; one more return statement in seh_me's scope (+1 per return) broke the tie the retail way. Measure weights before trying spellings.
- (0x00DB97A0) A post-loop `if (T) return` after an infinite loop puts its return pad in the cold pad area; when the end-of-function dtors are CALLED like the pads, cross-jumping keeps that cold copy and the exit block lands before the outro (6859). Once those dtors are called via the block region (above), the same source lays the exit after the outro as retail.
- (0x00D13580) Two exit pads that retail keeps apart while ours cross-jumps them can be one inline split inside them: here the loop-top pad expands the implicit TeleportData dtor and the cold pad calls its COMDAT; a header that only DECLARES the dtor (old opt-in) makes the pads identical. ct.py found it in one line (6770 -> 6861).
- (0x00D13580) A main loop whose retail head is the condition test reached by `jmp` and whose bottom is `NSF; T; je head; jmp exit` is `for (;; Game->NewScriptFrame()) { if (T) return; if (A || B) break; ... }` (the rotated top T check), not `while (!A && !B) { ...; NSF; if (T) return; }`.
- (0x00D13580) In the c2 static model every `if (T) return;` halves the fall-through frequency: a block after a break-only loop and a few terminate checks is 100x colder than one before; `for (; true; NSF)` restores the post-loop frequency (2.5 x header). Check the trace f of a site retail expands before blaming the threshold.
- (0x00D13580) A cutscene block that retail treats as HOT inside cold surroundings (movie dtor expanded at f ~0.0005 by our model, every other pad cold and in the cold area) takes a LOCAL frequency lever: each `do { } while (0)` multiplies the c2 static frequency of its body by 10 (two nested scopes: x100); a global lever (for(;true;) loop, if/do-while waits) also expands it but moves pads and frame slots elsewhere.
- (0x00D13580) Retail reloading a CSE'd string pointer in the non-null arm of the inline CCharString==text at some compares but not the first = its pieces are 1-ref (dropped) there; ours makes one 2-ref piece per compare (spill 8, eax). c2prio_f.py patched to print piece spill/refs (tools/c2prio_f.py) shows it; IL-identical spellings, implicit operator=, CSE-cap padding do not move it.

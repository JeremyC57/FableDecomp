# Chunk 98 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A virtual (or any) call result narrowed to a SHORT parameter (`thing->SetCurrentMapNumber(map->GetMapNumberAt(pos))`, callee returns `long`) schedules `push eax` before the `mov ecx,<obj>` of the outer call; declaring the callee as returning the parameter's own type (`unsigned short`) puts the `mov ecx` first (0x007233B0).
- `GetWorld()->GetFrame()` with `GetFrame` a STATIC member: VC calls the object expression and drops its result, then calls the static -- the retail `mov ecx,esi ; call A ; call B` pair with no `mov ecx,eax` (0x006AF790).
- A bool:1 copy (`OldMoving = Moving`) reached through a reinterpret view of the header's opaque bit-field bytes must go through ONE reference local (`SFlags& f = Flags(); f.OldMoving = f.Moving;`): two view calls re-read the byte (0x006AF790).
- Returning a global CRightHandedSet by value with a C3DVector that has a user memberwise copy constructor gives "first float through `fld/fstp`, the remaining five dwords through ecx/edx" (POD C3DVector: six dword moves) (0x006B1450).
- A float compare assigned to a bool:1 member (`AffectedByGravity = GetMass() > 0.0f`) compiles to a branch with a per-arm bit insert (`mov al,1 ; xor cl,al ; and cl,al ; xor [m],cl` and the `xor al,al` twin) -- no ternary needed (0x007232E0).
- `!f() && (f() || !(flags & 8))` through an inline predicate reproduces the double virtual call whose second non-null arm jumps to `return 1` (0x006B0190).
- STLport `erase(begin(), end())` on a pointer vector: both `erase` and the trivial-copy helper must be `__forceinline`, and the copy written as an early-out (`if (first == last) return result; n = bytes; return memmove(...) + n;`) to keep retail's unfolded `cmp eax,eax ; jne` with esi saved only on the memmove path; a plain inline erase is called out of line and the lane folds the self-compare (0x007254B0).
- Constructor shells: two bit-field clears and two float zeros all stored BEFORE the vtable in bits-then-floats order are body assignments in that order (as initialisers the floats are stored first) (0x00724F50); a member C3DVector zeroed AFTER the vtable store while a bool is stored before it = the bool a plain initialiser, the vector a member built by its inline value constructor (0x007266C0).
- A member read before a call that the source reads after it: take it into a named local in the order retail reads (`CThing* perceived = ...GetPItem(); CThing* owner = GetThing();`, 0x007447E0; `CThing* owner = ParentThing;` before the string fetch, 0x0079E520). An inline `GetThing()->` inside the expression is hoisted to the prologue.
- Nested call with an object-expression chain (`thing->F(3, pos, GetWorld()->GetWorldMap()->G(pos, 0))`): the inner call's arguments are pushed before the world-map virtual is called, the thing taken into a local first (0x006AFF00).
- The landed out-parameter GetInterface template needs `__forceinline` when the caller is a `__fastcall`/member taking the thing in ecx (a plain template is called out of line) (0x0072AC40).

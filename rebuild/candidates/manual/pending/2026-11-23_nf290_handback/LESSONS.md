# NF290 lessons (one line each)
- A self respell can be byte-equal and still not land: grep the shared headers for an inline body of the same symbol (in-class AND out-of-class `inline`) and compile one includer's HEAD object; a pick-any COMDAT there plus a strong self definition is a new duplicate (0x0049D8F0 v engine/CWorld.h, 0x0093E760 v campfire_types.h / 0x00972CC0). Move only the binders; the self needs the nf86 / nf88 scaffolding.
- The ENTRIES `spellings` column lists one witness per spelling; bind.py over every exe-census row found 11 more wrong binders in entries 29-60 (0x00A57BD0, 0x00AA0DC0, 0x00969470, 0x0097EC00, seven GetRotationInAnimation rows).
- bind.py's xr picks the first symbol containing a bare Leaf name: 0x005DD440 (no Leaf line, catalog name TransferBinaryIn) resolved to the PersistTransferBinaryIn COMDAT and showed `-`; read the object's UND set before calling such a row a non-binder.
- objsec HEAD v new compiles in two work dirs, so anonymous-namespace hashes (?A0x...) differ by path: renames map them in relocations, but `.drectve` /alternatename text needs drectve_eq.py; gen_ren.py now skips ?A0x pairs.
- A stand-in spelling can collide with a different retail function's real symbol: 0x006292D0's `?SetAsPaused@CWorld@@QAEX_N@Z` is the libpk 0x00C1C620 row's public name. Grep the new and the old spelling across all landed DEFs, not only the entry's address.
- Signature triage that needs no compile: a wrong spelling naming a class absent from both PDB name sets (sigdiff.py STANDIN) is a port; so is a call that passes a literal where the PDB wants an enum, a base pointer where it wants a derived one, or a const-returning accessor feeding a stand-in ctor.
- `void*` -> PDB class pointer at a call: the row's own PDB signature (void* destination) plus the callee's PDB type make the cast source-faithful (nf105); look for an earlier landed cast of the same kind in the row (NF93 in 0x00A92740).
- D1c settles clang's "used but not defined in this translation unit" errors in anonymous-namespace STL helper rows (identical own lines at HEAD): cl /Zs new + HEAD, then grade.

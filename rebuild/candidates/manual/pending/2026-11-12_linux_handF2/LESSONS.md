- A named `CCharString symbol("...")` passed to a `const CCharString&` parameter can be an implicit temporary in retail: same construction order, but the frame keeps one word per temporary and the arms' destructor tails merge (0x00406AE0: named local 344v314, `GetTextBySymbol("...")` matches).
- VC7.1 packs frame slots per statement tree: a statement that contains an inline expansion makes every variable of that statement interfere (no slot sharing, no dead-argument-word reuse). Read "which arm reuses which slot" as "which variables belong to one statement" before blaming the allocator (0x00406AE0).
- An inline function used twice in one function is expanded once and called once by VC7.1 itself when its body is in the TU: do not write two functions for it (0x00406AE0 GFIntToWideString).
- A pointer reloaded from its frame slot after `set.insert(p)` (ours) against a register kept across the call (retail) is callee visibility: define FABLE_RETAIL_STLP_MAP + FABLE_RETAIL_STLP_MAP_ORIGINAL_INSERT_BODY so insert_unique / _M_insert are visible (0x009D5BF0, 0x00BE06B0; both went from ~10 bytes off to a match).
- `test esi,esi ; je ; inc [esi]` for a counted pointer stored into a struct is copy construction: an aggregate initialiser `T x = { a, b, ptr };`. Member-wise assignment expands ShareData (0x00BE06B0).
- A dead float compare that survives as `fcomp ; fstp st(0) ; fnstsw ax` with no branch comes from two `return true` statements in different blocks (`if (c) return true; } ... return true;`): the optimiser keeps the test, the later block merge drops only the jump. Side by side they merge early and the whole expression goes; an empty `if` removes its inputs too (0x00909A00).
- `fld [eax+18h] ; add eax,18h ; fld [eax+4]` after a by-value call is a member read through the returned temporary (`f().Peek...()`), not through a named local (0x00909A00).
- When a register tie involves `this` against a loop value, look for a PDB inline accessor on another object (`LevelDown->GetCell(x, y)`): one load of the object per iteration instead of two changes the use counts and the whole assignment (0x00B939E0, 316v336 to match).
- `mov byte [slot],1 ; mov al,[slot]` before a duplicated epilogue is a single `return flag;` reached from an arm that sets the flag, not `flag = true; return flag;` (0x00B939E0).
- A by-value polymorphic temporary whose copy is one vftable store and whose destruction is only the base destructor call has implicit copy constructor and destructor; a user-written empty destructor re-stores the vftable (0x00BCFB00, 341v336 to 336v336).
- Same-size residue that is only the load order of a call's arguments: read them into locals in retail's order before the call (0x00BCFB00: vertex count, primitive count, start index).
- q.py copies the source into its work directory: a variant must be self-contained (a quoted include of a file next to it makes Wine cl hang until the timeout).

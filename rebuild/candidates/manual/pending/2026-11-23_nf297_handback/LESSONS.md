# NF297 lessons (one line each)
- The binding table keeps one witness per (symbol, target), so a header-bound wrong binder can hide behind another row's witness: 0x0040C790 bound ?Save@...@AAEXXZ through fable_user_profile.h's main class (a member, so `private:` compiled) while the table named only 0x0040D400. Run scen / decl over every census row and compile the header-bound ones before sizing an opt-in.
- scen's DECL column misses a declaration inside a local class whose header line it misparses; a compiled control's DEF is the truth (0x00B935C0 DEFINED QAE although scen showed DECL=-). Compile the self as a control in every unit and read its DEF before moving binders.
- A landed test can link the row object against its own stub of the moved callee (0x004022B0's `IsTextureBitDepthSupported(int)` stub): grep every changed row's test for a stub definition of each moved spelling, not only for `#include`s.
- `virtual ~T()` is in place only when the local model is already polymorphic or holds an explicit `void* __vftable` that the hidden vptr can replace; if the base is the non-polymorphic one, make the BASE polymorphic (`virtual void v00();` in place of the member) or the derived -> base reference gains a +4 adjustment.
- A row that DEFINES a derived destructor over the model is not an in-place `virtual` fix: the derived dtor turns virtual and its table changes (entries 20, 78).
- void -> bool on a discarded call, pointer -> reference returns (`->` -> `.`), unsigned <-> signed parameters fed literals, and `long` returns compared with an unsigned member all leave the object byte-identical (17 / 17 ALL_EQ here).
- tools/show.py (wrong spellings + every declaration / call line of the self and census rows on one screen) replaces decl.py + calls.py for most entries; sigdiff's STANDIN flag alone settles the stand-in-typed ones.

# Chunk H40g lessons (GOTCHAS-ready one-liners)

- (chunk H40g, 2026-11-11) A profile / progress marker whose string is re-addressed after its constructor (`call ??0CCharString ; xor edx,edx ; lea ecx,[esp+2Ch] ; call StartProfile`, 0x00507C9F..0x00507CB7) is a NAMED CCharString in an inline helper taking `const char*`; a `CCharString("...")` temporary passes the constructor's eax instead (`mov ecx,eax`).
- (chunk H40g) `throw CGenericException()` (empty class, throw info 0x013692F8) copies one uninitialised byte from the temporary's slot, and VC7.1 may colour that slot with a live bool (0x00508328 reads [esp+13h] = loadedOnPlayerProximity): do not model it as throwing the bool.
- (chunk H40g) An if / else-if keyword ladder over one CCharString with the inline `operator==(const char*)` (null string: strcmp against "") comes out in retail as TWO full chains behind one null test (0x00507EAE: 24 `repe cmpsb` blocks, then 24 calls of 0x004115A0 on esi). VC7.1 only does that when it keeps the PStringData in a register across the out-of-line compares; `/Oa`, `#pragma optimize("a")` and a visible CBasicString operator== body do not get it (0x00507C30, open).
- (chunk H40g) Stack-argument bookkeeping for nested fastcall string operators: read each `lea reg,[esp+N]` minus 4 per outstanding push to recover the slot; 0x0041A060 looks like a two-argument thiscall at 0x00508738 but takes none (hidden return in ecx) -- the two pushes belong to ToCharString's return slot and to the following operator+.

# Chunk 4007 -- lessons from the authoring agent (fold into GOTCHAS at landing)
- `if (a || b) X else Y`: VC7.1 places X after Y (both tests jump forward to X), and X's inline decisions are made first, in source order. When retail has a late block whose decisions look "pre-penalty" (everything expanded) behind a block that is under the caller-size penalty, try the `||` form with the late block first (0x0061B610: 0x0061D383 / 0x0061D3E2 jump to 0x0061DAEC; +110 equal instructions and the block's whole call set in one edit).
- A second `||` / `&&` operand with temporaries gets conditional-destruction flags; an inline bool function removes them. Look for the function: `tools/xref.py <callee>` found a third caller of 0x004B1270, the out-of-line copy 0x0061A260 of the inline member the two big rows expand, and the PDB had its name (IsQuestCardAvailable).
- The body of an inlined bool helper is code in the caller: `if (x) return false; return true;` folds away, `return !x;` and `return x == false;` leave a bool candidate that moved 149 instructions' worth of choices in a 12 KB caller.
- `if (n != 0)` in front of a `for` halves the static frequency of the loop body (2.5x instead of 5x) with no code change; it is the only per-quest loop spelling of six that lowers it (do-while 10x, while / for(;;)+break / goto 9x).
- `~_List_base` and `list::_M_insert_dispatch` score above c1'*(1/f+2)/3 (not by a constant factor); `_M_insert_dispatch` is called at pen 0 up to about f 14 and expanded above, `~_List_base` is expanded at pen 0 from f ~1.2 and never once the penalty is on (below f ~23).
- A full direct-call comparison (retail call targets v the object's DISP32 symbols, `tools/cd.sh`) finds every wrong inline decision of a large row in one line each; use it before reading diffs.
- Ruler diagnostics: one dead `{ CCountedPointer<CAction> r(new CAction); r->ActionType = ..; }` group is ~325 IL tuples of caller size. Never a hand-in.
- FableWin `signatures.tsv` lists the member names of a class (`awk '$2 ~ /@CTCInventoryQuests@@/'`): quickest way to name an inline helper found in a body.
- FableWin's signature list also says which TEMPLATE INSTANTIATIONS a function uses: a class with only the one-argument `??$GetTC@V<T>@@@CThing@@QAE_NPAP..` and no two-argument one means the original called `GetTC(&tc)`. The spelling changes no byte by itself but adds inline layers (IL), which decided the last residue here.
- A residue that 24..200 dead statements anywhere in the function flip (and that IL in another function does not) is an IL-amount effect (here: SIB base/index order in an expanded loop). Use the ruler only to MEASURE the distance, then look for the layers FableWin proves (accessors through smart-pointer operators, forwarding constructors, one-argument templates). The same amount is what the inline-budget debt at a later call site was missing.
- pd.py masks branch targets: run a branch-target check (tools/bt.sh) once a big row is close; a statement block in the wrong arm hides behind equal instructions.
- FableWin was built by a newer compiler: a virtual call is `mov edx,[eax+N]; call edx` there (+1 instruction, +2 bytes), uchar arguments use movzx; helpers first instantiated in a size-optimised TU have the `#pragma optimize("s", on)` form (-1 instruction with `leave`). Compare instruction counts with those three shifts in mind.
- A behaviour test's retail expectation can be cut straight from the decoded call map (map/ev0.txt) with per-run address ranges for the arms not taken; where retail lays an else arm before its if arm (take v unavailable here) the ranges still work because each run takes one of them.

# Chunk 328 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A bool bit-field written through a temporary pointer (`GetAICreature()->ImmuneToAttack = false;`) compiles to `mov cl,[eax+N] ; add eax,N ; and cl,.. ; mov [eax],cl`; through a NAMED local (`CThingAICreature* c = GetAICreature(); c->ImmuneToAttack = false;`) it is retail's `and byte ptr [eax+N],0BFh` / `mov cl ; or cl,40h ; mov [eax+N],cl` (0x00923DA0, 0x00923E10).
- CArray<T>::DeallocateUnusedMemory (STLport-vector CArray) = `if (capacity() > size()) { CArray<T> temp; temp.reserve(size()); temp.insert(temp.begin(), begin(), end()); DeallocateMemory(); p = Exchange(_M_start, temp._M_start); l = Exchange(_M_finish, temp._M_finish); _M_end_of_storage = temp._M_end_of_storage; DestroyRange(p, l); if (p) free(p); }` with a destructor-less temporary; the honest `swap(temp)` + inline temp destructor keeps dead stores into the escaped temporary (189v180). Five instantiations match (0x0051B560, 0x005E3920, 0x006FD0B0, 0x009E7C70 + DeallocateMemory twins).
- Trivially destructible CArray DeallocateUnusedMemory instantiations (0x009B79B0, 0x009B6EB0, 0x00A725D0, 0x009B5DB0) keep a one-mov scheduling diff: retail tests the old start for the free before loading the temporary's start word.
- Kraken creature actions (and any CCombatActionBase child): vtable slot 3 = PerformAction, 4 = FinishAction, 12 = Initialise, 56 = FrameUpdate. A FinishAction that builds the next action is `Creature().SetCurrentAction(CNext(Creature(), *PTarget.GetPItem(), 0, false));` behind a two-fetch inline `PTarget.GetPItem() && !(PTarget.GetPItem()->m_flags91 & 1)` (0x00924A90, 0x00924670); the same form with a 3-argument ctor (0x00924880) picks other registers (parked).
- `if (!Interrupt && kraken->HasTargetBeenHit()) { if (!Interrupt) FinishAction(); }` reproduces the member re-read after the bool call (0x009242D0 / 0x00924040).
- CBasicString length bump: `unsigned long n = StringLength + len; StringLength = n; PData[n] = 0;` stores straight from eax; `StringLength += len; PData[StringLength] = 0;` adds a register copy (0x009A06B0).
- A size-checked allocate-and-construct template returns through the shared epilogue only when written `if (valid) { ...; return objects; } return 0;`; the early `if (!valid) return 0;` form duplicates the epilogue and adds an aligned loop entry jump (0x00BFBC80).
- CCountedPointer::operator= whose source words are loaded at entry (ebp/edi) and whose data store sits inside the different-block arm: read `other.Data` / `other.Info` into locals first, then `if (Info != info) { Release(); Data = data; Info = info; if (info) ++info->RefCount; }` (0x00AD1FC0). The CCPPointerInfo DeleteFunc is called with the data in ecx: model it `void (__fastcall*)(void*)`.
- `GetWorldFrame() + (long)(expr)` adds into esi (`add esi,eax`); with the conversion in a named `long delay` local VC adds into eax like retail (0x009350C0).
- CDynamicObjectHeap::CreateMoreBlocks's doubled entry-link store is `entry->NextEntry = FreeList; Free(entry);` (the inline Free re-reads FreeList after the aliasing store) (0x00AF88F0).

# Inputs, observed ordering, and portable behavior

The whole native function546bytes is exact after relocation rebinding. It computes distance to the node box, upward/downward LOD margins, and puts the smaller margin into a sphere centered on the *current* camera position. The original debug-only assertion uses current_lod, while release leaves the argument unused.

Camera/renderer pointers and the SubNode discriminator follow native aliasing behavior: virtual IsPatch may change either global or the node's SubNode; the code rereads the current patch and globals at the original points. Fixtures exercise all three mutations, including replacing the patch and nulling it.

The normal coordinate contract is finite IEEE single coordinates, ordered Min/Max per axis, and round-to-nearest arithmetic. A box may have zero extent; a sphere radius may be negative. Renderer band indices must have valid backing. Both native and original debug source inspect the remap of band+1 before checking whether that index is less than8. The real release member is eight CLODLoadInfo entries; native sentinel read at index8 overlaps AsyncLoadTask's low byte. The portable semantic fixture declares nine actual entries, with a controlled sentinel, so the full copied function can test this behavior without undefined array access. This does not change or enlarge the reconstructed native class.

The existing C3DBoundingBoxSSE.h helper has a portable twin. Windows tests call the actual shared SSE macro and the twin separately; finite results and non-NaN signed-zero/Inf edge results compare all32bits. Generated finite inputs and all11760 full-function cases pass. A separate exploratory multi-NaN edge sweep compares NaN classification.

**Portability limitation:** a stricter exploratory multi-NaN test exposed a pre-existing x87 versus SSE NaN-payload-selection difference in this shared helper. No source-level NaN payload contract was proved. NaN payload identity is not claimed; no old helper path was changed to hide this observation. The failing strict-payload source is preserved in private_evidence/00bf7bc0_test_strict_nan_payload_FAILED.cpp and its failing VC_RUN log remains under runtime/behavior_tests/00bf7bc0. The final full-body fixture explicitly checks NaN classification, and exact bits for every non-NaN result. Engine-valid finite coordinates are not affected.

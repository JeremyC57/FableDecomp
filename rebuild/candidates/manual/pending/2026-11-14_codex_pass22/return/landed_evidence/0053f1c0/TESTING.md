# Behavior validation

The standalone fixture pastes the complete selected target body verbatim. Shared real C2DBoxF/C2DExtentsF/C2DVector, CUIState, counted/def pointer and original vendor map/vector implementations run with controlled original external UI interfaces. It checks28672 combinations of child/fake-child lists, scrollbar exclusion, scroll direction, zero/positive/negative extents, drag/Changed state, existing/missing state-map entries, UI scale and definition mutation during ChangeZoom. Assertions check every callback, clip-box mutation, displayed zoom/position, action limits, final base update, and reference/lifetime balance. A separate720-case insertion suite covers every permutation of five keys plus begin/end/duplicate hints.

VC71 /Od /W3 /GR- without /EHsc links the two freshly rebuilt library objects first. All14 selected library bodies are verified in the actual executed PE. GCC64 -std=c++03 -O0 runs the same fixture and original vendor algorithms; the original vendor no-exceptions option avoids mixing 2003 STLport range exceptions with modern libstdc++. Host long/pointers retain their real widths; only fixture ABI size assertions are disabled. Production types/headers remain unchanged. Both print exactly0053f1c0_TEST PASS. These are controlled interface tests, not a full game/UI integration run.

The inherited unfinished fixture had an invalid CResource boundary method, a const-adoption constructor mismatch and independent ownership blocks for shared children. Main fixed those fixture problems, retained the original receipt, and tested real shared ownership. None was a production algorithm change.

# Native behavior and test domain

A timer is registered before the first termination guard and initialized with rand()%90. If the prisoner was not already released, a cell-door wrapper remains alive through release conversations; null implementation makes MsgIsUsedBy false. The hero escape flag chooses RELEASE versus IDLE. A successful comment is followed by a termination guard, then a30-frame reset. Door use waits for the parent's existing conversation, creates the FREE conversation and sets ReleasedAndFollowing. The script then enables follow/persistence/faction in the observed order.

Until PrisonCourtyard is loaded, each iteration advances a frame before its guard and COURTYARD/hit reactions. Region loading during that frame does not suppress the current iteration. After a post-loop guard it disables cross-region following, then runs an endless GUARDS loop with NewScriptFrame in its increment. A direct hero hit qualifies; otherwise an ability hit qualifies only if it is not the healing ability14. Hit conversations do not reset the talk timer. Only explicit termination guards exit Main.

The fixture calls the complete production body98304 times and exercises actual CCountedPointer release/copy ownership for the cell-door wrapper. Callee fixtures assert exact strings, IDs, booleans, hero/prisoner identities,30-frame resets,3.0f follow distance, phase order, conversation sequencing and cleanup. Stop n action traces are exact prefixes of stop n+1. No callbacks occur after the terminating guard except required timer/handle destruction. The timer is deregistered exactly once on every cut, and each allocated cell-door implementation is destroyed once. Empty handles are supported.

All inputs are small signed32-representable values, while real host long/pointer widths are retained on g++64. No NaN, overflow, unaligned access or fabricated object layout is used. Fixture ABI adapter disables native-size assertions only; it does not replace the shared ownership implementation. Native/code matching and behavior coverage are separate evidence, not a claim to model the entire game.

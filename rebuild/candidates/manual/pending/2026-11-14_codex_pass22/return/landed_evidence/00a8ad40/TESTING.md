# Behavioral and ABI verification

10,256 complete-body cases pass VC7.1 RTM /Od /W3 /GR- without /EHsc and g++ -std=c++03 on64bit. Exhaustive small grids cover material/primitive/bone counts0..3, discard/stats/cloth booleans, all3allocation-failure positions, and every primitive failure or success. A separately written event oracle checks every read and allocation size, initialization, material/primitive call, primitive pointer advance, lock/unlock order, early exits and final guard cleanup.16large-count cases cover all three overflow guards and32bit wrapped intermediate arithmetic, stopping allocations before unsafe large buffers.

The source function is copied in full into the standalone fixture. Its ONLY textual adaptation is sizeof(T)->FIXTURE_SIZEOF(T), which casts to unsigned int so64bit host size_t does not widen original32bit arithmetic. Dependency fixtures are controlled test doubles, not production class models. Shared production classes are checked independently by24native32layout assertions. Source/body equality and test hashes are enforced by review/main_00a8ad40/final_audit.py. Stream underflow internals are an existing shared dependency and are not simulated; the target read dispatch and failure paths are covered.

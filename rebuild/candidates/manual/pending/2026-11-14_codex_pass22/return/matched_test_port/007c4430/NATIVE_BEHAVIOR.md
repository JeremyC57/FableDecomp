The level chooses one of four attached continuous-heal sounds if the parent has a sound component. The original parent local is CThingCreatureBase&. A live Z-target is selected when targeting is present and the player is Z-targeting; an enemy target falls back to the caster. The root creature pointer starts null, is assigned under the creature type flag, and is checked by two original nested IS_THING_ALIVE calls before healing. Every initial recipient gains a heal-list entry, null effect slot and zero health accumulator. When the def supplies a named effect, the spell creates its particle; a live particle is attached and stored. The recipient's events component receives original hit-by-special-ability parameters.

A self cast searches the rough area with original IsNot/In2DRange filters, appending creature handles. The loop skips its already-added target. Every other appended creature gets an effect/accumulator slot; live non-enemies receive particle/event work. Dead/enemy recipients remain in the list and retain their null effect/zero accumulator slots. Actual shared reference counts and container ordering are observed in the fixture.

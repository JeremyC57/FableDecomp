# Behavior and supported input invariants

If there is no shopkeeper component or associated shop, terminate immediately. Otherwise mark stock state unknown. Outside opening hours, request occupied/free sale places and iterate the owning shop's original object list. Each live created entity with a base definition and StockItem subdefinition chooses the nearest sale place, retaining its own position when no place exists and choosing the first tied place. Walk there, look at it and put it away. Move/look failures or subsequent death/null intelligent pointers terminate before the action and final stock-state update. During opening hours, process min(place count,item count), run to the first place and walk to later places, then look and get out the item. PerformActionAndWait's result is ignored in both branches. Set final stock state only on completion and terminate once.

GetSubDef returns false when there is no matching subdef info and leaves its output untouched. Existing info returns true even if the manager result is null. The actual CDefPointer conversion, assignment and destructors balance reference counts for new, null, existing and same-object output cases. Native release code intentionally omits the debug cast check, so the manager's definition type must match the requested StockItem type.

Component presence bits and map entries must be consistent and designate the actual component type. Native GetTC's miss-after-presence path can select end()->second; fixtures never claim that inconsistent map state is a valid input. Source list nodes/vector elements remain alive across their uses, while an AI action may make the intelligent object pointer null or mark its thing dead. Fixtures cover both. Sorted LowerBound input uses real array backing, even for an empty range, avoiding null-pointer subtraction and invalid accesses.

All input positions are small exact binary integers; nearest-place comparisons reduce to exact integer distances in the fixture. Scalar1.4f and0.0027777f are the actual production parameter values and are checked as the compiled float constants, not used as approximate fixture geometry. Counts/refcounts/indices remain small signed32-representable values on both32/64-bit hosts. No claims about NaN, overflow, alias-violating input or the full game's mutable world are made.

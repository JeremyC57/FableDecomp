# Native behavior and portable fixture invariants

The function searches a sorted cache by circle segment count. A hit shares the existing counted buffer temporarily and selects it. A miss allocates a raw32-byte vertex buffer with segments+2 entries, writes the center position only, writes segments+1 perimeter vertices with cosine/-sine positions, zero normal and zero UV, unlocks it and inserts an owning cache entry. Selection calls the real inline SelectVertexBuffer interface, which forwards stream0, buffer handle, offset0 and the buffer stride to SetStreamSource. The temporary counted owner is released after selection.

The center's20 bytes after XYZ are *unwritten observed native behavior*. Fixtures begin the backing storage with a known byte pattern, start real vertex object lifetimes by placement default-initialization, and inspect these bytes as unsigned char rather than reading indeterminate float values. Each perimeter vertex is fully initialized. The test does not zero the whole buffer and does not use T() as a substitute for native uninitialized storage.

Normal inputs have positive segment counts, representable allocation counts/byte sizes, successful allocations/locks and a sorted cache of valid counted buffers. Zero segments would divide by zero; the source preserves this native absence of a guard. Fixtures cover1..26 and boundary/phase counts31/32/33,63/64/65,127/128/129,255/256/257 and1024. The external mutable lookup table uses controlled exact binary fractions; no retail lookup table bytes are copied or claimed. Interpolation indices and quarter-turn shift are checked independently against an explicit nearest-even reference.

The portable fixture uses typed64-bit pointers and size_t, with small keys, counts and reference counts so no long64 overflow assumption enters. Empty ranges have real nonnull backing. Every object copied/destroyed by the actual STLport helper bodies has a started lifetime and valid storage.

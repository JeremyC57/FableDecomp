On the second consecutive invisible frame it clears both child slots (incrementing the index twice) or both owned persistent handles, then returns. Offscreen position likewise clears immediately. The original upper-screen comparisons have no lower-screen rejection. Visible drawing selects relative or absolute zoom, aligns the x coordinate, rounds x/y with GFFloatToLongNear, creates text and a two-unit bottom-right shadow, and submits child or persistent primitives. Unavailable swaps text/shadow colours. Actual original scopes and direct returns are preserved.

The full fixture uses the actual descriptor/base/colour/vector bodies, original counted pointer and handle ownership operations, and the complete Draw body.

## 0x006D8F10

- (wf16f, 0x006D8F10) A callee-saved register saved mid-body in straight-line code (`push ebp` / `pop ebp` around a run of inlined calls) is decided against the OTHER saved registers: VC7.1 only nests the save when every register pushed before it (ebx) has no hoistable restore, i.e. the blocks that use it are not post-dominated by a block inside or before the range. A dead-end block does that: `default: { __assume(0); }` (braced, as a NODEFAULT / ASSERT(false) macro expands) survives to register allocation; a bare `default: __assume(0);` is pruned early and does not. Probe for it with an early `if (g) return;` after the first use of the outer register: if the wrap appears, look for an unreachable arm in an inlined switch.
- (wf16f) VC7.1 keeps a dead-end switch arm's range check only while the arm emits code; an empty unreachable default drops the `dec eax ; jne` -- so a 2-way `sub eax,N ; je` over two named cases is the signature of an unreachable default, not of `case A / default`.
- (wf16f) `__assume` anywhere in a function stops VC7.1 forwarding a by-value float parameter of an inlined callee (it gets a frame home: `push ecx` local, `mov [esp+N],eax`); the float traits writer takes `const float&` (FableWin ?TransferBinaryOut@?$CPersistTraits@M@@...ABM@Z), which is also what keeps the code clean.
- (wf16f) VC7.1 uses a visible out-of-line callee's mod/ref to delete a constructor store into an object whose address it passes as `this` (CPersistTraits<float>() DefaultVal store vanishes once TransferBinaryIn's body is in the TU, any of inline noinline / plain noinline / auto_inline off).

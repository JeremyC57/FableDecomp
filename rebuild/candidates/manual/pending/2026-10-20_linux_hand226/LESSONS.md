# Chunk 226 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A loop with `lea edi,[ebx+N]` before it and both registers stepped by the element size is a per-iteration reference to a member sub-object (`CComponentInstance& instance = it->second;`); reading `it->second.X` directly folds the offsets into one register (0x00AF3DC0, CParticleSystem component loops).
- Two zero-initialised float locals whose stores straddle an `fld ; fcomp` sequence: the first-declared one stores before the fcomp (0x00AF3DC0).
- Retail NParticleEngine::CParticleSystem sits below Ego_r.pdb from Components on: CVectorMap 0x10 (PDB 0x14), STLport lists 4 bytes (PDB 12), CParticleUpdateParameters 0x24 (PDB 0x2C): Particles +0x1C, Decals +0x20, UpdateParameters +0x24, NoActiveParticles/Decals +0x48/+0x4C, flag byte +0x50, GlobalAlpha +0x54, Scale +0x60 (0x00AF4100, 0x00AF43B0, 0x00AF59A0). Component entries are pair<EPSCType, CComponentInstance> (0x18; instance vptr 0x0129F478, counted component +4/+8, Enabled +0xC).
- Two virtual calls compared with `==` on the right of `&&` are evaluated right-call-first by VC7.1; retail's left-first order (and `cmp left,right`) comes from an inline bool helper on the left object (`return GetType() == other.GetType();`) (0x00AF4EE0). The same `==` as a whole `if` condition evaluates left first (0x00AF4100).
- A by-reference iterator whose node stays cached in a register across the call (`lea eax,[esp+N] ; push eax ; call ; mov edi,[ebx+8]`) means the callee is defined earlier in the same TU and only reads it: a stand-in body above under `auto_inline(off)` (0x00AF5770 over ClearDecal 0x00AF5430).
- A call argument chosen per arm with the common pushes hoisted above the branch (`push ebp ; je ; push ebx ; jmp ; push [esp+18h] ; call`) is an if/else of two complete calls that VC tail-merges; the ternary argument form selects through a frame temporary (0x00AEB990).
- A local STLport list whose head node stays in a register across calls that take the list by reference (and is homed in a dead argument slot) needs those callees' bodies above under `auto_inline(off)` -- without them VC reloads the head and gives the list its own frame slot (0x00AEB990: real list::clear 0x00AEC840 plus a stand-in FindVisible).
- In this module STLport vector destructors split by element cost: a vector of intelligent pointers (virtual dtor) inlines `_Destroy(first, last)` (end loaded first, `push 0 ; call [vtable]` per element), a vector of counted pointers calls the out-of-line `__fastcall _Destroy_range(first, last, const allocator&)` with the allocator temporary in the top byte of the `push ecx` word (0x00693EF0, 0x0098ABF0, 0x00562FF0).
- engine/CCreatureActionBase.h keeps Ego_r.pdb container sizes (0x10): retail CutSceneEvents is +0x90 and DependentThings +0x9C (0x00693EF0).
- `imul 2AAAAAABh` with no following `sar` divides by 6 (sar 1 = 12, sar 2 = 24): CPhysicsMesh's C3DTriangle2 face indices are three unsigned shorts (0x00A6DA40).
- `C3DVector e = b - a;` lets VC7.1 build the inline operator result straight into `e`; retail's frame temporary plus integer-move copy (and a later local reusing that temporary's slot) is a default-constructed local assigned the result (`C3DVector e; e = b - a;`) (0x00A42170).
- The wide `== L""` split works like the narrow one: `if (!block) { if (wcscmp(L"", L"") == 0) goto empty; } else if (size == 0 && MemCmp_Unsigned16(start, L"", 0) == 0) goto empty;` -- STLport's size compare shows as `sub ; test eax,0FFFFFFFEh` (0x004FDAB0).
- `push eax ; mov ecx,eax` with a single `lea eax,[obj]` for `obj.F(obj, ...)` comes from an inline wrapper passing `*this`; calling `obj.F(obj, ...)` directly re-forms the address with a second `lea` (0x00ADF300).
- Frame-slot sharing between an out-parameter local and a later operator temporary follows block scope: in 0x00815AA0 only the second out vector in an inner `{}` block (with the statement that consumes it) reproduces retail's 0x24 frame (both outer: 0x30; both inner: 0x18).
- The CPersistContext::Transfer<T> enum template (closed-enum switch, `default: __assume(0)`, cases 4..0) also covers the string and intelligent-pointer instantiations (0x004109A0 CCharString, 0x00410AC0 CWideString, 0x006C9A10 CIntelligentPointer<CThing>): the traits' `T DefaultVal` is constructed before the jump (in the dead `name` slot when 4 bytes wide) and destroyed on every exit; all three park on one shape (case 0 pops the shrink-wrapped ebx before the traits destructor) plus, for the intelligent pointer, the inline-once operator= band.
- TransferVectorOfSubComponents rows that `resize(n, T())` take the landed 0x0067D6B0 template with an STLport `resize(n, const T&)`; the size-optimised copies (0x00476E3E/0x00477CD2, `idiv`, biased `lea ebp,[esp-74h]` frame from `optimize("s", on)` alone -- adding `("y", off)` gives `mov ebp,esp`) park on a this-spill vs loop-offset register choice.

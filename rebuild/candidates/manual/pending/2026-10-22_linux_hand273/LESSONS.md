# Chunk 273 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- Address-taken pointer kept in a register (004c9d60 AddTC). Retail stores the new TC into a dead argument slot right after the call (`mov [esp+14h],edi`) but uses edi everywhere; the slot is only passed by address at the very end (list push_back). The shape is a second local copied right after the call (`CTCBase* updateEntry = tc;`) and passed by reference at the end. Passing `tc` itself by reference moves every use to memory; an inline by-value wrapper keeps the register but stores the copy late.
- `__declspec(noreturn)` on abort is needed when retail falls through from the bitset range check (`call puts ; call abort ; mov ecx,eax`) and keeps using the tested value. Without it, VC copies the position to a callee-saved register.
- When retail inserts into a CVectorMap and then sorts without testing Dirty, it is `Add()` followed by a Resort() that sorts and clears Dirty (0x004CD650's body). `Sort()` with the `if (Dirty)` test reloads the flag after the push_back growth call. The map's Add/push_back need `__forceinline`, otherwise VC emits them out of line.
- STLport `_Construct` placement new with retail's null test: `inline void* operator new(unsigned int, void* p) throw()`. Guard it with `#ifndef __PLACEMENT_NEW_INLINE` / `#define __PLACEMENT_NEW_INLINE` so the VC test (which includes <new>) and g++ (which rejects the unsigned int form; mkt.py defines the macro) both compile.
- A same-TU GetDef stand-in that only writes the def slot (`*(void**)&def = found;`), combined with a const-local release (`const T* object = def.m_p; if (object && --const_cast<T*>(object)->m_count == 0) ...Destroy();`), gives retail's `dec dword ptr [ecx+4] ; jne` end-of-function release (00832e60). This resolves what GOTCHAS chunk 160 called a lane gap.
- Vector locals that must stay in the frame need an InsertGrow stand-in that leaks `this` (`GrowVectorStorage(this, count)`). To keep `last` in a register, give the stand-in a non-escaping body and write push_back as `T* finish = last; if (finish != end) { Construct(finish, v); last = finish + 1; }`.
- A writer stand-in that writes first/last and reads end keeps a vector<CCharString> live without escaping it; ~CCharString then uses `first` cached in edi/ebp (00522880). A CThingCreature* upcast pushed into a vector<CThing*> takes its own temp slot; push the loop thing as `(CThing*)thing`.
- `__forceinline` on the out-parameter GetInterface gives the eax-component form (`mov eax,[eax+4] ; push ; mov ecx,eax`); a plain template misses the inline budget (008326a0). In the same function, the ternary pick form (`*out = (cond ? last : it)->component`) gives `mov ecx,[eax+4]` before virtual calls (00703590 uses both forms).
- Separate component-pointer locals per GetInterface call keep all lookup keys in the one dead argument slot. Reusing one `preparer` local for two lookups gave the second key its own frame word (00703590).
- Passing a literal to a `const CCharString&` parameter (implicit conversion, `CCharString(const char*, long = -1)`) builds the temporary before the pushes; combined with a filter temporary in an `&&` chain, this reproduced retail's single `flags = 3` store (00680050) and the separate fallback tail block (0082d3b0).
- A named value local (`long priority = control->ScriptPriority;`) loads before _ftol. An inline GetBrain() accessor loads `this` before the argument lea. An inline GetFaction() accessor moves the second faction reload into a dead register.
- A reference-returning operator[] (`*(begin()+i)`) fixes the ecx/edx vs eax/ecx naming in vector loops (00663610). Write the range helper as the ternary `range ? seed % range : 0`; the if/return form places the zero arm first (00666b50).
- x87 order: `X*X + (Y*Y + Z*Z)` or `Z*Z + Y*Y + X*X` gives the z,y,x load order. Reusing the length variable for the reciprocal (`length = 1.0f/(float)sqrt(length)`) gives retail's `fmul st(1)` and the final `fstp st(0)` (00838ec0).
- CHitParameters (PDB) is packed: Position at +2, Direction at +0xe, so it needs `#pragma pack(push,1)`. Building a C3DVector local from member components (`C3DVector a(R.X, R.Y, R.Z)`) avoids CSE of the member address into ebp (006a9690).
- Test harness: g++ needs `#define __declspec(x)` for `noreturn`/`novtable`, and list nodes freed by the body must be malloc'd in the test (a static node aborts glibc's free); VC's CRT tolerated it.

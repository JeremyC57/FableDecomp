# Chunk 120 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A creature argument that retail loads as `mov eax,[esi+4] ... mov eax,[eax+18h] ; push eax` (zero register in ecx, string address in edx) is an inline state-group accessor `GetCreature() { return PBrain->PCreature; }`; a direct `PBrain->PCreature` argument rotates the eax/ecx/edx roles (0x00947CA0, 0x00947D30, 0x00956460).
- The 0x009001xx..0x009006xx state-group constructors are a size TU: a CIntelligentPointer vtable shared by two or more members is cached in a callee-saved register (`mov ebx,offset vtbl ; mov [edi],ebx`) only under `#pragma optimize("s", on)` (0x00900173, 0x00900647).
- `if (x == A) store; else if (x == B) store;` with identical store tails is cross-jumped so `mov ecx,esi` is hoisted above the first `je`; the `x == A || x == B` form keeps it after the branch (0x00950BB0).
- `setne bl` across destructors followed by `test bl,bl ; sete al` is `bool failed = r != 2; return !failed;` (0x00947D30); an 8-bit `neg al ; sbb al,al ; inc al` tail is `return f() ? false : true;` -- `return !f();` widens to `sbb eax,eax ; inc eax` (0x0095A420 probe).
- A nested `if (GetInterface(&c, T)) { if (!c->Pred(this)) return false; }` returns the predicate's own `al` without an `xor al,al` (VC knows it is 0) and a following `return a() && b();` materialises `mov eax,1 / xor eax,eax` (0x009189C0).
- SGI `__pop_heap(first, last, result, T value, Compare, Distance*)` for a 28-byte record with an out-of-line copy constructor: `ret 28h`, `sub esp,1Ch ; mov ecx,esp` builds the copy for `__adjust_heap`, `imul 92492493h` divides by 28, and the callee destroys `value` (the implicit destructor's member dtors in reverse order) (0x00624800).
- The CScriptThing member model needs CBase to own the vptr (`struct CBase { virtual void v00(); CBase(); }`); with a non-polymorphic CBase VC puts the vptr in CScriptThing and every member shifts by 4 (0x00D72160).
- Action temporaries over `CCombatActionBase(creature, type, CSoundPair())` @ 0x00858030: the derived vtable store is scheduled between the PerformActionAndWait pushes; the CSoundPair temporary is zeroed with immediates after the pushes, but from a zero register before the pushes inside a loop (0x00925170 vs 0x009250F0); 0x0062E900 is ~CCombatActionBase (implicit derived destructor).
- The float-span random helper: `long fps = g_framesPerSecond; seed = GetPWorldSeed(); range = (long)(fps * seconds);` then the LCG/GFROR13 step, used as `(long)(g_framesPerSecond * 5.0f + (float)Random(10.0f))` -- the call-holding operand is evaluated first and `fild ; jge ; fadd 2^32` converts the unsigned (0x00941CF0).
- The lane DOES share the inlined GetInterface key slot with a later CIntelligentPointer or predicate temporary (0x00954900, 0x00954C60, 0x00954980: 8-byte frames) but NOT with a zero-initialised address-taken pointer passed to GetSubDef (0x00972340: `sub esp,8` vs retail `push ecx`).
- A virtual GetInterface-on-a-const-creature row calls the const LowerBound 0x004365B0 (write the const template overload); a component from it used as the `this` of a virtual call lands in eax + `mov ecx,eax` in the lane where retail loads ecx directly (0x00954980, parked).
- Region def add-ref `inc dword ptr [esi+4]` before a flag load on the same object is split by the lane into load/inc/store around the load for every inline/forceinline/base-class AddRef form (0x0093D720, parked).

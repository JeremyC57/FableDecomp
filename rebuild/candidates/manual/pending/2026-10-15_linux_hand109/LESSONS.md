# Chunk 109 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A CDefPointer filled by an out-parameter call (`GetSubDef(def)` / `GetDef(index, def)`) and then used across another call: retail keeps the loaded pointer in a callee-saved register and releases through it (`dec [esi+4] ; jne`); in the lane a destructor re-reads the address-taken slot after the call and materialises `&m_refCount` (`add eax,4 ; dec edx ; test edx,edx ; mov [eax],edx`). Writing the release by hand on a named pointer local (`T* p = def.m_pObject; ... if (p) p->Release();`, Release = `if (--m_refCount == 0) Destroy();` on the counted object) fixes the release (0x00662C70, 0x00662C10: only an argument-load scheduling difference left). When the pointer is loaded and immediately tested (no intervening call) the lane still loads it into eax and splits the release (0x0083D900): lane gap.
- The out-parameter `GetInterface(T**, kind)` template inlined into a `__thiscall` filter is ALSO emitted out of line as a COMDAT (`??$GetInterface@...`), larger than a small functor: such sources need `// Leaf: ??RCThingFilter_<Name>` (0x006A8880, 0x006C8C50, 0x006A89E0, 0x006A80E0). Retail `mov eax,[eax+4] ; mov ecx,eax` = the out-parameter template, `mov ecx,[eax+4]` = HasTC + the pointer-returning inline find.
- A filter returning `f() == m_member` as `bool` compiles to `sub eax,[esi] ; neg ; sbb eax,eax ; inc eax` (member folded as a memory operand: 0x006A75D0, 0x00982DB0, 0x006A70B0, 0x006A80E0); retail's `mov edx,[esi] ; xor ecx,ecx ; cmp eax,edx ; sete cl ; mov al,cl` (0x00733020) is NOT reproduced by the reversed compare (`cmp edx,eax`), a base-pointer member or a reference member.
- A down-cast by a type bit written as a ternary (`flags & 10h ? this : 0`) is branchless (`and ; neg ; sbb ; and`); retail's `xor edi,edi ; test cl,dl ; je ; mov edi,eax` is a null-initialised local assigned in an `if` (0x006A78D0). An inline `return a(x) && b(x);` returned from a bool caller gives the full-register `mov eax,1` / `xor eax,eax` next to the caller's own `xor al,al`.
- A float clamp that re-reads the member after storing the argument (`mov [ecx+8],eax ; fld [ecx+8] ; fcomp`) is an inline helper taking the member BY REFERENCE (`Clamp(m_value, 0.0f, 1.0f)`); the direct `if (m_value < 0)` compares the argument instead (0x006BB810).
- `scoped_ptr<T>` in a constructor's init list must be a member class with an inline constructor: its zero store is scheduled before the epilogue's `pop edi`; a plain `T* p` initialiser sinks below it (0x00835C20).
- The retail CThingGameObject is 0xd0 bytes (PDB 0xe8): PThingStandingOn at +0xc0, its bitfield byte at +0xc8, then 7 bytes of tail padding (the class is 8-aligned); CThingDeadCreature's members follow at +0xd0 (0x00835C20).
- The one-argument STLport `vector::resize(n)` is `resize(n, T())` with the temporary built in the caller's frame: out-of-line CCharString default constructor first, the zero stores after the argument pushes, the temporary's members destroyed in reverse order (0x0052C6A0, first try).
- A `bool : 1` bitfield compared with a bool argument is a byte compare (`shr cl,7 ; cmp cl,dl`); a void call as the last statement of such a setter tail-jumps with the argument slot reused (`mov dword ptr [esp+4],0 ; jmp`) (0x006626A0).
- `Reset(new T(a, b))` on an out-of-line Reset duplicates the Reset call into both arms of the allocation null test (0x00662970); the inline `Reset(0)` release (re-read block after the decrement, then zero block and object) is the RemoveFrom* shape (0x006629B0).
- Ego_r.pdb names (`ghidra_out/egor_pdb_names.tsv`) settle propagated labels: the PDB lays a class's methods out in the same order as retail, so a neighbour-order match plus the argument count is strong evidence (0x00664CB0 GetMaxSneakingSpeed, 0x00662C10 GetAnimsWithNameStartingWith); vtable slot numbers from rtti-vtables.tsv name `vfunc_N` rows (CThing slot 15 = CreateFromDef, slot 36 = DrawPreparePrimitivesForRendering).

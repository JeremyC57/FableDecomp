# NF386 lessons (one line each)
- A binder blocked by T3 is often not the only binder: check every retail caller of the target (callers_B.txt). GFVBoxToABox had a hidden second binder (0x00B314E0); GFACoordToVCoord has four.
- When a respell adds a local declaration of a real class, check SHARED_HEADER_AVAILABLE in the new-side vland log against HEAD. A flat-branch declaration opt-in (the NF292 CTCDoor form) usually replaces the local class at no byte cost.
- A planted control in a flat branch flags only the flat-branch includers; rows that define the retail switch read the other branch. Explain each unflagged includer.
- land_scripted copies rows/ only. Headers and moved tests must go in before it runs; say so in T3.txt.
- Census by compile for a delete line: compile every retail caller of the target, not just the witness (0x00753840 has 7 callers).
- objcheck refusing "vftable / RTTI defined" is wrong when HEAD defines the same set; compare the DEF sets.
- The proof that a T1 target is unblocked: apply all table files to a scratch copy, then check each target keeps one spelling and that its own object defines it.

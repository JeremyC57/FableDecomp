- 0x00A446C8 / 0x00A44720 (unoptimised TU): `xor ecx,ecx; je body; jmp exit` in front of a loop is the VC6 for-scope idiom `#define for if (0) {} else for`; spell `if (0) {} else for (...)`. Plain `for (;;)` emits no test, `while (true)` emits `mov eax,1; test eax,eax; je`.
- 0x00A446B9 (unoptimised TU): a *named* catch parameter (`catch (T& e)`) reserves one more frame slot than an unnamed one (`sub esp,8` vs `push ecx`); read the catch type from the FuncInfo handler array (0x01369504 -> CASuspendableProcess::CExceptionExit&), do not assume `catch (...)`.
- 0x00F29F60 / 0x00462FAC: a 5-byte `jmp` virtual `Copy(const CDefClassBase*)` is `*this = *static_cast<const T*>(def);` with the class's operator= declared (retail keeps the implicit assignment out of line right behind Copy); the catalog row then wrongly swallows the operator= body.
- 0x00C5C090 / 0x00C5D530: a thunk that loads one argument into ecx and still pops four stack words is calling a same-TU `static` with VC7.1's private convention; put the landed kernel in the TU as `static __declspec(noinline)` and call it normally.
- 0x00C2E6B1: `p = list.Find(key); CString s = p->m.GetX();` as two statements makes the call come before the hidden-return `lea/push`; chained in one expression VC7.1 pushes the return slot first.
- CParentDefClassBase is 0x39 bytes packed: a derived def must NOT be inside `#pragma pack(1)` (its first member aligns to +0x3C).
- cl under Wine spins until the timeout on an `#error` / missing include: preflight with `g++ -E -D_MSC_VER=1310 -I<overlay> -I rebuild/include` (tools/pf.sh) before grading.
- Catalog rows of 12-60 bytes whose disassembly starts with `[ebp-N]` reads or ends in a bare epilogue are funclets / tails of a neighbouring function: check the previous catalog entry's extent before authoring.

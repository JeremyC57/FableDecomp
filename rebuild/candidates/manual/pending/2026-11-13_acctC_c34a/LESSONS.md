- (0x006A1A00) Constant stores of an inline-constructed vector scheduled AFTER a virtual call's argument pushes = the vector is a temporary in the outer call AND the virtual call's object is a named pointer local (`physics->GetFacingVector(t)`); a named vector or an inline accessor chain both schedule the stores earlier.
- (0x006A1A00) A CDefString -> CCharString temp built before the pushes with GetString 0x00415DD0 CALLED and destroyed before the result test, in a TU whose other site expands the conversion: not the conversion operator (VC7.1 never expands the forwarder while calling GetString: plain = both or neither by site frequency, FORCEINLINE = both). `bool found; { CCharString s = x.GetString(); found = f(s, ...); } if (found)` gives the bytes and the right target.
- (0x007FC9D0) A CCharString temporary argument that refuses to share a frame slot with temporaries / inline-scope locals of sibling statements (frame 4 bytes too big): spell it as a NAMED local in its own block `{ CCharString s("X"); f(s); }` -- block-scoped named locals pack with disjoint scopes, statement temporaries of the enclosing block do not.
- (0x007BC38A) x87 spills tell the type: qword spill of a sin/cos result = the double intrinsic result CSEd (write sin((double)x) at each use); dword = the C++ float overload. A `fld st(0)` copy of a value squared = a by-value parameter of an inline helper of that type.
- (0x007BC38A) ebp-frame slot ORDER of two same-size vectors follows packer weight (IL reference count): an in-place Normalise + *= on a local adds ~6 references; copying to a second local first moved the slot below the other vector as retail.

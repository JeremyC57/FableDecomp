# Chunk 2042 -- lessons from the authoring agent (fold into GOTCHAS at landing)
- (0x007F2DC0) Spelling an alive test out (`p.Get() == 0 || p->IsDead() || ...`) instead of `!IS_THING_ALIVE(p) || ...` adds an `||` term and HALVES the static frequency of all later code: that moved three inline decisions in a later loop (IS_THING_ALIVE 72 -> 117, CIntelligentPointer(T*) 85 -> 150, operator= 64 -> 112) to retail's "called". Read the trace's f column before restructuring loops.
- (0x007F2DC0) A `for (; it != end; )` loop with `continue`s is weighted like a `while` (body x9, test x10 in the inline trace); an `if (x == 0 || x->IsDead()) { erase; continue; }` makes the two identical erase blocks cross-jump into one (retail keeps two: write `!IS_THING_ALIVE`-shaped single tests).
- (0x007F2DC0) An `if (!v.empty()) { iterator it = v.begin(); <call>; do { ... } while (++it != v.end()); }` gives retail's guard-then-aligned-loop-head with no re-test after the call (`for` re-tests after the call because the vector escaped).
- (0x007F2DC0) A `long` local copy of a member that retail keeps in the frame (`mov eax,[m]; mov [esp+X],eax` before a branch, `fild [esp+X]` after it) is forwarded by VC7.1 in every plain spelling tried (named/int/const/bool flag/inline helper by value or reference/reordered tests); only an address-taken copy (a named reference to it, or reusing an address-taken local) or a volatile member keeps it.

# NF310 lessons (one line each)
- A self retype onto the PDB spelling can collide with pick-any COMDAT copies that includers of a shared header already emit under that name (engine/CTCObjectAugmentations.h inline HasCombinationOfAugmentations / HasAugmentationOfType in 0x00839100 / 0x007677E0): before a self rename, `nf.py syms` every compiled census object for a DEF of the new name; a strong self beside them is a new duplicate (GOTCHAS 427), so the self needs the nf86 / nf88 pick-any form (T3) and only the binder moves.
- A binder that "binds" a call to a class's implicit member can be binding its OWN COMDAT: 0x00836A50 called ??1CThing@@UAE@XZ that it emitted itself (CThing.h's default branch declares no destructor); switching to the declared-only FABLE_RETAIL_CTHING_DTOR opt-in drops 23 COMDATs (objsec NOT_EQ). Read the HEAD object's DEF list before treating an implicit-member binding as an access fix.
- A binder fix onto the PDB access (protected ctor IAE) breaks resolution when the self row itself still DEFINES the public form (0x004C9030 defines QAE@K): check the self's DEF in bind.py before moving binders, or the link shows a new unresolved that HEAD resolved.
- reloc_bindings.tsv lines can be stale against today's sources (0x006186F0 is the PAV witness of InMap while its source declares `const CThing&`): the compiled bind is the evidence, never the table line.
- A pre-existing cast at a call site can stay when only the declaration's spelling changes (`*(const CBonusItemDef*)bonus`, `*(CThingCreatureBase*)PCreature.GetPItem()`); dropping a cast the new signature makes unnecessary (`(CWorld*)&PeekWorld()` -> `PeekWorld()`) is fine when objsec is ALL_EQ.
- `static void f();` -> `static void __fastcall f();` for a no-argument function is byte-neutral at the call site (cdecl caller cleans nothing): the PDB SIXXZ spelling lands in place.
- nf.py's link / grade / zs helpers deleted their scratch with os.unlink / shutil.rmtree; NF310 routes them through the toolkit's clean.py so no helper deletes a variable path itself.

# Chunk H40f lessons (GOTCHAS-ready one-liners)

- (chunk H40f, 2026-11-11) A per-site call / expand split that is off by one uniform factor outside the {0.5, 1.5} of the loop condition can be composed from folded operands on the branches in front of it: `if (x || false) break;` halves the fall-through (0.25 instead of 0.5), `if (c || false) { if (T) return; ... }` scales the join by 0.833 (0.25 + 0.75 x 0.5 against 0.5 + 0.5 x 0.5), `if (c && true)` halves the arm. 0x00D0F640: loop `&& true` x Gate3Open `|| false` x kills `|| false` = 0.208 gave retail's decision at all 17 ~vector<CScriptThing> / ~CScriptThing sites (229 -> 108 lines). `|| false` on a negated call (`!IsLevelLoaded(..) || false`) changed nothing.
- (chunk H40f) `&& true` on an if arm is not a substitute for the loop-condition factor: 0x00E50FD0 with a plain loop and the fold on its two hot arms went from 99 to 240 lines.
- (chunk H40f) tools/hmerge.py-style block merges fail silently in three ways: the block lands inside a neighbouring `#ifdef`, an `#ifndef X / default / #else / new / #endif` block is inserted in FRONT of the default line it was meant to replace (the opt-in then keeps the default too), or a helper `#define` leaves its block. 0x0061E6D0 compiled with ~CUIStateDef still user-declared and graded 12260 v 12356; with the duplicate removed it is hand882's 12357. After a merge, diff against HEAD must show added lines only AND every `#else` arm must be followed by `#endif`, not by the old line.
- (chunk H40f) Expression-temporary rotation at a thiscall: only memory arguments used once are rotation temporaries (size -> ecx, id -> eax); the `mov ecx,[this home]` is not, whatever the object expression (named pointer, reference, `(*this).`, base at +0, first member at +0). An argument used twice or three times in the statement becomes an allocator piece and takes no rotation step (0x00C4F600, work/c4/a8, a9).
- (chunk H40f) VC7.1 propagates `if (v == 2)` into the arm: `f(v)` inside it compiles to `push 2`, byte-identical to the literal (0x00C4F600, work/c4/p1).
- (chunk H40f) A masked-line count can fall while the byte gap grows: 0x00DB97A0 with `&& true` on the main loop is 248 lines (888 before) but 157 bytes short (49 before). Read both numbers.

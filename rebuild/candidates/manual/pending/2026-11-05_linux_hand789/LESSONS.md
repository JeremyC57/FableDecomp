- (chunk 789) **Inline CScriptThing::operator==:** spell it `PImp->IsEqualTo(*other.PImp)`, which is 0x008AAE20's own body. `PImp.Data->IsEqualTo(...)` makes VC7.1 CSE `&Me` into the register that already holds it, so Me's Data loads as `[ebx+4]` instead of `[ebp+0Ch]`. That keeps ebx live, spills a loop offset and grows the frame by 4 (0x00CFE030).
- (chunk 789) **Virtual call on a local you also assign:** a by-value CScriptThing local that is later assigned keeps a virtual `IsAlive()` (`mov edx,[esp+X]; call [edx+12Ch]`) only when called through `const CScriptThing* p = &local;`. (A const-reference alias is folded back into the object, GOTCHAS I-44.) (0x00CFE030)
- (chunk 789) **Literal string compares in quest scripts:** `Me.GetDataString() == "LIT"` (null arm `repe cmpsb` against "", else `call Compare 0x00411570; neg; sbb; inc`) needs FABLE_RETAIL_CBASICSTRING_TEXT_EQ_INLINE plus FABLE_RETAIL_CCHARSTRING_FORCEINLINE_TEXT_EQ. Without the second, the second compare of an `||` chain calls the operator out of line. A named bool and the plain `if (a || b)` give the same bytes (0x00CFE030).
- (chunk 789) **Leave ~CScriptThing out of line when retail expands it once:** if retail expands ~CScriptThing at a single exit, leaving it out of line costs one block. A plain inline `~CScriptThing() {}` expands at several exits, including the final normal exit (23 vs 183 difflines, 0x00CFE030).
- (chunk 789) **A `{ }` block fixes frame slots:** a block around a late CTimer and its loop, up to the idle loop, gives retail's slots for the earlier temporaries (0x00D82640).
- (chunk 789) **Force every ~vector call out of line:** declare `template<> std::vector<CScriptThing, std::allocator<CScriptThing> >::~vector();` without a body. Every ~vector<CScriptThing> is then called (0x008AC970). Without it, VC7.1 expands the vector dtor at every exit of a loop-heavy thread (0x00D7FE90).
- (chunk 789) **Round-loop rotation:** `do { ... } while (round < 3);` followed by the trailing code reproduces retail's rotation where a for/while loop does not (0x00D7FE90).
- (chunk 789) **First-loop placement:** an entity-script first loop written `for (;;) { if (ParentClass.Flag) break; ... }` gives retail's placement; `while (!Flag)` puts the body elsewhere (0x00DEA3F0).
- (chunk 789) **Movie PImp dtor:** a declared-only `template<> CCountedPointer<CScriptGameResourceObjectMovieBase>::~CCountedPointer();` gives the PImp dtor call 0x006E7AB0 at the expanded movie exit (0x00DEA3F0).
- (chunk 789) **Parent-handle Release:** IsValid / Release through `Parent& parent = ParentClass;` gives retail's `mov eax,[esi+14h]; lea ebx,[eax+N]`. A handle reference or pointer gives `add ebx,N` (0x00E776F0, 0x00DEA3F0).
- (chunk 789) **CScriptDef.h include hang:** engine/CScriptDef.h needs FABLE_RETAIL_DEF_CLASS_BASE and FABLE_RETAIL_CDEFSTRINGTABLE. Without the latter, CDefString.h `#error`s and cl.exe spins under Wine. A `g++ -fsyntax-only ... | grep '#error'` pre-check catches it.

# wfB4 lessons (one line each)
- (0x00B8B780, 0x00B89C30) The SetRenderState bookmark test/or operand order is decided by two c2 comparator calls per inlined AND, both readable with a 3-minute gdb trace of the merge-sort comparator 0x1076A394 (k/cmp.py + agentC20 sched2/host.py): measure the ids before sweeping spellings.
- First pass (inline time): record ids come from a free list (step 3 per setter) and then from the high-water mark; an id >= 2048 wraps (rotl16(id,5)) and swaps the operand order from that block on. Dead asserts do not touch it; one more inline parameter / local record before the block does.
- Second pass: two temp ids (mod 1024), one growing ~36 and one ~20 per setter block; the retail-order window starts where the fast one wraps and ends where it catches the slow one. Dead asserts add ~8 to both (start moves, end does not); a named local or a trivial accessor expansion moves the slow one by 23..36 at once.
- FableWin COMDAT ADDRESS ORDER is evidence for helper USE: the inline functions placed right after a function's TU are the ones that TU used first; a helper whose only COMDAT sits at a later address (GetAppropriateMipmap, GFLimit<JJJ> for the billboard TU) is NOT used by that TU.
- FableWin float code: +2 instructions per binary float expression passed as an argument (rounding temporary) and 3 instructions per float constant push or member-float push: operator*(float) 31i, operator+/- 34i, GetTranslation / GetRowX 22i are the default one-expression bodies; a row with many constant float arguments is ~2i per argument larger without any ASSERT.
- A "NoTranslation" product whose retail bytes keep the translation dot products is a full SetMultiply / PostMultiply on a by-value matrix copy whose translation was zeroed with constants: VC7.1 folds `+ 0.0f` and drops the dead zero stores (0x00B8B9CB).
- Check the FableWin neighbours of a row before trusting its sizes: RenderWeaponTrail's FableWin body uses CArray<CArray<C3DVector>> and a std::list, i.e. a later source revision.
- (0x00BCC800) UNREFERENCED OUT-OF-LINE COPIES of a row's inline helpers are oracles for the helper TEXT: grade each copy (pointer-to-member probe, retail bytes by VA) before touching the row. Six copies with the same-direction register swap = one wrong text in the innermost helper (FindNode), not six allocation ties.
- (0x00BCC800) A register swap that follows an inlined helper into every caller is a priority gap of 2-3: run c2prio on the smallest copy, read the per-block K table, and look for the block where one more live candidate (K+1) gives the swing. Here: a named `index` used twice (`if (table[index]) return F(table[index], key);`) instead of a `child` local.
- (0x00BCC800) A value read twice through the same expression keeps its index local alive across the test (a real candidate that takes the scratch register first); a single-use named local is forwarded and changes nothing. `x = t[i]; if (x) f(x)` and `if (t[i]) f(t[i])` are the same instructions with different register choices.
- A probe variant chain built with string replace silently fell back to the default text for every later variant: keep one file per variant and verify one variant changes the output before trusting "no change".
- (0x00B89C30) Bookmark-order rows: letters = fixed second-pass base XOR "swap from the first block whose first-pass id is >= 2048"; the final setter run first drains a free run of ids, then takes new ids from the high-water mark. Each named local or temporary object adds exactly 1 to every later id wherever it is declared, so sweep n = 0..12 unused locals ONCE (2 s a grade, tools/p2.sh letters): if the retail letters are not in that list, no spelling that only adds symbols can close the row.
- (0x00B89C30) The id map has regimes: at n = 3 an earlier free run ends one block sooner and every later run starts 32 / 64 lower, so the response to a count ruler is not monotonic; a one-block miss is not "one local away".
- (0x00B8B780) Size the row itself against FableWin before believing an assert count: subtract 2 instructions per constant float argument (0.0f / 1.0f cost +1 byte, other constants +5), then divide by the assert size (+63i / +223b or +82i / +318b). Here: one assert, with an accessor call in its condition, not two.
- (0x00B8B780) A FableWin COMDAT first emitted with a TU for an accessor that no retail byte uses (GetVertexCount, GetPRenderToSurface) is the condition of a debug ASSERT, not a missing statement.
- The shared header already has landed FITTED SetRenderState variants (SETRENDERSTATE_DESIRED, _BOOKMARK, ADDSTATE_DIRTY: one named symbol per expansion each): try the five combinations before any ruler on a bookmark-order row; they move the window by whole blocks.
- A variant that defines an opt-in the header cannot compile alone makes cl spin until the timeout and blocks the work directory of that address for later grades: preflight with g++ -E, and never grade the same address from two shells.

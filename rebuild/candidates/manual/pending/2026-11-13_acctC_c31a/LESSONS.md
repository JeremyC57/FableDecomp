# agentC31 LESSONS (one line each)
- (caller-size budget) Measure a budget residue as a WINDOW in tuples from one inline trace (ag.py: a+g at the critical sites; dtor penalty = 26*(a+g)/9000 added to c 47, so the flip is at a+g 9347, not 9000) and then price each authentic STL layer by trace (tuples per site x sites): REBIND +19.6/allocate site, allocator::allocate -> __sgi_alloc::allocate +9 (+14 with STLport's named `__result`), _Construct in _M_create_node +12, node allocator built by the converting ctor instead of default-constructed -5. The STLport-verbatim combination landed inside a 56-wide window that REBIND overshoots.
- (STLport) FABLE_RETAIL_STLP_ALLOC_PROXY_REBIND is the path STLport 4.6 uses only for compilers WITHOUT member template classes; for VC7.1 the proxy inherits allocate() and the layers are allocator::allocate -> __sgi_alloc and _STLP_CONVERT_ALLOCATOR(__a,_Tp) == __a. Try those before REBIND on rows with many list / vector nodes.
- (twin idioms) After the inline decisions were right, 43 hunks of "register / frame" residue in 0x00601310 were two twin idioms: a named `CText* descriptionText` taken AFTER the first use of `description.Get()`, and the twin's FABLE_RETAIL_CCOUNTEDPOINTER (ctor tests the member): only then does c2 thread `if (!p.IsNull())` through the ctor's null arm (retail `je` straight into the else arm).
- (c2 frequency) c2's static frequency sums incoming edges; a `for` with an increment leaves the code after the loop at the BODY frequency, a for without increment / a while does not; frequencies saturate at 2^64/1e8 after ~8 leaking loops. Score threshold for a callee of cost c: called iff f <= c/(222-2c) (f > 1).
- (shell) `export W=... FABLE_HDR_OVERLAY=$W/hdr` on ONE line expands $W before it is set: vland then grades without the overlay and prints SRC_FAIL. Use two export statements.
- (map rows) `GetRegionNumberMapIsIn(GetParentThing().GetCurrentMapNumber())` (landed 0x00605570 spelling) is what gives `movsx ecx / mov edx,[eax] / push ecx` at 0x006031D7; with `ParentThing->` the push comes first.

# Chunk 321 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- **Zero kept in a saved register comes from a helper argument.** Retail had `push edi; xor edi,edi` early, used edi for zero stores and compares, and loaded `mov edi,[g_pScriptDef]` before an interface call (the field read came after the call). Passing the global pointer to a `__forceinline` helper (`DayModInterval(Game->GetDayOfWeek(), g_pScriptDef)`) loads it into edi before the call. That makes edi a saved register, and VC then reuses it as the zero register. Plain `Game->GetDayOfWeek() % g_pScriptDef->X` reloads into ecx after the call and uses immediate zeros. A `const long&` field helper is close but adds `add edi,0x9d4`. Example: CQR_EscortTrader_ManagerScript::Main 0x00E24E10.
- **Shared dtor exit placed after a later block.** `if (!IsActiveThreadTerminating()) X; else return;` places the shared destructor exit out of line, after the later code. The plain `if (Term) return; X;` lays it inline at the test. Example: 0x00D835D0.
- **CScriptThing::operator= over CCountedPointer.** It inlines only when CScriptThing::operator=, CCountedPointer::operator= and Release are all `__forceinline`. Example: 0x00DCC770.
- **Vectors declared first.** When retail's vector zero-init stores come before the first GetThingWithScriptName call, the vectors are declared first. Example: 0x00D72B70.
- **Region temporary before the `new`.** A direct `AddSpawnedFunction(new CSpawnedFunc<..>(..), "Region")` with a `const char*` region builds the region CCharString before the `new`. An explicit `CCharString("", -1)` builds it after. Examples: 0x00E0EA40 and the landed 0x00D3AD60.
- **CEnginePrimitive2DSprite is 0x58 bytes with 8-byte alignment.** Give it an `unsigned __int64` member. Functions with sprite locals then get retail's `push ebp; mov ebp,esp; and esp,-8` frame, and eight sprites give a frame of 0x2e0. Example: 0x0043B050.
- **Inlined CDataInputStream reads in a run share one stack slot.** Write them through an inline `template <class T> T ReadValue() { T v; Read(&v, sizeof(T)); return v; }`. Named locals get separate slots and a `sub esp`. A flag stored from a 4-byte or 1-byte read goes through a non-bool temporary (`setne`). A variable-size array read tests `size > 0` first and compares `size <= SourceChunkBytesRemaining` (`cmp eax,[ebx+0x14]; jg`). Example: 0x00AE1BC0.
- **Trace strings built and dropped.** `CCharString("") + "text" + s (+ "tail")` whose temporaries are destroyed as T2, T1, then the result (the last result outlives the others) is a named local: `CCharString message = ...;` in its own block. Example: 0x00CDDCB0.
- **Empty allocator temporary.** `list(const allocator& = allocator())` with an empty allocator struct zero-initialises the temporary byte (`mov [esp+x], bl`). Retail has none, so give the allocator a user ctor `allocator() {}`. Example: 0x00CDDCB0.
- **STLport list deallocate tests for null.** `if (_M_node) free(_M_node);`, giving `cmp eax,ebx; je`. Example: 0x00CDDCB0.

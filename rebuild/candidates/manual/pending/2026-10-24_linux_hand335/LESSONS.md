# Chunk 335 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- STLport `__uninitialized_fill_n(first, n, x, __false_type)` gets its second induction register (`lea esi,[eax+N]`, with stores relative to it) only when two conditions hold. The element needs a memberwise USER copy ctor, and it must contain a member that has its own user copy ctor. The IV then points into that member (+8 of a 3-long record, +1 of a BGRA colour copied through an inline `Set(r,g,b,a)`). An implicit copy gives one IV and block moves (00769000, 00720310, 13 rows in all).
- An element stride of 0x0d with the record at +1 is a genuinely byte-packed element. `#pragma pack(1)` states the real layout here and does not hide one (00513a00).
- A constructor-less POD member inside a user-copied element is copied as a block (`lea ecx,[edi+N] ; lea edx,[esi-M]` and four moves). Do not give it a ctor (009f6c90).
- GFSerialise*BinaryIn: when a stream's virtual is reached through an inline wrapper, VC7.1 re-addresses the returned CCharString temporary with an extra `lea eax,[ebp-4]`. Call the slot through the vtable view directly inside the traits (0043151d family).
- Traits DefaultVal built by implicit conversion (`DefaultVal("", 0)` where DefaultVal is a pair<CCharString,long>-like type): this gives retail's `lea` re-address of the temporary. An explicit `CCharString("")` reuses eax and swaps a register (006d3a30).
- Nested traits inside an inline TransferBinaryOut: a NAMED `CPersistTraits<T*> secondTraits;` local shares the outer slot. An unnamed `CPersistTraits<T*>().TransferBinaryOut(...)` temporary gets its own frame slot (006c7ba0).
- `std::remove_copy_if` with a radius predicate: write the length as `sqrtf(X*X + Y*Y + Z*Z)` through an inline `float sqrtf(float)` over the `sqrt` intrinsic, and give the predicate a named `offset` local. A double expression reorders the x87 stack (008c2ed0).
- An inlined CVectorMap component lookup inside a filter that is itself inlined into a template loop (ForEachIf): VC7.1 leaves LowerBound, GetTC and the filter's operator() OUT of line unless each is `__forceinline`. Plain `inline` is not enough at that depth (0080e5d0).
- GetAllLeafThings with real filters matches with the landed GetPBestLeafThing CThing/list model plus the FindThingsInRoughArea push_back recipe: an rvalue `(T*)thing` and a same-TU noinline `_M_insert_overflow` stand-in. `CFilter_Bind2` is `{const A* Filter1; const B* Filter2;}` with an inline `operator()` (the filter reference is re-read from its argument slot for each call) (006186f0).

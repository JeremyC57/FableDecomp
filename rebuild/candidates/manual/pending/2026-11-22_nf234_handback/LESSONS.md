# NF234 lessons (one line each)
- pk.py reads retail to max(catalog length, copy length), so a NEQ line can print equal sizes ("103 v 103"); disassemble the owner for its real length.
- A size-mode pick-any copy that calls a member its /O2 caller expands needs that member's specialization AND the caller's (Reset over ReleaseData): one opt-in per COMDAT the TU emits.
- A zero-initialised static whose inline ctor only stores zeros gets no ctor code in VC7.1's _$E1: the initializer is just the atexit registration.
- absrefs.py misses nothing that stores a vtable, but NF233's family census did: run it on every vtable address before counting spellings (0x00B260B0 was a third 0x0122DE50 spelling).
- fam.sh's VF='' falls back to its default filter (Component); pass a real filter to list other classes' vtables.
- absrefs.py needs S exported in the environment, not just set in the shell.

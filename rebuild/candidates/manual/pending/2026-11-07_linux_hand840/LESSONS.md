# LESSONS (chunk 840, expert retry pass 3) -- GOTCHAS one-liners

- (2026-11-07, chunk 840) VC7.1's 2-instruction scheduling ties (which of two ready `lea`/`mov` goes first, a frame-address lea versus a member load) are decided by IR numbering, so an UNRELATED spelling change earlier in the function flips them while every spelling at the site keeps ours: a named `const float speed = Speed / g_framesPerSecond;` before SetVelocity put the AddTC name-temporary `lea` ahead of the ParentThing load (0x007BC8FC); `if (alwaysOpen) return true;` instead of nesting the villager block under `if (!alwaysOpen)` put the GetTC key address `lea ecx,[esp+18h]` ahead of `lea esi,[eax+44h]` (0x00773950). Try early-return / named-local rewrites of the statements BEFORE a 1-2-line tie before parking it.
- (2026-11-07, chunk 840) SIB base/index order of `buffer[size] = 0` (retail `[eax+esi]`, size reload as base): make the buffer an inlinee local -- an inline helper taking the owning object by reference (`ReadWholeFile(CDiskFileWin32& file)`) that allocates, terminates and reads -- VC7.1 ranks the member reload above the helper's local; every spelling with the buffer as a local of the row gives `[esi+eax]` (0x009E5C90, the CleanOutLine 0x009BB0D0 rule again). Call the local object's virtuals through the qualified name inside such a helper (`file.CDiskFileWin32::Read(...)`) or the reference parameter goes through the vtable.
- (2026-11-07, chunk 840) A UI component delta (`ChangePosition(d + Position, time, immediate)` with the un-converted, UI-scaled delta accumulated in a local by `*=`) reproduces retail's load/store order around the `sub esp,8` + GetUIScale pushes; assigning `d += Position` first and passing the local does not (0x0052EA30).
- (2026-11-07, chunk 840) Retail leaves a constant `return false` / `return 0` `xor` AHEAD of the register pops when the block is a join (dtor early-outs or list end tests jump to it) and interleaves `mov al,1` / `add eax,8` among the pops on the other exit; VC7.1 RTM and QFE-4035 both interleave the xor too, under every return / result-variable / dtor / loop / flag spelling (0x0073ACC0 40 attempts, 0x0070C4E0 47): park this family early (`xor al,al` or `xor eax,eax` moved one pop down).
- (2026-11-07, chunk 840) The engine `CCountedPointer` header dtor form (separate decrement, Data/Info zeroed after) and a by-value `CCountedPointer<T>` parameter compile to the same bytes as the 2-field local model; it is not a lever for the join-block xor placement.
- (2026-11-07, chunk 840) Documented flags are not levers for these ties: /Oa /Ow /Op /Os /Ot /Ob1 /Oi- /GF /Gy /GS /Gs /Gr /Ox /O1 all keep or worsen the residue (0x0070C4E0, 0x0073ACC0, 0x007534B0, 0x007BC8FC, 0x0058301A, 0x00773950, 0x0047ED76).
- (2026-11-07, chunk 840) `struct` versus `class` in a local model changes every callee symbol (`ABUC3DVector` v `ABVC3DVector`) and the leaf; with `class X : public Y {` remember `public:` or the leaf mangles as private (`EAE`). Check objdump -t on every hand-back.

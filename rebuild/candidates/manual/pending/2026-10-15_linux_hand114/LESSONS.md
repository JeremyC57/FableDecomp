# Chunk 114 -- lessons from the authoring agent (fold into GOTCHAS at landing)

- A plain constructor whose stores run in an order no init list can give (Zoom +0x10 before Position +0x08, the type/flag words last) is all BODY assignments with empty default constructors on the member structs (NUISystem::CUIState 0x0052E5D0); `m = T(1, 1)` temporaries in the body cost a 109-byte copy instead.
- STLport `deque::back()` (`iterator tmp = _M_finish; --tmp; return *tmp;`) keeps retail's dead 0x10-byte frame and the single surviving `last` store only with the IMPLICIT iterator copy constructor; a user memberwise copy constructor SROAs it away (0x00913960, 23 v 42).
- STLport `vector::erase(first, last)` on a POD element inlines `__copy_trivial(last, _M_finish, first)` = `last == first ? result : (char*)memmove(result, first, n) + n`: retail keeps the `cmp eax,eax` of `erase(begin(), end())` and the dead memmove arm (0x00B2FA40).
- The fleet's 24i rule also fixes the ARGUMENT LOAD ORDER of the quest-script constructors: with a plain three-zero vector member the lane loaded arg1 first and put `mov ecx,edi` above the vector's zero stores; the real `_Vector_base(const allocator&)` + `_STLP_alloc_proxy` vector reproduced both (0x00E46BD0). CScriptThing members want the PImp counted pointer as a member OBJECT with an inline constructor (vtable store before the two zero words).
- Quest-script `CTimer` members register themselves in an inline constructor `CTimer() : Index(g_pGameScriptInterface->RegisterTimer()) { }` (GSI global @ 0x0143E8F8, slot 87); CCharString[N] members of the no-EH script module are built by an inline `dec ebx ; jne` loop.
- A value computed from a global struct pointer whose pointer is loaded BEFORE an intervening call (rand) but whose second field is re-read through the global AFTER it = the pointer in a local for the first use, the global again for the second, and the result in a named local (`CScriptDef* def = g; long t = g->Max - rand() % def->Range; Set(t);`, 0x00E1FEB0); computing it inside the call argument hoists the interface fetch into ebx.
- Script "terminate check" shapes: `while (!(a || b)) { Game->NewScriptFrame(); if (IsActiveThreadTerminating()) return; } if (IsActiveThreadTerminating()) return;` is the rotated WAIT macro (first operand tested at the entry and the bottom, the rest at the aligned head); a terminate check as the LAST statement of a void function becomes `jmp IsActiveThreadTerminating` (0x00E7A580, 0x00E2BA50).
- A float def value passed to a `float` virtual parameter is pushed with integer moves (`mov edx,[edx+2b4h] ; push edx`) from plain `Game->GiveHeroMorality(g->Value)` (0x00E2BAC0).
- A by-value CWideString return with no stack arguments and the hidden result in ecx is a static `__fastcall` function; `return Get() + L"lit";` reproduces through the `__fastcall` operator+ (result ecx, left edx, right on the stack) with the temporary in the `push ecx` frame slot (0x0041A4C0).

# Chunk 160 lessons (for GOTCHAS)
- (wave 25, chunk 160) A creature action handed to SetCurrentAction straight from its ctor's eax (`push eax` after the ctor call) is a TEMPORARY passed by reference: `creature->SetCurrentAction(CCreatureAction_X(*creature, arg));`; its inline dtor stores no vtable, so the action class is `__declspec(novtable)` over the out-of-line ~CCreatureActionBase (0x693EF0). A named local pushes `lea ecx`.
- (wave 25, chunk 160) `v = C3DVector(a, b, c)` with only the 3-float ctor declared gives retail's frame temporary copied through integer registers; declaring a user copy ctor or operator= turns the copies into fld/fstp (0xB317A0). Conversely a ternary `cond ? ref : C3DVector(0,0,0)` returned by value needs the memberwise user copy ctor for the edx copy (0x92BD80).
- (wave 25, chunk 160) A by-value CCharString result used through esi (VC keeps the returned pointer) is a temporary passed by reference into an inline helper (`AllocTC(GetClassTypeName(), *owner)`); a sum whose inner temporaries die before the use is a named local (`CCharString text = "End" + Name() + ";\r\n"; out += text;`).
- (wave 25, chunk 160) Two predicate objects whose frame slots come out swapped as named locals are argument temporaries of the filter (`Filter(CPredA(), CPredB(x))`, 0x7AF050).
- (wave 25, chunk 160) A pointer computed from a locked rect and passed on wants a named local (`unsigned char* dest = PMem + bpp*x + Pitch*y;`, 0x9F4120); an inline expression folds PMem into the add.
- (wave 25, chunk 160) A bool getter with one shared `xor al,al` exit after the callee-saved pushes is nested ifs ending in one `return false;`; an early `if (!out) return false;` opens its own exit before the pushes (0x783730).
- (wave 25, chunk 160) Member vectors zeroed in a ctor want the `_Vector_base` + `_STLP_alloc_proxy` model to place `lea ecx,[esi+N]` before the last zero store (0x7AEFD0); CTCBase slot 6 is OnInitialActivate, slot 28 of CTCActionUseBase OnActionUse(CThing&).
- (wave 25, chunk 160) A base class whose method is called on `this` must be the polymorphic root, or VC adjusts `this` by the vptr (`lea ecx,[esi+4]`, 0x7DAAE0).
- (wave 25, chunk 160) Unsolved: a local CDefPointer whose address went to GetSubDef releases with `dec dword ptr [ecx+4] ; jne` in retail, the register form in our build (0x7EB110/0x7EB1A0); two identical SetText arms cross-jump in our build where retail keeps both (0x729B20); register-only rotations at 0x9A4F20, 0x7EBAB0, 0x7F9010.

# Chunk H40d lessons (GOTCHAS-ready one-liners)

- (chunk H40d, 2026-11-11) A register swap between a loop index and a vector base (`mov ebp,[begin]` / `xor ebx,ebx` v the reverse) that c2prio shows as a priority tie is closed by naming the element once: `const CScriptThing& follower=followers[i]; if (!(victim==follower)) { ...followers[i]... }`. The named reference is one more candidate in the loop-top block (K 2 -> 3: base 92 -> 100, live-through index 100 -> 96), costs no instruction, and the second `followers[i]` is still re-read after the call in between. 0x00E6BC50 (retail 0x00E6C468 / 0x00E6C47C); the eax / edx order of two earlier size() reads and a thread-exit pad's register form were consequences of the same swap, not separate residues. Probe: c2prio table rows of the loop's lines (hand H40d tools/vt.sh, 60 s, no grade).
- (chunk H40d) Per-callee inline thresholds can be read off one trace and turned into frequency bounds: with c1 44 a site is called below f 46.4, with c1 60 below 38.1, c1 19 / 20 (movie dtor / ctor) below ~4.6 / ~5.0 (7 x score is linear in 1/f with a knee at f = 100: for the c1 44 dtor 291.7 + 15380/f above, 380 + 6400/f below). A pair of sites of two different callees at one program point (0x00D0F640: vectors CALLED, leader ~CScriptThing EXPANDED at the same return) pins the frequency there to a narrow band and makes the whole split a solvable system; solve it before trying shapes.
- (chunk H40d) `while (!T) { ...; NSF; }` and `for (; !T; NSF) { ... }` are not interchangeable for c2's static frequencies when the body's arms fall through to the loop end (0x00E50FD0: first inline site at 498 v 125, and the four thread exits of one scene go EXP CALL EXP CALL v EXP EXP EXP CALL); in a body that is one straight line of thread exits they are identical (0x00D0F640). Trace both before choosing.
- (chunk H40d) Retail's `call T ; test al,al ; je <continue> ; jmp <exit>` (instead of the usual `jne <exit>`) marks a `return` that still had its own cleanup copy when blocks were laid out and was cross-jumped into the common exit afterwards (0x00D13580: 0x00D14E43, 0x00D14EE4); thread checks in front of such returns are not merged with their twins in other arms.
- (chunk H40d) A sibling function with the same statements can show a different retail call / expand split (0x00D0EE70 v 0x00D0F640, down to a cost-8 vector dtor and the vector ctor being called at the sibling's early sites): the difference is in the frequencies at the top of the body, so a lever found on one must be checked against the other before it is believed.

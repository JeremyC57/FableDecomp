# NF247 lessons (one line each)
- `// Leaf:` lines are loose prefixes (`OnDeactivate`, `?FrameUpdate@CModeScreamerAggressive`): compile the target rows and read the DEF symbol before counting spellings; vtmap's SAME / DIFF reads the Leaf line, not the object.
- A vtable's census needs every emitter, not just the dtor rows: ctor rows on a header without FABLE_RETAIL_CMODEBASE_VIRTUALS emit a short ??_7 whose derived virtuals take new slots one off (0x008AC3F0 bound three names at the next slot's address).
- An intermediate class's names fall through too: a local derived model missing its own overrides binds the intermediate's names (CModeDragonHover) at the derived addresses, not only the root's (CModeBase).
- CAnimFilterOfGroup.h gives the implicit inline destructor only with INLINE_CTOR, which needs FABLE_RETAIL_CCHARSTRING (GetAsCharArray / GetLength) and emits EQ pick-any copies of the ctor (0x0073E8F0) and ??_G (0x0073E970).
- equiv_check with a sparse overlay tree flags `__FILE__` in headers reached through -idirafter as a DIFF; rerun those rows with an empty old tree (both sides then resolve through the repo path) before calling them real.
- Bank the in-place form first (UND-only diff), then try the header port: here every port graded first or second time, but the fallback cost one compile per row.
- A header opt-in that would give a callee its PDB access (IAE) creates a split when the callee's self row and other binders still spell QAE: declare it as landed and queue the family move.

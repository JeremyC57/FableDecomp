# LESSONS (chunk 835, expert retry) -- GOTCHAS one-liners

- (chunk 835) The CIsThingAlive / CIsThingConscious nested-copy blocker is STRUCTURAL in retail, not a budget: a scan of every retail reference to the two vtables (bin/vtscan.py; 413 + ~90 construction sites) finds the nested CScriptThing copy 0x004ABE90 CALLED at 100% of them (373 + 78 expanded ctors, incl. the 20-byte CPredicate_And ctor 0x00E24760 and Clone 0x00CDF130) while by-value copies in the same functions expand; the nested ~CScriptThing is called too; only the standalone dtors 0x00E241B0 / 0x00EF7AB0 expand ~CScriptThing. On the lane the outer inline tree is all-or-nothing: /d2inlT sweeps (T30 nothing, T40 nested + 1 by-value, T50/T60/T100 one more each), __forceinline on the predicate ctor, definition order, inline helpers, inline_recursion, /Ob1 /Os /Ot /Oa /Gy /GX /EHsc /Zi, pragma regions auto_inline(off) / optimize("",off) / optimize("g",off) (call the outer whole), optimize s/t/y/a/p/w, check_stack, runtime_checks (inert) never split it.
- (chunk 835) The only construct that reproduces retail's per-site shape is a region `#pragma inline_depth(0)` (or (1)) round the row-local predicate ctor/dtor DEFINITIONS (a property of the inlinee, not of the call site): 0x00DE2610 35 -> 9, 0x00D82640 38 -> 14, 0x00DC5F80 36 -> 19, 0x00DAF080 30 -> 20, 0x00E27E90 31 -> 22 masked lines; the residue left is a CALL to the nested CPredicateBase() ctor (retail has none: its vtable store is dead), and an implicit CPredicateBase ctor is still emitted and called. Forbidden in rows (ASM_RULES / chunk brief): owner question, see NOTES.md.
- (chunk 835) Retail is not LTCG here: a two-TU /GL + link /LTCG build (bin/ltcg.py) inlines the out-of-line CScriptThing copy at every depth and gives the copy ctor a custom convention (`this` in eax, other in ecx) and Main `this` in esi; retail's NScript Mains are plain thiscall with the standard copy-ctor call.
- (chunk 835) 0x00EA5230 on the shared headers: the first bandit wait devirtualises a row-local `inline bool CScriptThing::IsAlive() const { return PImp.Data && PImp.Data->IsAlive(); }` (PImp.Data test + slot 75 on the Imp), the two attacker waits keep the virtual call through `reinterpret_cast<const CScriptThing&>(attacker).IsAlive()` on a VALUE local (lea ecx hoisted above the terminate jne); a row-local `inline CScriptThing::~CScriptThing() { }` is required for the inline-once dtor at the first terminate exit (without it 1053 bytes, md 116).
- (chunk 835) /G5, /G6 and /G7 change nothing in an x87-heavy row (0x0068CB90): the lane's copy/x87 scheduling residues are not a target-processor flag.
- (chunk 835) VC7.1 compiles a reference-to-local alias and a one-member struct wrapper of a long exactly like the plain local (0x00D3D150 c13/c14 byte-identical): neither is a lever for register colouring.
- (chunk 835) FABLE_HDR_OVERLAY is only honoured for a header when its includers are overlaid too (MSVC searches the including file's directory first); prove the overlay with a deliberate breaking rename that must SRC_FAIL, never `#error`.

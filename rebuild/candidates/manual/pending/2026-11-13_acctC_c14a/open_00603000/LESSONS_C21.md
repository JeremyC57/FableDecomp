# agentC21 LESSONS (one line each)
- (c2 inliner) The inline "size" of a callee is the BYTE SIZE of its own optimised COMDAT in the same TU (objdump size = traced sz: 53 / 103 / 116 / 89); dead IL, assert arms, do-while(0), empty loops and Validate {} can never change it; measure with tools/osz.py in 3 s instead of a row trace.
- (c2 inliner) cost = bytes - argument savings (8 for a method on a local with one argument, 5 through a pointer/reference) - 10 for a LEAF callee + bytes*w/255 for a callee that keeps a loop (w = 1 + 254*loop tuples/all tuples) + a caller-size penalty past 9000 tuples; nested calls of an expanded callee are re-decided at the site.
- (c2 inliner) Implicit template instantiations take the `#pragma optimize` state at the END of the TU, not at the first use; check a TU's end state with a COMDAT only that TU can emit (retail __copy<CUIMiniMapMarker> 0x00612F70 = 133 bytes = ours).
- (c2 frequency) A `for` loop multiplies its body by 5 AND every later block of the function by 5 (leak); `while` 9 and no leak; do-while 10; an explicit guard halves; a loop inside an INLINED helper does not leak into the caller; sites inside an inlinee get site f x internal f (cold sites clamp to 1); a site inside __try is never inlined above cost 5 (site flag 2).
- (c2 codegen) A standalone body can be BIGGER for a shorter text: `{ ReleaseData(); Data = data; }` is 89 bytes (tail copied three times), the full Reset 103.
- (c2 codegen) Reloading and storing a member through an opaque `this` (`else Info = Info;`) is folded at /O1 (release not inlined) and when `this` is a local, but costs 11 bytes in the callee's own /O2 body: the only text class found that changes an inline price without changing any emitted row or /O1 byte.
- (FableWin sizes) FableWin = /Od /Os /EHsc: run fwsize with FW_EXTRA="/EHsc /Os" (ctor(), dtor, reset, DeleteData then grade SAME); one ASSERT = 13 instructions / 35 bytes (16i/43b with a two-term condition).
- (0x005FF190) A site whose path from the function entry is two `for` levels and two 50/50 branches has f >= 6.25 under every loop spelling; if retail calls a 95-cost callee there, the callee's price in that TU is higher (>= 103), whatever the text looks like elsewhere.

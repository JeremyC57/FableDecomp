# NF265 lessons
- When both PDBs carry a public `X` and a private `XBlockWhileBusy` twin, decide by the bodies and a long ordered run of retail
  neighbours matched to each PDB, not by access alone: a header-inline public forwarder could reach a private callee.
- A stand-in renderer type carries every callee it is called through: moving one data global moved five spellings in 0x00BE6090; census
  each moved callee (self leaf + other binders) before calling the unit count-reducing.
- Prove a header-route port of a big local-model row by sections, not by grade: same DEF list, every non-debug section byte- and
  relocation-equal after the renames. Expect `.drectve` to gain `/DEFAULTLIB:"libcp"` once the row pulls stlport/fable_containers.h.
- Control the controls: run pre.sh on a deliberate-error file and equiv_check on a planted default-path token before trusting "no output".
- Copied grading scripts may pass the overlay to the HEAD side or none at all; read them before the first grade.
- Census the NEW spelling, not only the address: grep rebuild/src/compiled for every symbol you are about to introduce. A same-TU helper
  that a landed row defines strongly (and no relocation binds, so no table line) can already own the name for another function.
- Two PDB ordering arguments can point opposite ways (adjacency to one neighbour); prefer a long run of consecutive functions matched in
  order (six here) over a single neighbour, and check the bodies (destroy-now v queue) against the names' meaning.

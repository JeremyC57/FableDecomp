# Chunk 148 lessons (for GOTCHAS)
- CAnimFilterOfGroup inlined into CMode* constructors: write the CRC as ONE call with two guards, `Calc(0, p == 0 ? "" : p->text, p == 0 ? 0 : p->length)`. VC folds the guards into one null test and the register pattern (eax/ecx + `mov edx,eax`, eax/ecx + edx-direct, ecx/eax + edx-direct) then follows the surrounding members by itself; the if/else forms (either assignment order) lock one pattern and miss the others. Nine constructors matched from one prelude.
- A module that calls 0x00404310 instead of inlining the CRC (0x0096DD10) wants an out-of-line `CCharString_ComputeCRC32(const CCharString&)` declaration in the filter ctor.
- Inline intelligent-pointer `operator=`: when retail calls GetPItem() on the source before forming the member address (`call GetPItem ; lea edi,[esi+N]`), take the item into a local first (`CBaseObject* item = o.GetPItem(); SetPItem(item);`); the direct `SetPItem(o.GetPItem())` puts the `lea` first. (0x008D7510 matched with the direct form because its member address was formed after the call anyway.)
- Destructors with no own vtable store over CModeBase: make every derived level `__declspec(novtable)` with a NON-virtual destructor; `~CModeBase() {}` inline stores 0x012673CC and the filters' implicit destructors store only CAnimFilterBase 0x0122FFCC. The catalog's "CModeIntangible::~CModeIntangible" twins were ~CModeDragonFlying (0x00743000) and ~CModeSleepBed (0x0084B840).
- A ternary-of-conditions skip test `cmp eax,1 ; jne ; test [m],2 ; jmp ; cmp eax,1Dh ; je exit` is nested early returns: `if (t == 1) { if (!(bits & 2)) return; } else if (t == 0x1d) return;` (the `?:` forms materialise a 0/1).
- A `push 0` before a virtual call on `this` whose result is pushed next can be the OUTER call's trailing argument, not the virtual's (0x008D6780: GetAnimFromName(name, GetAnimFilter(), 0)). Check the frame arithmetic of the following `lea`.
- 0x00AABCA0 / 0x00AAC460 / 0x00AAC5E0 are CSoundEmitterLH (vtable 0x0129E6EC), not CModeHoverBase; 0x008EA8A0 is CModeWalkInAllDirections slot 7. A VC6 list `erase(iterator)` whose iterator is built with `push ecx ; mov eax,esp ; mov [eax],esi` needs an iterator class with a user copy ctor.
- The pq-style diff filters that hide `call` lines also hide call/instruction ORDER differences: always trust the q.py status line and compare instruction bytes position by position.
- Lane gaps seen (parked): the CAnimInit build in the AnimUpdate family (BankIndex register ecx vs edx and the `lea` register for &init, four rows); `push -1` of a name temporary scheduled before the novtable base's register-zero stores (two CModeDragonFlyingBase ctors); esi/edi colouring of `this` vs the member address when `this` is used after the loop (0x008D7930); the lookup owner coalesced into esi (0x008DE700); a store sunk below the EH state store (0x00CAF820); `push eax` before `mov ecx,esi` (0x00C44AB0); a loop-invariant argument hoisted into ebp (0x00AAC5E0); locals sharing a dead argument slot (0x008EA8A0 / 0x008EA930).

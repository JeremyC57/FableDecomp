# Chunk 115 -- lessons from the authoring agent (fold into GOTCHAS at landing)
- Counted-pointer words zeroed AFTER a member object's vtable store (`call base ; mov [edi],vt ; xor ebx,ebx ; mov [edi+8],ebx ; mov [edi+0Ch],ebx`) need an EMBEDDED `{Data, Info}` struct with an inline constructor inside the member class; `PImp_Data(0), PImp_Info(0)` initialisers let the lane hoist the `xor` (first member) or the stores themselves (second member) above the vtable store (00d2f6b0, 00ec53c0, 00eb2000). The same holds for a run of zeroed scalars right after the derived vtable store in a constructor that then calls out (00df5c90: an embedded state struct; 00b29720: a 12-byte vector member), while the landed 00ed0e60 shows plain zeros can match when nothing follows them.
- A member re-read as `this` after an out-of-line call for the NEXT call (`call GFGetSystemManager ; mov ecx,[esi+4] ; mov edx,[eax+60h] ; push ; push ; mov ecx,[edx+8] ; call`) is `CSystemManager* system = GFGetSystemManager(); system->a->b->f(member, 1.0f)`: the call in a local, the chain derefs after the pushes (00a63200, 00a63240); the `display` local (one deref before) and the `core` local (both before) colour differently.
- An argument loaded into a callee-saved register BEFORE a chained object call and pushed after it (`mov edi,[esi+4] ; call GetDisplayEngine ; mov eax,[eax+74h] ; push edi ; mov ecx,eax ; call`) is a named local for the argument PLUS a named local for the chained object (00681980); either alone pushes before the call.
- `if (r) return !T(); T(); return 0;` (both arms call the terminating test, the result parked in bl) is the only form that reproduces the quest scripts' post-call `IsActiveThreadTerminating` guard; `if (T()) return false; return r;` is folded to `not al ; and eax,ecx` by the lane (00eb07d0).
- The vtable-call object expression of a global (`g->vcall(member, rand() % 6 + 10)`) is hoisted above the `rand()` call by the lane: put the computed argument in a local first (00ed72f0).
- A base constructor argument that is a member read of another argument (`owner->m_40` stored at +4 before the thing copy) must be the base's LAST parameter so that right-to-left evaluation loads it before the reference argument (`CVtable_012c3224(thing, owner->m_pInterface)`, 00eb2000); the derived class's own plain initialisers (`m_pOwner(owner)`) sit before its vtable store, a scalar stored after the last member constructor is a body assignment.
- IsFinished-style bodies that duplicate a sibling's whole body with its guard folded (`test eax,eax ; je`) are that sibling defined ABOVE in the same TU and inlined (00a3b330: Stop); `x >= 1.0f` is `fcomp ; test ah,1 ; jne`, `!(x < 1.0f)` is `test ah,5 ; jnp`.
- `fld qword ptr [__real@0.0] ; fstp qword ptr [esp]` is `double t = 0.0;` (the lane reproduces the constant load; no `fldz`), and a float function returning that double is `return (float)t;` with no narrowing under the era defaults (00a3b220/00a3b260).
- `log` as `fldln2 ; fxch ; fyl2x` needs `#include <math.h>` + `#pragma intrinsic(log)`; the clamp `if (v < K) v = K;` writes the immediate into the parameter slot and re-reads it (00a3b920).
- A `__thiscall` member called with ecx untouched since entry (`mov esi,ecx ; ... ; call GetDisplayEngine`) emits no `mov ecx,esi` -- declare it as a member, not static (0069e940).
- A by-value map key passed on by reference is `lea eax,[esp+0Ch]` of the ARGUMENT slot only when the inline find helper takes it `const unsigned long&`; a by-value helper parameter is copied back into the same slot first (009cc410).
- `vector::resize(2, T())` with an out-of-line T() constructor: the explicit temporary's returned `this` is pushed directly (`push eax`), consecutive temporaries share one frame slot sized for the largest (00eb6a00).
- Scalar `??_G` rows labelled `vector_deleting_destructor' in the manifest (`test byte ptr [esp+8],1 ; ret 4`) land with `// Leaf: ??_G<Class>`, a `__forceinline virtual ~T()` and a `new T` factory; a release written on a LOCAL copy of the member (`D* d = Data; if (d) { if (--d->m_refCount == 0) delete d; }`) gives `dec [ecx+8] ; jne ; push 1 ; call [eax]` (0098c3d0, 009c1ae0).

# wfD2 LESSONS
- (0x00E27E90, 0x00DC5F80) The "nested-copy blocker" of predicate rows (predicate ctor expanded, its nested CScriptThing copy 0x004ABE90 called, by-value copies expanded) closes with the landed idiom FABLE_RETAIL_CPREDICATEBASE_NOVTABLE + a `#pragma inline_depth(0)` region round the row-local predicate ctor (/dtor) + FABLE_RETAIL_CSCRIPTTHING_IMPLICIT_COPY. Two parked rows closed with it at once.
- (0x00E27E90, 0x00DC5F80) Writing a script loop `for (;; Game->NewScriptFrame()) { if (T) return; ... }` instead of `{...; NSF(); if (T) return;}` gives the same block layout but a different frequency model: it moved an implicit ctor's expand/call decision (0x00E27E90) and a const-0 register piece across the loop (0x00DC5F80). Try it first on any script loop residue.
- (0x00E27E90) When /d2inlT sweeps show the three relevant sites' scores interleave so no threshold fits (T54..56 / T57), a scoped `#pragma inline_depth(0)` round the single declaration whose implicit ctor retail CALLS is the per-site device.
- (0x00CFE030) Dead initialised locals (k=1..288, top or in-loop) do NOT move the SIB base/index order of a CSE'd, strength-reduced element address `[edi+ecx]` v `[ecx+edi]`; the record-count lever is not universal.
- (0x00EE57B0) For a long script Main whose length gap is exit pads, compare JUMP TARGETS of every T-check exit against retail (pad map), not the diff hunks: scoped inline_depth(0) regions on the exits retail sends to the all-call pad took the row from 4356v4246 / 60 hunks to 4261v4246 with only two misrouted exits.
- (0x00EE57B0) An inline_depth(0) region round a `return` inside a while-loop body had no effect when another return of the same scope (the block's first T check) is expanded: the exits appear to share one cleanup decision.
- (0x00EE57B0) `for (; true; Game->NewScriptFrame())` is NOT `for (;; Game->NewScriptFrame())` to VC7.1: the explicit `true` halves the static frequency of every block in (and after) the loop. When all of a row's exit-pad decisions (and loop alignment fillers) look like "ours expands at sites retail calls" by a uniform factor, test a diagnostic extra halving before the loop; if that fixes everything, try `for (; true; NSF)` / `while (true)` spellings of the loop.
- (tools) wfD2/tools/jt.py (exit site -> pad map, retail v ours) + tools/inl.sh / cmp_inl.sh (per-exit S/T/B decisions with f and score) found it in ~15 grades after 55 earlier grades of regions.
- (0x00D75060) Retail `mov eax,[esp+X]; lea ecx,[esp+X]; call [eax+12Ch]` (virtual IsAlive on a local filled by a Game call) = the local is a reference bound to the returned temporary (`CScriptThing& X = Game->Get...(...)`, as landed 0x00CE0920); bind only the locals retail calls virtually: by-value locals keep GetPos / GetDataString inline.
- (0x00D75060) VC7.1's static frequency model depends on the loop statement: a `for` with an increment expression (`for (n = 0; n < 4; ++n)`, `for (; n < 4; ++n)`, `for (;; NSF)`) gives the loop exit the header frequency (2.5 x entry for exits in and after the loop); `while (n < 4)` / `for (; n < 4; )` / do-while give exit = header / 2. A 1200-byte gap of expanded exit pads closed (5237 -> 4041) by the while spelling; measure with the inline trace before trying spellings.

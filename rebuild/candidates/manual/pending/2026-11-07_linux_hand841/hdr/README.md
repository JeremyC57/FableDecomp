# Chunk 841 header overlay

Each existing header was copied fresh from `rebuild/include/engine/` and only added to. The new lines sit inside a new opt-in
`#ifdef FABLE_RETAIL_<X>`, so the default path is textually unchanged. Run `diff rebuild/include/engine/<h> hdr/engine/<h>` and you see
only `>` lines. I re-diffed every file just before hand-back and none of the repo copies had changed. Because no default path changed,
no landed includer can change, so I did not recheck any.

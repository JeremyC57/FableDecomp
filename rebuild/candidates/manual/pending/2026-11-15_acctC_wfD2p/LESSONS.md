# wfD2 LESSONS
- (0x00E27E90, 0x00DC5F80) The "nested-copy blocker" of predicate rows (predicate ctor expanded, its nested CScriptThing copy 0x004ABE90 called, by-value copies expanded) closes with the landed idiom FABLE_RETAIL_CPREDICATEBASE_NOVTABLE + a `#pragma inline_depth(0)` region round the row-local predicate ctor (/dtor) + FABLE_RETAIL_CSCRIPTTHING_IMPLICIT_COPY. Two parked rows closed with it at once.
- (0x00E27E90, 0x00DC5F80) Writing a script loop `for (;; Game->NewScriptFrame()) { if (T) return; ... }` instead of `{...; NSF(); if (T) return;}` gives the same block layout but a different frequency model: it moved an implicit ctor's expand/call decision (0x00E27E90) and a const-0 register piece across the loop (0x00DC5F80). Try it first on any script loop residue.
- (0x00E27E90) When /d2inlT sweeps show the three relevant sites' scores interleave so no threshold fits (T54..56 / T57), a scoped `#pragma inline_depth(0)` round the single declaration whose implicit ctor retail CALLS is the per-site device.
- (0x00CFE030) Dead initialised locals (k=1..288, top or in-loop) do NOT move the SIB base/index order of a CSE'd, strength-reduced element address `[edi+ecx]` v `[ecx+edi]`; the record-count lever is not universal.
- (0x00EE57B0) For a long script Main whose length gap is exit pads, compare JUMP TARGETS of every T-check exit against retail (pad map), not the diff hunks: scoped inline_depth(0) regions on the exits retail sends to the all-call pad took the row from 4356v4246 / 60 hunks to 4261v4246 with only two misrouted exits.
- (0x00EE57B0) An inline_depth(0) region round a `return` inside a while-loop body had no effect when another return of the same scope (the block's first T check) is expanded: the exits appear to share one cleanup decision.
- (0x00EE57B0) `for (; true; Game->NewScriptFrame())` is NOT `for (;; Game->NewScriptFrame())` to VC7.1: the explicit `true` halves the static frequency of every block in (and after) the loop. When all of a row's exit-pad decisions (and loop alignment fillers) look like "ours expands at sites retail calls" by a uniform factor, test a diagnostic extra halving before the loop; if that fixes everything, try `for (; true; NSF)` / `while (true)` spellings of the loop.
- (tools) wfD2/tools/jt.py (exit site -> pad map, retail v ours) + tools/inl.sh / cmp_inl.sh (per-exit S/T/B decisions with f and score) found it in ~15 grades after 55 earlier grades of regions.
- (0x00D75060) Retail `mov eax,[esp+X]; lea ecx,[esp+X]; call [eax+12Ch]` (virtual IsAlive on a local filled by a Game call) = the local is a reference bound to the returned temporary (`CScriptThing& X = Game->Get...(...)`, as landed 0x00CE0920); bind only the locals retail calls virtually: by-value locals keep GetPos / GetDataString inline.
- (0x00D75060) VC7.1's static frequency model depends on the loop statement: a `for` with an increment expression (`for (n = 0; n < 4; ++n)`, `for (; n < 4; ++n)`, `for (;; NSF)`) gives the loop exit the header frequency (2.5 x entry for exits in and after the loop); `while (n < 4)` / `for (; n < 4; )` / do-while give exit = header / 2. A 1200-byte gap of expanded exit pads closed (5237 -> 4041) by the while spelling; measure with the inline trace before trying spellings.
- (0x00CFE030) A SIB base/index order residue between an inlined vector field load and an LSR temp is c2's operand sort on record ids and can be MEASURED in 35 s (tools/lk/lk2.py = wfB6's comparator log without the float filter; tools/lk/kk.sh): field record key = id * 32, LSR temp key = (id * 64) mod 65536 where the temp is the 12th record of a fresh 32-record chunk (key id = (64 * chunks + 22) mod 2048). Record ids are per function (other functions in the TU do not move them).
- (0x00CFE030) Dead-local rulers must be swept DENSELY: the windows were 2-3 wide (k = 81, 82, 112..114 at the top; 17/18 + 25..32 at two positions) and a sweep at 1,2,3,...,36,48,64,96 missed all of them. Position matters only relative to the statement where the first-pass allocation crosses a chunk boundary (find it by bisecting the position with a known-good k); locals inside an expanded helper only add records at inline time (they move the LSR temp, not first-pass ids).
- (0x00D75060) VC7.1 static frequencies for exit-pad work (measured): `if (T) return;` halves the running frequency (site = c/2); a return inside an if block costs c/4 and leaves 0.75 c; a counted for multiplies body AND all following code by 5; while / do-while / for(;cond;) do not; one do-while(0) wrapper is x1, two nested are x10 inside and x2 after. Write the retail decisions as inequalities on these before trying loop spellings: here they prove a x4 boost between two checks that no ordinary loop spelling supplies.
- (pad maps) Follow the FALL-THROUGH for `je` exits (the expanded pad sits inline after the check) and the jump target for `jne` exits, to the `ret`, listing calls by target: tools/pm.py prints retail v ours per T site and flags the misrouted ones.
- (0x00CFE030) A c2 record-count residue that needs ~200 more records before loop strength reduction (42-local ruler) closes with ONE dead release assert placed AFTER the record that must keep its id: inline-expanded CCharString text == terms in the dead arm carry ~1 chunk (32 records) each, out-of-line calls / plain compares almost nothing; asserts before the inlined sites change live code through the inline budget. Sweep count x condition weight x place in one-line-per-variant scripts (~300 grades, 10 min).
- (0x00D75060) `#pragma inline_depth(0)` disables __forceinline expansion too, and a pragma placed between an expression and its `;` applies to the whole statement: a temporary's dtor cannot be outlined alone in a statement that also needs inline helpers (GetPos / operator=). A /d2inlT window + regions is only a fix when every must-call site is a whole statement or a scope end.
- (0x00D75060, succ. 4) VC7.1 static frequencies by loop family (exit-pad work): counted `for(init;cond;inc)` ties the in-loop return, the body's scope-end dtor and the post-loop return at 2.5 x entry for EVERY spelling (bound, comparison, if/else or continue forms, do-while(0)-wrapped returns); while / do-while / goto loops make the body x18 hot and split exits 1:1; `for(init;;)` / `while(true)` + bottom break make the body cold but c2 then emits an extra T call. Dead release asserts change no frequency. Use tools/ffq.sh to read all pad f's in one trace.
- (0x00D75060, matched) An exit pad retail expands AFTER a loop whose in-loop exits it calls (f(post) > f(in-loop)) is the INLINE_DEPTH_REVISIT lever-2 statement macro on the in-loop terminate check: `do { if (T) return; } while (0);` stops that return draining the loop, so the post-loop check gets entry/2 instead of entry/4; then outline the now-hot wrapped check with a scoped inline_depth(0). Read the per-site f's with tools/ffq.sh + tools/vq.sh (one trace, ~30 s) before trying loop spellings.
- (0x00D75060) Retail `call ~X; inc reg; cmp reg,N; jl top` = the loop counter increments AFTER the body's scope end: `do { ... } while (++n < N);` (or a for increment), not `while (n < N) { ...; ++n; }` (VC7.1 keeps source order: inc before the dtor call).
- (0x00D75060) `while (true) { ...; if (++n >= N) break; }` with a terminate check at both loop top and after the loop makes c2 hoist the two IsActiveThreadTerminating calls into one before the compare (one T call fewer than retail); a structured loop condition keeps them apart.

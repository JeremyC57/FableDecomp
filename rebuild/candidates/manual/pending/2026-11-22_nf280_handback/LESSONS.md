# NF280 lessons (one line each)
- A one-store callee with a made-up name can be named from Ego_r's donor ORDER: the PDB member that sits directly before the same two neighbours as in retail, with a /Od size (fablewin_obj_functions.tsv) that fits one store, is the name (0x004457F0 = CGamePlayerInterface::Update).
- engine/CGamePlayerInterface.h's polymorphic class sits under FABLE_RETAIL_EXPRESSION_FRAME and needs FABLE_RETAIL_CDISKFILEWIN32 for its size: without it the opaque CDiskFileWin32 is 1-aligned and the class comes out 0x894, not 0x898 (clang `char (*)[offsetof(...)]` probes find the member in one call).
- A row's `// Leaf:` written as a bare name hides its real spelling: read the HEAD object's DEF list (sc.sh) before claiming the old leaf in RENAMES.
- Callee parameter spellings in a local model (pointer v reference) are names too: UpdateChecksum's PAV binding came only from GetInputs' local model; both PDBs say ABV.

# NF268 lessons (one line each)
- Freeze the overlay first: draft the port and clang-precheck it before equiv_check, so one whole-tree run covers every opt-in the port needs.
- A private self leaf on a row-local class model (QAE) is often a self-v-binder split; the class header's USE block (declarations at the right access) fixes it on the port.
- A slot-N clang census needs a VC7.1 object per row before any define: here all three "emitters" emitted no ??_7 at all.
- A self rename to virtual (QAE -> UAE) on a row-local derived model is line- and byte-neutral when the base model already has a vptr: check the object defines no ??_7 afterwards.
- A DECL_ONLY mirror that removes every pick-any definer of a destructor in a set must be judged by the link, unresolved lines included, not by the grade.
- pre.sh cds into the agent work dir: give it absolute paths.

## Lessons folded into GOTCHAS / the chunk brief this session
Frame size follows the callee's return-temporary type (respell virtuals to the PDB return type); same-TU stand-ins'
read/write of a parameter decides local homing; same-file bodies for every callee taking a counted pointer give
`dec [edi]; jne`; an identical leading call in both if-arms is hoisted; `(float)((float)a*b)` forces the early product
spill (replaced the GFAXToVX `volatile`); a callee retail inlines everywhere but once is a plain non-inline member
defined earlier in the file; three adjacent float slots are one C3DVector local; PDB respelling changed no bytes in 5
of 5 rows (do it for names, not codegen); the shared `engine/CDefPointer.h` Release() is mov/dec/mov where retail has
`dec [ecx+4]; jne` (header debt for migration wave 10); vland's host test transform drops every line containing
`static_assert`, so a static-assert macro must sit on one line.

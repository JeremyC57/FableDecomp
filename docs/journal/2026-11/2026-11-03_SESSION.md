## Learned (also in GOTCHAS)
- **Retail packing:** CIntelligentPointer / CBaseIntelligentPointer have alignment 1, but their owners are not packed (POwner at +0x0D, OwnerUID at +0x18; Ego_r has 60 of 648 members at odd offsets). C2DVector is packed too.
- **One STLport instantiation calls its own helpers.** One proven caller fixes T for the vector member and both helpers.
- **Explicit specializations:** an explicit specialization of a shared-header STL helper takes the primary template's convention (YI under /Gr).
- **CMainGameComponent vtable 0x0122F180:** dtor, Init, Run, ChangeTextureColourDepth, SetQuit, then Update, GetInputs, Render, PostInit, IsEditorActive. MSVC numbers new virtuals in declaration order.
- **Inlined callees:** to reproduce one, define its body in the TU (SetState's quit request = state 47 folded into FrameUpdate). Switch case source order sets the block order.
- **CWideString:** the wide-char constructor must not be explicit (0x006286F0).
- **Overlay pitfalls:**
  - Under FABLE_HDR_OVERLAY, `#pragma once`-only headers get included twice (C2011): recheck on a full-mirror overlay.
  - hdrcheck.py silently compares nothing when cpp stops early: use hdrcheck2.py.
- **Wine hangs:** a fatal cl error can spin cl.exe at 100% CPU for minutes. Run the preprocessor first and bound compiles at 120 s. Kill a stuck cl.exe and the agent's command returns.
- **Container restarts:** they kill agents, but `$S` survives. Resume an agent with SendMessage (its transcript is kept) and have it rerun only the unfinished recheck splits.
